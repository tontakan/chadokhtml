ขันติธรรมนำสันติสุข: บทเรียนจากอารยกาอำมาตย์

By wolf tbmx

Page 1/12

นานมาแล้ว ณ พระนครพาราณสี ปกครองโดยพระเจ้าพรหมทัต พระองค์ทรงเป็นกษัตริย์ที่มีเมตตาธรรมและทรงทำนุบำรุงบ้านเมืองให้ร่มเย็นเป็นสุข ประชาชนต่างยกย่องในความยุติธรรมของพระองค์ ภายในพระราชวังงดงามด้วยลวดลายวิจิตรบรรจง แสงแดดอ่อนๆ ยามเช้าสาดส่องลงบนพื้นหินอ่อน ทำให้บรรยากาศดูสงบเงียบและศักดิ์สิทธิ์

Page 2/12

แต่แล้ววันหนึ่ง ความสงบสุขก็ถูกสั่นคลอน เมื่อทหารสื่อสารรีบวิ่งเข้ามาในท้องพระโรงเพื่อรายงานข่าวด่วน มีกองทัพขนาดใหญ่จากเมืองข้างเคียงกำลังเคลื่อนพลใกล้เข้ามา นำโดยพระเจ้ารุทร กษัตริย์ผู้มีนิสัยวู่วามและกระหายในอำนาจ ทรงต้องการจะยึดครองเมืองพาราณสีมาเป็นของตน

Page 3/12

ข่าวการรุกรานแพร่กระจายไปทั่วเมือง พระเจ้ารุทรผู้เหี้ยมเกรี้ยวกำลังควบม้าศึกนำหน้ากองทัพที่ดูน่าเกรงขาม ทรงชูดาบขึ้นเหนือศีรษะด้วยความลำพองใจ เสียงโห่ร้องของทหารดังก้องไปทั่วทุ่งหญ้า ทุกย่างก้าวของกองทัพสร้างความหวาดกลัวให้กับผู้ที่พบเห็น

Page 4/12

เมื่อทราบข่าวร้าย พระเจ้าพรหมทัตทรงกริ้วเป็นอย่างมาก พระองค์ทรงเรียกประชุมเหล่าขุนนางทันที "เราจะยอมให้ใครมารังแกเมืองของเราไม่ได้! จงเตรียมกองทัพ เราจะออกไปรบกับพระเจ้ารุทรเดี๋ยวนี้!" พระองค์ตรัสด้วยเสียงอันดังจนท้องพระโรงสั่นสะเทือน

Page 5/12

ในขณะที่ทุกคนกำลังตื่นตระหนก อารยกาอำมาตย์ผู้มีปัญญาเฉลียวฉลาดและยึดมั่นในขันติธรรมได้ก้าวออกมาข้างหน้า ท่านเป็นที่ปรึกษาที่พระเจ้าพรหมทัตทรงไว้วางพระทัยที่สุด "ขอเดชะพระอาญาไม่พ้นเกล้า ความโกรธเปรียบเสมือนไฟที่เผาผลาญใจตนเองก่อนจะเผาผู้อื่นพระพุทธเจ้าข้า" อารยกากราบทูลด้วยน้ำเสียงนุ่มนวล

Page 6/12

"ท่านจะให้เราอยู่เฉยๆ ให้เขายึดเมืองอย่างนั้นหรือ?" กษัตริย์ถามด้วยความไม่พอใจ แต่อารยกาอำมาตย์ยิ้มอย่างอ่อนโยนแล้วกราบทูลต่อ "การใช้กำลังหยุดกำลังมีแต่จะสร้างความพินาศ แต่การใช้ 'ขันติ' หรือความอดทนอดกลั้น จะช่วยให้เรามองเห็นทางออกที่สงบสุขได้มากกว่าพระพุทธเจ้าข้า" ท่านเริ่มเล่าถึงผลเสียของสงครามที่จะเกิดกับผู้บริสุทธิ์

Page 7/12

อารยกาอธิบายว่า ความอดทนไม่ใช่ความอ่อนแอ แต่คือความเข้มแข็งที่เหนือกว่าการใช้อาวุธ "ผู้ที่ข่มใจตนเองได้ คือผู้ชนะที่แท้จริง หากพระองค์ทรงใช้ความสงบสยบความโกรธ พระองค์จะทรงปกป้องชีวิตผู้คนนับหมื่นได้โดยไม่ต้องเสียเลือดเนื้อแม้แต่หยดเดียว"

Page 8/12

พระเจ้าพรหมทัตทรงสดับฟังคำสอนเรื่องขันติธรรมและเริ่มไตร่ตรองตาม พระหฤทัยที่เคยร้อนรุ่มด้วยเพลิงแค้นค่อยๆ เย็นลงเหมือนถูกประพรมด้วยน้ำทิพย์ พระองค์ทรงตระหนักได้ว่าหากทำสงคราม ประชาชนจะต้องกำพร้าและพลัดพราก ความแค้นจะไม่มีวันจบสิ้น

Page 9/12

พระเจ้าพรหมทัตตัดสินใจส่งทูตถือสาส์นแห่งสันติภาพไปให้พระเจ้ารุทร โดยในสาส์นนั้นไม่ได้มีคำขู่เข็ญ แต่มีเพียงคำเชิญชวนให้มาร่วมโต๊ะเจรจาเพื่อความเป็นอยู่ที่ดีของประชาราษฎร์ทั้งสองเมือง ท่านทูตเดินทางไปยังค่ายทหารฝั่งตรงข้ามด้วยความกล้าหาญ

Page 10/12

เมื่อพระเจ้ารุทรได้อ่านข้อความในสาส์นที่เต็มไปด้วยความเมตตาและเหตุผล แทนที่จะเป็นคำท้าทายอย่างที่ทรงคาดไว้ พระองค์ก็ทรงเริ่มฉุกคิดถึงความเหนื่อยยากของทหารและความไร้สาระของการเข่นฆ่า ความอ่อนโยนของพระเจ้าพรหมทัตได้ชนะใจที่แข็งกระด้างของพระองค์ลงอย่างสิ้นเชิง

Page 11/12

กษัตริย์ทั้งสองพระองค์ตกลงที่จะพบกันที่ชายแดนโดยไม่มีอาวุธ ทั้งคู่เดินเข้าหากันและสวมกอดกันด้วยมิตรภาพ สงครามที่กำลังจะเกิดขึ้นถูกระงับลงด้วยพลังแห่งขันติธรรมและการให้อภัย ทหารทั้งสองฝ่ายต่างโห่ร้องด้วยความยินดีที่ได้กลับบ้านไปหาครอบครัว

Page 12/12

เมืองพาราณสีกลับมาสงบสุขอีกครั้ง พระเจ้าพรหมทัตทรงยกย่องอารยกาอำมาตย์ให้เป็นยอดแห่งขุนนาง และทรงใช้ขันติธรรมเป็นหลักในการปกครองตั้งแต่นั้นมา นิทานเรื่องนี้สอนให้รู้ว่า ความอดทนชนะทุกสิ่ง และสันติภาพที่ยั่งยืนเริ่มต้นได้ที่ใจของเราเอง
