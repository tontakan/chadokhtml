มณิสูกรชาดก: แก้วมณีกับพญาหมูป่าผู้ริษยา

By wolf tbmx

Page 1/12

ในอดีตกาล ณ ป่าหิมพานต์อันกว้างใหญ่ มีถ้ำแก้วมณีหลังหนึ่งตั้งตระหง่านอยู่อย่างสงบ แสงจากแก้วมณีนั้นส่องประกายระยิบระยับไปทั่วผืนป่า สร้างความสว่างไสวและความร่มเย็นให้กับสรรพสัตว์ทั้งหลายที่ได้พบเห็น ราวกับเป็นดวงดาวที่ตกลงมาสถิตอยู่บนพื้นดิน

Page 2/12

ที่ใกล้ถ้ำแก้วมณีนั้น มีพญาหมูป่าตัวหนึ่งชื่อว่า "วราหะ" อาศัยอยู่ วราหะเป็นหมูป่าที่มีจิตใจขุ่นมัวและเต็มไปด้วยความริษยา เขาไม่ชอบแสงสว่างที่งดงามของแก้วมณีเลย ทุกครั้งที่เขาเห็นแสงนั้นส่องประกาย เขาจะรู้สึกหงุดหงิดและปรารถนาจะทำลายความงามนั้นเสีย

Page 3/12

วราหะคิดในใจว่า "แสงของแก้วมณีนี้ช่างน่ารำคาญยิ่งนัก มันสว่างจนข้าแสบตา ข้าจะต้องหาวิธีทำให้มันมัวหมองและสิ้นแสงไปให้ได้ เพื่อที่ป่าแห่งนี้จะได้มืดมิดตามที่ข้าต้องการ" เขาเฝ้ามองแก้วมณีด้วยความอาฆาตมาดร้าย

Page 4/12

วันหนึ่ง วราหะเดินไปยังปลักโคลนที่เน่าเหม็น เขาลงไปนอนกลิ้งเกลือกในโคลนนั้นจนทั่วทั้งตัวหนาเตอะไปด้วยสิ่งสกปรก เขาตั้งใจจะใช้ร่างกายที่เปื้อนโคลนนี้ไปถูไถแก้วมณี เพื่อให้โคลนนั้นบดบังความใสกระจ่างของมัน

Page 5/12

วราหะเดินตรงไปยังแก้วมณีด้วยความมั่นใจ เขาใช้แผ่นหลังและสีข้างที่ชุ่มไปด้วยโคลนหนาๆ ถูไถไปบนพื้นผิวของแก้วมณีอย่างแรง เขาพยายามขยี้โคลนให้ติดแน่นที่สุดเท่าที่จะทำได้ โดยหวังว่ามันจะดับแสงสว่างนั้นลง

Page 6/12

แต่เหตุการณ์กลับไม่เป็นไปตามที่วราหะคิด ยิ่งเขานำโคลนไปถูมากเท่าไร และยิ่งเขาออกแรงขัดถูแรงขึ้นเพียงใด โคลนที่เปียกชื้นกลับหลุดลอกออกมา และแรงเสียดสีนั้นกลับกลายเป็นการขัดเงาให้แก้วมณีนั้นใสสะอาดยิ่งขึ้นกว่าเดิม

Page 7/12

วราหะไม่ยอมลดละ เขาคิดว่าเขาอาจจะยังใช้โคลนไม่มากพอ เขาจึงวิ่งกลับไปที่ปลักโคลนอีกครั้งและคราวนี้เขาพอกโคลนจนตัวพองโต แล้วกลับมาขัดถูแก้วมณีด้วยโทสะที่แรงกล้ากว่าเดิม

Page 8/12

นอกเหนือจากความพยายามของหมูป่า ในถ้ำใกล้ๆ กันนั้น มีพระฤๅษีตนหนึ่งชื่อว่า "มุนีกัสสปะ" ท่านบำเพ็ญเพียรอยู่และได้เฝ้าสังเกตการกระทำของวราหะมาโดยตลอด ท่านมองดูด้วยความสงบและเปี่ยมไปด้วยเมตตา

Page 9/12

วราหะขัดถูจนเหนื่อยหอบ ร่างกายของเขาสั่นเทาด้วยความเหนื่อยล้า แต่ผลลัพธ์ที่ได้คือแก้วมณีนั้นกลับยิ่งสะท้อนแสงอาทิตย์สว่างจ้าจนส่องไปไกลถึงสวรรค์ ความสกปรกจากตัวหมูป่าไม่อาจทำให้แก้วมณีระคายเคืองแม้แต่น้อย

Page 10/12

แสงสว่างนั้นส่องเข้าตาของวราหะจนเขาต้องหลับตาลงด้วยความเจ็บปวด ความริษยาที่เขามีกลับทำร้ายตัวเขาเอง เพราะยิ่งเขาพยายามทำลายผู้อื่น เขากลับยิ่งสร้างความรุ่งโรจน์ให้กับสิ่งนั้นและสร้างความลำบากให้กับตนเอง

Page 11/12

มุนีกัสสปะเดินเข้ามาหาวราหะอย่างช้าๆ แล้วกล่าวสอนว่า "ดูก่อนพญาหมูป่า ความดีงามและบริสุทธิ์นั้นเปรียบเสมือนแก้วมณีนี้ ยิ่งมีผู้คิดร้ายหรือพยายามนำสิ่งสกปรกมาแปดเปื้อน ความมั่นคงในความดีนั้นจะยิ่งขัดเกลาให้ผู้นั้นผ่องใสยิ่งขึ้นไปอีก"

Page 12/12

วราหะได้ฟังดังนั้นก็เกิดความละอายใจ เขาสำนึกผิดและเลิกริษยาแก้วมณีนั้น ตั้งแต่นั้นมา เขาก็อาศัยอยู่ร่วมกับสัตว์อื่นในป่าอย่างเป็นสุข โดยมีแสงสว่างจากแก้วมณีเป็นเครื่องนำทางชีวิตสืบไป ชาดกเรื่องนี้สอนให้รู้ว่า "ความดีที่แท้จริง ย่อมไม่หวั่นไหวต่อการใส่ร้ายป้ายสี"
