เงาลวงแห่งราตรี: บทเรียนจากวีณูนถูณชาดก

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งในนครพาราณสีอันรุ่งเรือง มีพระธิดาผู้เลอโฉมพระนามว่า เจ้าหญิงอินทุมดี เธอประทับอยู่ในปราสาทที่ตกแต่งด้วยลวดลายวิจิตรบรรจง ชีวิตของเธอพรั่งพร้อมไปด้วยความสุข แต่ในใจของเธอกลับโหยหาความตื่นเต้นและการผจญภัยที่อยู่นอกหน้าต่างบานนั้น

Page 2/12

ในคืนหนึ่งขณะที่ลมพัดเย็นสบาย เจ้าหญิงอินทุมดีได้ยินเสียงเพลงขลุ่ยอันไพเราะลอยมาจากสวนหลวง เสียงนั้นช่างนุ่มนวลและเปี่ยมไปด้วยเสน่ห์ จนเธอทนไม่ไหวต้องแอบเดินตามเสียงนั้นไปในความมืดมิดของราตรี

Page 3/12

ที่ใต้ต้นอโศกใหญ่ เธอเห็นเงาร่างหนึ่งทาบลงบนกำแพงหิน เงาที่สะท้อนออกมานั้นดูสูงสง่า ไหล่กว้าง และดูเหมือนยอดบุรุษผู้กล้าหาญ เธอมองดูเงานั้นด้วยความหลงใหล โดยหารู้ไม่ว่าแสงไฟจากตะเกียงดวงน้อยที่วางอยู่บนพื้นเป็นตัวหลอกตา

Page 4/12

เจ้าหญิงอินทุมดีรวบรวมความกล้าและเอ่ยทักทาย "ท่านผู้มีเสียงเพลงอันไพเราะ ท่านคือยอดนักรบจากเมืองใดกัน?" วักรันตอบกลับด้วยน้ำเสียงที่ทุ้มต่ำและสุภาพ "ข้าพเจ้าเป็นเพียงผู้ที่รักในเสียงดนตรีเท่านั้นพะยะค่ะ" คำพูดที่ถ่อมตัวนั้นยิ่งทำให้เจ้าหญิงปักใจเชื่อว่าเขาต้องเป็นวีรบุรุษผู้ปลอมตัวมา

Page 5/12

ตลอดหลายคืนต่อมา ทั้งสองได้พูดคุยกันผ่านความมืด เจ้าหญิงเล่าความฝันของเธอ ส่วนวักรันเล่าเรื่องราวของดวงดาวและบทกวี เธอจินตนาการไปว่าภายใต้เงามืดนั้น เขาต้องมีใบหน้าที่หล่อเหลาราวกับพระอินทร์และรูปร่างที่สมบูรณ์แบบ

Page 6/12

"ในคืนวันเพ็ญที่กำลังจะมาถึง จะมีงานเทศกาลโคมไฟทั่วเมือง" เจ้าหญิงเอ่ยด้วยความตื่นเต้น "ข้าอยากจะพบท่านในแสงสว่าง เพื่อที่ข้าจะได้เห็นความสง่างามของยอดบุรุษที่ข้าหลงรัก" วักรันนิ่งเงียบไปครู่หนึ่งก่อนจะตอบตกลงเบาๆ

Page 7/12

เมื่อคืนวันเพ็ญมาถึง นครพาราณสีถูกประดับประดาด้วยโคมไฟนับพันดวง แสงสีทองสว่างไสวไปทั่วทุกหนแห่ง เจ้าหญิงอินทุมดีในชุดเต็มยศที่งดงามที่สุด เดินออกมาที่จุดนัดพบพร้อมกับนางรับใช้คนสนิท

Page 8/12

เจ้าหญิงสอดส่ายสายตามองหาชายหนุ่มที่สูงสง่าตามที่เธอเคยเห็นในเงา หัวใจของเธอเต้นรัวด้วยความคาดหวัง "เขาต้องโดดเด่นกว่าใครในงานนี้แน่นอน" เธอรำพึงกับตัวเองขณะเดินผ่านซุ้มดอกไม้

Page 9/12

ทันใดนั้น เธอเห็นชายคนหนึ่งยืนอยู่ใต้แสงตะเกียงที่จุดนัดพบ เขาไม่ได้สูงใหญ่เหมือนเงาที่กำแพง แต่กลับเป็นชายร่างเล็ก หลังค่อม และมีท่าทางเกรงใจ เขาคือวักรันนั่นเอง เมื่อเขาหันมาเห็นเจ้าหญิง เขาก็ส่งยิ้มที่อ่อนโยนให้เธอ

Page 10/12

เจ้าหญิงอินทุมดีหยุดชะงักด้วยความตกใจ ความเพ้อฝันที่เธอสร้างขึ้นพังทลายลงในพริบตา "นี่หรือคือยอดบุรุษที่ข้าหลงรัก? เหตุใดท่านจึงดูต่างจากเงานั้นนัก!" เธออุทานออกมาด้วยความผิดหวังและสับสน

Page 11/12

วักรันก้มศีรษะลงเล็กน้อยแล้วกล่าวว่า "ข้าพเจ้าไม่เคยบอกว่าข้าพเจ้าเป็นยอดบุรุษผู้สง่าพะยะค่ะ เงามืดน่ะขยายทุกอย่างให้ใหญ่เกินจริง แต่เสียงเพลงและถ้อยคำที่ข้าพเจ้ามอบให้ท่านนั้นมาจากใจจริงของข้าพเจ้าเสมอ"

Page 12/12

เจ้าหญิงอินทุมดีได้สติและตระหนักได้ว่า เธอหลงรักเพียง "เงา" และภาพลักษณ์ที่เธอสร้างขึ้นเองในใจ บทเรียนนี้สอนให้เธอรู้ว่า ความจริงใจและความงดงามที่แท้จริงไม่ได้อยู่ที่รูปร่างที่ตาเห็น แต่อยู่ที่ตัวตนข้างในที่แสงสว่างเปิดเผยออกมา
