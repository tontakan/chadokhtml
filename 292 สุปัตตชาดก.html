พญากาสุปัตตะกับศรัทธาแห่งความรัก

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในป่าใหญ่อันร่มรื่น เป็นที่อยู่อาศัยของฝูงกานับพัน โดยมี "อาร์กา" พญากาผู้สง่างามและเปี่ยมด้วยคุณธรรมเป็นหัวหน้า อาร์กามีคู่ครองที่รักยิ่งชื่อว่า "มาลตี" ทั้งสองใช้ชีวิตร่วมกันอย่างมีความสุขท่ามกลางแมกไม้สีเขียวขจีและเสียงขับขานของธรรมชาติ

Page 2/12

อยู่มาวันหนึ่ง มาลตีซึ่งกำลังตั้งครรภ์เริ่มมีอาการแพ้ท้อง นางรู้สึกเบื่ออาหารทุกชนิดในป่า และปรารถนาจะได้ลิ้มรสอาหารอันประณีตจากเครื่องต้นของพระราชาแห่งเมืองพาราณสี นางเอ่ยปากบอกอาร์กาด้วยความอ่อนแรงว่า "ท่านพี่ ข้าอยากทานข้าวสุกที่มีกลิ่นหอมและรสเลิศจากวังหลวงเหลือเกิน"

Page 3/12

อาร์กาผู้รักภรรยายิ่งนัก ไม่อาจทนเห็นนางทุกข์ทรมานได้ จึงเรียก "เวกา" กาทหารเอกผู้มีความว่องไวและซื่อสัตย์มาพบ อาร์กากล่าวว่า "เวกาเอ๋ย มาลตีเมียรักของข้าอยากทานอาหารหลวง เจ้าพอจะช่วยข้านำอาหารเหล่านั้นมาให้นางได้หรือไม่?" เวกาตอบรับคำสั่งด้วยความเต็มใจ

Page 4/12

อาร์กาได้วางแผนการให้เวกาอย่างละเอียด "จงรอจังหวะที่พนักงานห้องเครื่องกำลังยกถาดอาหารผ่านลานกว้าง แล้วจงโฉบลงไปนำอาหารมาให้ได้ แต่อย่าได้ทำอันตรายใครเด็ดขาด" เวกาพยักหน้ารับคำและเตรียมพร้อมสำหรับการเดินทางไกลเข้าสู่ตัวเมือง

Page 5/12

เวกาบินข้ามป่าและขุนเขาจนมาถึงกำแพงเมืองพาราณสีอันยิ่งใหญ่ เขาเกาะอยู่บนยอดหอคอยสูง เฝ้ามองความวุ่นวายภายในวังหลวงด้วยสายตาที่แหลมคม รอคอยเวลาที่เหมาะสมตามที่อาร์กาได้บอกไว้ กลิ่นหอมของอาหารลอยมาตามลมทำให้เวการู้ว่าเป้าหมายอยู่ไม่ไกลแล้ว

Page 6/12

ภายในห้องเครื่องของวังหลวง "ปาชากะ" พ่อครัวใหญ่กำลังปรุงอาหารรสเลิศอย่างสุดฝีมือ กลิ่นเครื่องเทศหอมฟุ้งไปทั่วบริเวณ เขากำลังจัดวางอาหารลงในถาดทองคำเพื่อเตรียมนำไปถวายพระราชา โดยมี "ดาสะ" ลูกมือคอยช่วยประคองถาดอย่างระมัดระวัง

Page 7/12

เมื่อดาสะยกถาดอาหารเดินออกมาที่ระเบียงทางเดิน เวกาที่ซุ่มรออยู่ก็โผบินลงมาอย่างรวดเร็วราวกับลูกศร เขาใช้กรงเล็บเกี่ยวชิ้นเนื้อและอาหารคาวหวานออกมาจากถาดได้สำเร็จ ปาชากะที่เดินตามมาเห็นเข้าก็ตกใจและร้องตะโกนก้อง "ขโมย! มีกามาขโมยเครื่องเสวย!"

Page 8/12

เวกาพยายามบินหนีไปพร้อมกับอาหารในจะงอยปาก แต่ปาชากะไม่ยอมแพ้ เขาคว้าผ้ากันเปื้อนเหวี่ยงขึ้นไปบนอากาศเพื่อจะดักจับเวกา เวกาต้องหักหลบอย่างรวดเร็วแต่ก็ยังไม่ยอมทิ้งอาหารเหล่านั้น เพราะเขานึกถึงคำสั่งของอาร์กาและชีวิตของมาลตี

Page 9/12

ทว่าทหารยามชื่อ "มานสะ" ที่เฝ้าอยู่ใกล้ๆ เห็นเหตุการณ์ จึงรีบใช้ตาข่ายดักนกเหวี่ยงเข้าใส่ จนในที่สุดเวกาก็ถูกจับตัวไว้ได้ มานสะจับเวกาไว้มั่นแต่ก็แปลกใจที่เห็นกานี้ไม่ได้ดุร้ายและยังพยายามรักษาชิ้นอาหารไว้อย่างดี เขาจึงนำตัวเวกาไปเข้าเฝ้าพระราชา

Page 10/12

ในขณะเดียวกัน อาร์กาที่บินตามมาเฝ้าดูด้วยความเป็นห่วง ได้ตัดสินใจบินลงมาปรากฏตัวต่อหน้าพระราชา "พรหมทัต" อาร์กาหมอบลงและกล่าวด้วยภาษามนุษย์ว่า "ข้าแต่มหาราช โปรดอย่าลงโทษทหารของข้าเลย เขาทำไปเพราะความรักและความภักดีที่มีต่อเมียของข้าซึ่งกำลังตั้งท้อง"

Page 11/12

พระเจ้าพรหมทัตทรงประทับใจในความซื่อสัตย์ของเวกาและความรักที่อาร์กามีต่อภรรยา พระองค์จึงตรัสว่า "ความรักของพวกเจ้านั้นยิ่งใหญ่นัก ข้าจะมอบอาหารเหล่านี้ให้เจ้า และขอให้พวกเจ้ามารับอาหารหลวงได้ทุกวันจนกว่านางกาจะคลอด" อาร์กาก้มกราบด้วยความซาบซึ้งใจ

Page 12/12

อาร์กาและเวกานำอาหารหลวงกลับไปให้มาลตีที่ป่าได้อย่างปลอดภัย มาลตีได้รับประทานอาหารด้วยความอิ่มเอมใจและแข็งแรงขึ้น จนในที่สุดก็นำความสุขมาสู่ฝูงกาทั้งปวง เรื่องราวความรักและความภักดีของพญากาสุปัตตะจึงเป็นที่เล่าขานสืบต่อกันมานานแสนนาน
