ปริศนาแห่งต้นทองกวาว: บทเรียนจากการมองโลก

By wolf tbmx

Page 1/12

ณ นครพาราณสีอันรุ่งเรือง มีเจ้าชายสี่พี่น้องผู้มีความใฝ่รู้ วันหนึ่งพวกเขาได้ยินเรื่องราวของ "ต้นกึงสุกะ" หรือต้นทองกวาวที่งดงามแปลกตา ทั้งสี่จึงปรารถนาจะไปเห็นต้นไม้นี้ด้วยตาตนเองสักครั้ง วสุ พี่ชายคนโต และ นกุล น้องคนรอง นั่งปรึกษากันในอุทยานหลวงเกี่ยวกับแผนการเดินทางไปดูต้นไม้ในตำนานนั้น

Page 2/12

วสุ พี่ชายคนโตออกเดินทางไปที่ชายป่าเป็นคนแรกในฤดูร้อน เมื่อเขาไปถึง ต้นทองกวาวกำลังผลัดใบจนหมดสิ้น เหลือเพียงกิ่งก้านที่แห้งเหี่ยวและดำคล้ำ วสุมองดูต้นไม้นั้นด้วยความประหลาดใจ เขาจดจำภาพที่เห็นไว้ในใจว่าต้นกึงสุกะมีลักษณะไม่ต่างจากท่อนไม้ที่ถูกไฟครอก

Page 3/12

ต่อมาในต้นฤดูฝน นกุล น้องคนรองได้เดินทางไปที่จุดเดิมบ้าง ในยามนั้นต้นทองกวาวเริ่มแตกใบอ่อนสีเขียวขจีหนาแน่นปกคลุมกิ่งก้านจนมองไม่เห็นลำต้น นกุลตื่นตาตื่นใจกับความเขียวชอุ่มนั้น เขาเชื่อมั่นว่าต้นกึงสุกะมีลักษณะเหมือนกับต้นไทรที่แผ่กิ่งก้านสาขาอย่างสง่างาม

Page 4/12

เมื่อเข้าสู่ช่วงกลางฤดูฝน สหัส น้องคนที่สามก็เดินทางไปชมต้นไม้บ้าง ทว่าในตอนนั้น ต้นทองกวาวกลับออกดอกสะพรั่งแดงฉานไปทั่วทั้งต้นราวกับเปลวเพลิง สหัสมองภาพนั้นด้วยความทึ่ง เขาจดจำอย่างมั่นใจว่าต้นกึงสุกะมีลักษณะแดงฉานประหนึ่งชิ้นเนื้อสดหรือเปลวไฟที่โชติช่วง

Page 5/12

สุดท้าย วิทูร น้องคนเล็กเดินทางไปถึงต้นไม้ในฤดูหนาว ในยามนั้นดอกและใบเริ่มร่วงโรย เหลือเพียงฝักที่ห้อยระย้าอยู่ตามกิ่ง วิทูรมองดูฝักเหล่านั้นแล้วคิดว่า พี่ๆ ของเขาคงเข้าใจผิดเป็นแน่ เพราะต้นกึงสุกะที่เขาเห็นนั้น มีลักษณะคล้ายกับต้นกระถินที่มีฝักยาวเหยียดเท่านั้นเอง

Page 6/12

เมื่อพี่น้องทั้งสี่กลับมาพบกัน วสุได้เอ่ยขึ้นว่า "ต้นกึงสุกะนั้นช่างอัปลักษณ์เหมือนตอไม้ดำๆ" นกุลขัดขึ้นทันทีว่า "พี่พูดอะไรกัน มันเขียวขจีเหมือนต้นไทรต่างหาก!" ทั้งคู่เริ่มโต้เถียงกันอย่างรุนแรงตามสิ่งที่ตนได้เห็นมา

Page 7/12

สหัสและวิทูรเมื่อได้ยินดังนั้นก็เข้าร่วมวงสนทนาด้วย "พวกพี่เข้าใจผิดแล้ว มันแดงเหมือนเนื้อสดต่างหาก" สหัสกล่าว ส่วนวิทูรก็เถียงว่า "ไม่ใช่เลย มันมีฝักเหมือนต้นกระถินชัดๆ" ความขัดแย้งเริ่มลุกลามไปทั่วอุทยานหลวง พี่น้องที่เคยรักกันกลับต้องมาทะเลาะกันเพราะเรื่องต้นไม้ต้นเดียว

Page 8/12

เพื่อหาข้อยุติ ทั้งสี่จึงตัดสินใจเดินทางไปหา พระฤๅษี ผู้เป็นอาจารย์และที่ปรึกษาของราชวงศ์ วสุเป็นตัวแทนกราบเรียนเล่าถึงความแตกต่างของต้นไม้ที่แต่ละคนได้เห็นมา พระฤๅษีฟังด้วยรอยยิ้มที่มีความเมตตาและสงบนิ่ง

Page 9/12

นกุลและสหัสพยายามอธิบายสิ่งที่ตนเห็นอย่างกระตือรือร้น "ทำไมสิ่งที่พวกเราเห็นถึงไม่เหมือนกันเลยล่ะครับท่านอาจารย์?" นกุลถามด้วยความสงสัย ส่วนสหัสก็ยังคงยืนยันในภาพดอกไม้สีแดงที่เขาประทับใจ

Page 10/12

พระฤๅษีได้กล่าวไขปริศนาว่า "พวกเจ้าทุกคนพูดถูก แต่ถูกเพียงส่วนเดียวเท่านั้น เพราะพวกเจ้าไปเห็นต้นกึงสุกะในฤดูกาลที่ต่างกัน ต้นไม้ต้นเดิมย่อมเปลี่ยนไปตามกาลเวลา" วิทูรฟังคำสอนนั้นแล้วเริ่มตระหนักถึงความจริงที่เขามองข้ามไป

Page 11/12

"การมองโลกเพียงด้านเดียวและยึดติดว่าตนเองถูกที่สุด ย่อมนำมาซึ่งการทะเลาะเบาะแว้ง" พระฤๅษีสอนต่อ วสุและวิทูรต่างก้มหน้าด้วยความละอายใจที่ตนเองเอาแต่เถียงกันโดยไม่ยอมฟังเหตุผลของพี่น้องคนอื่น ทั้งสองเริ่มเข้าใจว่าความจริงนั้นมีหลายแง่มุม

Page 12/12

พี่น้องทั้งสี่กลับมาสามัคคีกันอีกครั้ง พวกเขาเรียนรู้ที่จะรับฟังความคิดเห็นที่แตกต่างและเข้าใจว่าความจริงมีหลายมิติ สหัสและนกุลเดินจูงมือกันกลับเข้าเมืองด้วยใบหน้ายิ้มแย้ม ทิ้งบทเรียนเรื่องต้นกึงสุกะไว้เป็นคติเตือนใจสืบต่อไป
