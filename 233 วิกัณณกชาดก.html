บ่วงแห่งรสสัมผัส: บทเรียนจากวิกัณณกชาดก

By wolf tbmx

Page 1/12

ในแม่น้ำสายใหญ่ที่ไหลรินผ่านป่าลึกอันอุดมสมบูรณ์ มีปลาตัวหนึ่งชื่อว่า มัตสยา เขาเป็นปลาที่มีเกล็ดงามและท่วงท่าการว่ายน้ำที่สง่างาม มัตสยาใช้ชีวิตอย่างสงบสุขท่ามกลางกระแสน้ำที่เย็นฉ่ำ

Page 2/12

มัตสยามีปลาตัวเมียคู่ใจชื่อว่า มีนา ทั้งสองมักจะว่ายน้ำไปด้วยกันเสมอ คอยดูแลและเกื้อกูลกันในทุกยาม ไม่ว่าจะยามหาอาหารหรือยามพักผ่อนในหลืบหิน

Page 3/12

อยู่มาวันหนึ่ง มีเบ็ดอันหนึ่งถูกหย่อนลงมาจากเบื้องบน ปลายเบ็ดนั้นมีเหยื่อชิ้นโตที่ส่งกลิ่นหอมเย้ายวนใจลอยมาตามน้ำ มัตสยาผู้หิวโหยเริ่มได้กลิ่นนั้นและหันมองด้วยความสนใจ

Page 4/12

เมื่อเห็นมัตสยาทำท่าจะว่ายเข้าไปหาเหยื่อ มีนาก็รู้สึกสังหรณ์ใจไม่ดี เธอรีบว่ายมาขวางหน้าแล้วกล่าวเตือนว่า "พี่จ๋า สิ่งนั้นดูแปลกปลอมและอันตรายนัก อย่าได้เข้าไปใกล้เลย"

Page 5/12

แต่มัตสยากลับไม่ฟังเสียงเตือนของมีนาเลย ในใจของเขาเต็มไปด้วยความอยากลิ้มรสเหยื่อที่ส่งกลิ่นหอมนั้น เขาคิดเพียงว่า "แค่นิดเดียวเท่านั้น คงไม่เป็นไรหรอก"

Page 6/12

ทันทีที่มัตสยาฮุบเหยื่อเข้าไปเต็มคำ ตะขอเบ็ดที่แหลมคมก็เกี่ยวเข้าที่ปากของเขาอย่างจัง ความเจ็บปวดแล่นพล่านไปทั่วตัว มัตสยาพยายามดิ้นรนแต่สายเบ็ดกลับยิ่งรั้งเขาไว้แน่น

Page 7/12

บนฝั่งน้ำ เกวัตตะ ชาวประมงผู้ชำนาญการ รู้สึกได้ถึงแรงดึงที่ปลายสายเบ็ด เขาแสยะยิ้มด้วยความดีใจแล้วเริ่มออกแรงสาวสายเบ็ดขึ้นมาอย่างช้าๆ

Page 8/12

ร่างของมัตสยาถูกลากขึ้นพ้นผืนน้ำที่เคยเป็นบ้าน เขาพยายามอ้าปากหายใจแต่กลับพบเพียงอากาศที่เขาไม่คุ้นเคย แรงดิ้นของเขาเริ่มอ่อนแรงลงเมื่อถูกดึงขึ้นมาอยู่บนมือของเกวัตตะ

Page 9/12

มีนาเฝ้ามองภาพนั้นจากใต้น้ำด้วยความตกตะลึงและเศร้าโศก เธอไม่เข้าใจว่าทำไมมัตสยาถึงหายไปบนนั้น เธอรำพันด้วยความเสียใจว่า "พี่คงทิ้งฉันไปหาปลาตัวอื่นที่สวยงามกว่าเสียแล้ว"

Page 10/12

เกวัตตะนำมัตสยาไปวางไว้บนกองหญ้า เตรียมจะนำไปทำเป็นอาหารเย็น เขาไม่ได้สนใจเลยว่าปลาตัวนี้กำลังทรมานจากการสูญเสียอิสรภาพและคนรัก

Page 11/12

ในขณะนั้น วิทูระ รุกขเทวดาผู้สถิตอยู่ในต้นไม้ใหญ่ริมน้ำ ได้เฝ้าสังเกตเหตุการณ์ทั้งหมด ท่านปรากฏกายออกมาด้วยความเวทนาต่อความเขลาของสัตว์โลก

Page 12/12

วิทูระกล่าวธรรมเตือนใจว่า "ความโลภในรสสัมผัสชั่วครู่ทำลายได้แม้แต่ชีวิตและครอบครัว มัตสยาเอ๋ย หากเจ้าฟังคำเตือนและละความโลภ เจ้าคงไม่ต้องพบจุดจบเช่นนี้"
