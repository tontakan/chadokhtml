เจ้าลิงกปิละกับชุดนักบวชลวงตา

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งในป่าลึกอันเขียวขจี มีลิงแก่เจ้าปัญญาตัวหนึ่งชื่อว่า "กปิละ" แม้กปิละจะอายุมากแล้ว แต่มันก็ยังเป็นลิงที่ขี้เกียจหาอาหาร และมักจะใช้ไหวพริบในทางที่ผิดเพื่อหลอกกินแรงผู้อื่นอยู่เสมอ

Page 2/12

วันหนึ่ง กปิละเดินไปแถวชายป่าและพบกับกองเครื่องบริขารของนักบวชที่วางทิ้งไว้ มีทั้งผ้ากาสาวพัสตร์สีหม่นและไม้เท้า "หึหึ ถ้าฉันแต่งตัวเป็นนักบวชผู้ทรงศีล ชาวบ้านคงจะเอาของอร่อยๆ มาประเคนให้ฉันจนอิ่มแปร่โดยไม่ต้องเหนื่อยเลย" มันคิดในใจ

Page 3/12

กปิละเริ่มลงมือปลอมตัว มันนำขี้เถ้าสีขาวมาทาตามตัวจนทั่วเพื่ออำพรางขนลิง จากนั้นก็ห่มผ้าเหลืองอย่างประณีตและถือไม้เท้า ทำท่าทางเดินหลังโกงเหมือนผู้นำศีลผู้แก่กล้า

Page 4/12

เมื่อปลอมตัวจนเนียนตา กปิละก็เดินเตาะแตะออกจากป่ามุ่งหน้าไปยังหมู่บ้านที่อยู่ใกล้เคียง มันพยายามเดินสองขาและท่องพึมพำเลียนแบบเสียงสวดมนต์อย่างแนบเนียน

Page 5/12

เมื่อไปถึงโคนต้นไม้ใหญ่ใกล้หมู่บ้าน กปิละก็นั่งขัดสมาธิหลับตาพริ้ม ทำท่าบำเพ็ญตบะ ชาวบ้านคนหนึ่งเดินผ่านมาเห็นเข้าก็หลงเชื่อในทันที "โอ้! มีพระผู้เป็นเจ้ามาโปรดพวกเราแล้ว"

Page 6/12

ข่าวเรื่องนักบวชผู้สงบนิ่งแพร่กระจายไปทั่วหมู่บ้าน ไม่นานนัก ชาวบ้านต่างพากันนำถาดผลไม้รสหวาน ขนมนมเนย และน้ำผึ้งชั้นดีมาวางถวายตรงหน้ากปิละไม่ขาดสาย

Page 7/12

ในหมู่บ้านนั้นมีชายผู้มีปัญญาหลักแหลมชื่อว่า "วิทูร" เขาสังเกตเห็นความผิดปกติบางอย่าง วิทูรแอบเฝ้าดูนักบวชผู้นี้อยู่นาน และเริ่มสงสัยว่าทำไมพระผู้ทรงศีลถึงมีกิริยาที่ดูไม่สำรวมในบางจังหวะ

Page 8/12

วิทูรเดินเข้าไปใกล้กปิละเพื่อพิสูจน์ความจริง ในขณะที่เขาก้มลงทำท่าจะกราบ เขาก็แอบเห็นหางยาวๆ ที่ขดอยู่ภายใต้ผ้าเหลืองโผล่ออกมาเล็กน้อย "หึหึ เจ้าลิงตัวแสบ ปลอมตัวมาหลอกชาวบ้านนี่เอง" วิทูรคิดในใจ

Page 9/12

เพื่อให้กปิละเผยธาตุแท้ออกมา วิทูรจึงกลับไปนำถุงข้าวพองอบน้ำผึ้งที่ส่งกลิ่นหอมหวนรัญจวนใจที่สุดออกมา เขาเดินเข้าไปหานักบวชปลอมอีกครั้งพร้อมถุงของโปรดของลิง

Page 10/12

ทันทีที่กลิ่นข้าวพองลอยเข้าจมูก สัญชาตญาณลิงของกปิละก็ตื่นตัว มันลืมตัวไปเสียสนิทว่ากำลังปลอมตัวอยู่ กปิละลืมตาโพลงและรีบเอื้อมมือที่มีขนดกออกมาจากใต้จีวรเพื่อจะตะครุบถุงขนมนั้น

Page 11/12

ความแรงจากการตะครุบทำให้ผ้ากาสาวพัสตร์หลุดลุ่ยออก เผยให้เห็นร่างลิงแก่ที่ทาขี้เถ้าด่างพร้อย ชาวบ้านที่อยู่รอบๆ ต่างตกใจและร้องตะโกนด้วยความโกรธ "นั่นมันไม่ใช่พระนี่นา! มันคือเจ้าลิงเจ้าเล่ห์!"

Page 12/12

กปิละรีบวิ่งหนีหัวซุกหัวซุนกลับเข้าป่าไปพร้อมกับเสียงขับไล่ วิทูรจึงสอนชาวบ้านว่า "อย่าหลงเชื่อเพียงรูปลักษณ์ภายนอก เพราะคนชั่วจะแต่งกายสวยงามอย่างไร สันดานเดิมก็ย่อมปรากฏออกมาในที่สุด"
