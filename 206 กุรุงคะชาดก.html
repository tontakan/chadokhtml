กุรุงคะผู้ชาญฉลาดกับพรานลวง

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งในป่าลึกอันอุดมสมบูรณ์ เป็นที่อยู่อาศัยของพญาเนื้อผู้มีนามว่า "กุรุงคะ" เขาเป็นเนื้อที่มีรูปร่างสง่างาม มีดวงตาที่คมกริบและมีสติปัญญาเป็นเลิศ กุรุงคะใช้ชีวิตอย่างสงบสุขและคอยดูแลเหล่าสัตว์น้อยใหญ่ในป่าแห่งนี้ด้วยความเมตตาเสมอมา

Page 2/12

ไม่ไกลกันนัก มีพรานป่าคนหนึ่งชื่อ "ลุทธกะ" เขาเป็นพรานที่เต็มไปด้วยความโลภ ลุทธกะเฝ้าสังเกตเห็นว่าพญาเนื้อกุรุงคะมักจะมากินผลไม้ที่ใต้ต้นพุทราป่าเป็นประจำ เขาจึงวางแผนร้ายที่จะจับพญาเนื้อตัวนี้มาเป็นอาหารของตนให้ได้

Page 3/12

วันหนึ่ง ลุทธกะแอบปีนขึ้นไปบนต้นพุทราป่าตั้งแต่เช้ามืด เขาเตรียมตะกร้าที่เต็มไปด้วยผลพุทราสุกงอมรสหวานฉ่ำ "คราวนี้แหละ เจ้าพญาเนื้อผู้อวดดี เจ้าไม่มีทางรอดพ้นจากกับดักของข้าไปได้" ลุทธกะพึมพำกับตัวเองด้วยความกระหยิ่มยิ้มย่อง

Page 4/12

เมื่อดวงอาทิตย์เริ่มทอแสงทอง กุรุงคะก็เดินมายังต้นพุทราที่คุ้นเคย แต่ในวันนี้ เขารู้สึกถึงความผิดปกติบางอย่าง พญาเนื้อหยุดยืนอยู่ห่างๆ และสูดอากาศเพื่อค้นหากลิ่นที่แปลกปลอม "วันนี้ป่าดูเงียบเหงากว่าปกติ" กุรุงคะคิดในใจอย่างระมัดระวัง

Page 5/12

ลุทธกะที่ซุ่มอยู่บนต้นไม้เห็นกุรุงคะลังเล เขาจึงเริ่มโปรยผลพุทราลงมาทีละผล สองผล เพื่อล่อให้พญาเนื้อเดินเข้ามาใกล้โคนต้นไม้ "มาสิ เจ้าเนื้อน้อย ผลไม้หวานๆ รอเจ้าอยู่ตรงนี้แล้ว" พรานร้ายแอบหัวเราะเบาๆ อยู่บนกิ่งไม้สูง

Page 6/12

กุรุงคะมองเห็นผลพุทราที่ร่วงหล่นลงมา แต่มันไม่ได้หล่นลงมาตามธรรมชาติ ผลไม้เหล่านั้นกลับตกลงมาตรงหน้าเขาอย่างพอดิบพอดี "แปลกเหลือเกิน ผลพุทราเหล่านี้ดูเหมือนจะมีชีวิตและรู้ว่าข้ายืนอยู่ตรงไหน" พญาเนื้อผู้ฉลาดเริ่มจับสังเกตได้

Page 7/12

พญาเนื้อกุรุงคะเงยหน้าขึ้นมองที่ยอดไม้ แม้จะเห็นเพียงใบไม้ที่หนาทึบ แต่เขาก็รู้ดีว่ามีใครบางคนซ่อนอยู่ข้างบนนั้น ลุทธกะพยายามอยู่นิ่งที่สุดเท่าที่จะทำได้ แต่หัวใจของเขากลับเต้นรัวด้วยความตื่นเต้นที่จะได้จับเหยื่อ

Page 8/12

กุรุงคะตัดสินใจที่จะทดสอบความจริง เขาแสร้งทำเป็นพูดกับต้นไม้ว่า "โอ้ ต้นพุทราเอ๋ย ปกติเจ้าจะทิ้งผลลงสู่ดินอย่างนอบน้อม แต่วันนี้เหตุใดเจ้าจึงโยนผลไม้มาให้ข้าถึงที่ ราวกับว่าเจ้ามีมือที่ขว้างปามันมา"

Page 9/12

ลุทธกะได้ยินดังนั้นก็สำคัญผิด คิดว่าพญาเนื้อเป็นสัตว์วิเศษที่คุยกับต้นไม้ได้จริงๆ เขาจึงเผลอขยับตัวด้วยความประหลาดใจ ทำให้เกิดเสียงกิ่งไม้เสียดสีกัน "เจ้าพรานใจร้าย ข้ารู้แล้วว่าท่านซ่อนตัวอยู่บนนั้น!" กุรุงคะร้องประกาศลั่นป่า

Page 10/12

"ในเมื่อเจ้าไม่ตกหลุมพรางของข้า ก็จงตายเสียเถิด!" ลุทธกะคำรามด้วยความโกรธ เขาคว้าหอกที่เตรียมไว้แล้วพุ่งลงมาใส่กุรุงคะอย่างสุดแรง พญาเนื้อผู้ระวังตัวอยู่แล้วก็เอี้ยวตัวหลบได้อย่างหวุดหวิด

Page 11/12

หอกของพรานป่าปักลงบนพื้นดินเสียงดังสนั่น แต่กุรุงคะกลับวิ่งหนีเข้าสู่ป่าลึกไปอย่างรวดเร็ว ลุทธกะได้แต่ยืนมองตามด้วยความเจ็บใจ "เจ้าเนื้อตัวนี้ช่างฉลาดเกินคนจริงๆ" พรานป่ากล่าวทิ้งท้ายด้วยความพ่ายแพ้

Page 12/12

กุรุงคะกลับคืนสู่ฝูงด้วยความปลอดภัย เขาเล่าเรื่องราวที่เกิดขึ้นให้สัตว์อื่นๆ ฟังเพื่อเป็นบทเรียนว่า "ความโลภของผู้อื่นอาจมาในรูปของความหวานชื่น แต่สติและปัญญาจะช่วยให้เราพ้นภัย" ตั้งแต่นั้นมา พรานลุทธกะก็ไม่กล้ามากล้ำกรายในเขตป่าของพญาเนื้อกุรุงคะอีกเลย
