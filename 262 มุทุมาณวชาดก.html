มุทุมาณวชาดก: มาณพหนุ่มกับบทเรียนในถ้ำมืด

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว มีชายหนุ่มรูปงามนามว่า "จารุ" เขาเป็นผู้ที่หลงใหลในความสวยงามของทุกสรรพสิ่งรอบตัว จารุมักจะใช้เวลาทั้งวันไปกับการชื่นชมดอกไม้ที่เบ่งบานและเงาสะท้อนของตนเองในลำธาร เขาเชื่อเสมอว่าสิ่งที่สวยงามย่อมไม่มีอันตรายใดๆ

Page 2/12

วันหนึ่ง จารุตัดสินใจออกเดินทางเข้าไปในป่าลึกเพียงลำพัง เพื่อตามหาสิ่งที่งดงามที่สุดในโลก เขาเดินลัดเลาะผ่านแมกไม้ที่หนาทึบ แสงแดดรำไรส่องลงมาบนพื้นดินที่เป็นสีแดงอิฐ จารุไม่รู้เลยว่าเขากำลังก้าวเข้าสู่เขตแดนของนางยักษ์ผู้หิวโหย

Page 3/12

ทันใดนั้น จารุก็พบกับหญิงสาวผู้เลอโฉมนามว่า "มายา" เธอนั่งรอเขาอยู่ใต้ต้นไทรใหญ่ริมสระบัว มายามีรูปโฉมงดงามราวกับเทพธิดา ผิวพรรณของเธอผุดผ่องและประดับประดาด้วยอัญมณีล้ำค่า จารุตกตะลึงในความงามของเธอจนลืมความระมัดระวังตัวไปเสียสิ้น

Page 4/12

มายาส่งยิ้มหวานให้จารุและเอ่ยชวนด้วยน้ำเสียงที่ไพเราะ "ท่านผู้เจริญ หากท่านตามหาความงามที่แท้จริง จงตามข้าพเจ้ามาที่ถ้ำแห่งความลับเถิด ที่นั่นมีสมบัติพราวพรายยิ่งกว่าสิ่งใด" จารุผู้หลงใหลในรูปลักษณ์ภายนอกจึงรีบเดินตามเธอไปโดยไม่ลังเล

Page 5/12

เมื่อเข้ามาถึงภายในถ้ำ จารุเห็นประกายระยิบระยับอยู่เต็มไปหมด เขานึกว่าเป็นเพชรนิลจินดาที่ถูกประดับไว้บนผนังถ้ำ แต่ในความมืดสลัวนั้น เขายังไม่สังเกตเห็นความจริงที่น่าสะพรึงกลัวว่าสิ่งที่เขามองเห็นนั้นอาจไม่ใช่สิ่งที่เขาคิด

Page 6/12

จารุเริ่มสังเกตเห็นบางอย่างที่ผิดปกติ มายาไม่เคยกะพริบตาเลยแม้แต่ครั้งเดียว และดวงตาของเธอก็เริ่มเปลี่ยนเป็นสีแดงฉานราวกับถ่านไฟที่ลุกโชน ความสวยงามที่เขาเคยเห็นเริ่มจางหายไป กลายเป็นความเย็นเยือกที่น่าขนลุกเข้ามาแทนที่

Page 7/12

ทันใดนั้น ร่างของหญิงงามก็สูญสลายไป กลายเป็นนางยักษ์ที่น่าเกลียดน่ากลัว มายาเผยร่างจริงที่มีเขี้ยวแหลมคมและเล็บที่ยาวเฟื้อย เธอยืนตระหง่านอยู่กลางถ้ำและหัวเราะเสียงดังสนั่น "เจ้าช่างเขลาเหลือนักที่มองเพียงรูปลักษณ์ภายนอก บัดนี้เจ้าคืออาหารของข้า!"

Page 8/12

จารุทรุดตัวลงด้วยความหวาดกลัว เขาวิ่งหนีไปติดอยู่ที่มุมถ้ำลึก รอบกายเขาบัดนี้ไม่ใช่เพชรพลอย แต่เป็นเศษกระดูกของบรรดาผู้ที่เคยหลงกลนางยักษ์มาก่อน จารุเสียใจที่ความหลงใหลในรูปโฉมทำให้เขาต้องมาพบกับจุดจบเช่นนี้

Page 9/12

ในวินาทีที่สิ้นหวัง จารุก็นึกถึงคำสั่งสอนของ "สุเมธ" อาจารย์ผู้มีวิทยปัญญาที่เคยเตือนเขาไว้ว่า "ความงามที่แท้จริงมิได้อยู่ที่ดวงตาเห็น แต่อยู่ที่จิตใจที่รู้เท่าทันความจริง" ภาพใบหน้าอันสงบของอาจารย์ปรากฏขึ้นในความคิดของเขา

Page 10/12

จารุหลับตาลงและตั้งสติ เขาเริ่มสวดมนต์และระลึกถึงความดีงามที่อาจารย์สอน แสงสว่างสีทองเริ่มเปล่งประกายออกมาจากตัวของเขา แสงนั้นไม่ใช่แสงจากอัญมณีภายนอก แต่เป็นแสงแห่งปัญญาที่เริ่มเบ่งบานภายในใจของจารุเอง

Page 11/12

นางยักษ์มายาไม่สามารถเข้าใกล้แสงแห่งปัญญานั้นได้ เธอแผดร้องด้วยความเจ็บปวดและถอยร่นไปในมุมมืดของถ้ำ จารุใช้โอกาสนี้วิ่งออกจากถ้ำอย่างสุดชีวิต แสงสว่างนำทางเขาออกจากกับดักแห่งความหลงใหลนั้นไปสู่ป่าภายนอก

Page 12/12

จารุกลับมาหาอาจารย์สุเมธด้วยความนอบน้อม เขาได้เรียนรู้แล้วว่าความงามที่เปลือกนอกนั้นหลอกลวงได้ แต่ความงดงามแห่งปัญญาจะคุ้มครองเราเสมอ จากวันนั้นเป็นต้นมา จารุกลายเป็นคนใหม่ที่มองเห็นคุณค่าของจิตใจมากกว่ารูปกายภายนอก
