รากเหง้าแห่งปัญญา: บทเรียนแห่งความอ่อนน้อม

By wolf tbmx

Page 1/12

นานมาแล้ว ณ ดินแดนชมพูทวีปอันรุ่งโรจน์ มีพราหมณ์หนุ่มผู้หนึ่งนามว่า ภารทวาชะ เขาเป็นผู้ที่เฉลียวฉลาดอย่างยิ่ง ภารทวาชะใช้เวลาทั้งชีวิตศึกษาคัมภีร์พระเวทจนแตกฉาน จนเขามั่นใจว่าไม่มีความรู้ใดในโลกที่เขาไม่ล่วงรู้

Page 2/12

ภารทวาชะมีเพื่อนสนิทนามว่า กัสสปะ ทั้งสองมักจะสนทนาธรรมและถกเถียงปัญหาปรัชญาที่ลึกซึ้งอยู่เสมอ "กัสสปะเอ๋ย ข้าได้เรียนรู้ทุกสรรพสิ่งแล้ว ไม่มีสิ่งใดที่ข้าจะทำความเข้าใจไม่ได้อีก" ภารทวาชะกล่าวด้วยความลำพองใจ

Page 3/12

ต่อมา ทั้งสองได้ยินกิตติศัพท์ของพระพุทธเจ้า ผู้ทรงเป็นศาสดาเอกของโลก พวกเขาจึงตัดสินใจเข้าสู่ร่มกาสาวพัสตร์ บวชเป็นภิกษุในพระพุทธศาสนา แม้จะครองเพศบรรพชิต แต่ในใจของภารทวาชะยังคงเต็มไปด้วยความทิฐิ

Page 4/12

เมื่อได้ฟังธรรมจากพระพุทธองค์เพียงไม่กี่ครั้ง ภารทวาชะก็นึกในใจว่า "สิ่งที่พระองค์สอน ข้าก็รู้อยู่แล้ว ความรู้ของพระพุทธเจ้าก็ไม่ต่างจากความรู้ที่ข้ามีเลย" เขาเริ่มมองข้ามคำสั่งสอนและไม่ตั้งใจปฏิบัติอย่างแท้จริง

Page 5/12

พระพุทธองค์ทรงทราบด้วยพระญาณว่าภารทวาชะและเพื่อนพราหมณ์อีกหลายรูป กำลังถูกไฟแห่งความหลงผิดแผดเผาใจ พวกเขาคิดว่าตนเองหยั่งถึง "รากเหง้า" ของธรรมะแล้ว ทั้งที่ความจริงยังติดอยู่เพียงเปลือกนอก

Page 6/12

วันหนึ่ง พระพุทธองค์ทรงเรียกประชุมสงฆ์ที่ป่าเลย์ยา ภารทวาชะและกัสสปะเดินมาสมทบด้วยความมั่นใจ "วันนี้เราจะได้ฟังสิ่งที่เรารู้อยู่แล้วอีกหรือเปล่านะ" กัสสปะกระซิบถามเพื่อน

Page 7/12

พระพุทธองค์ทรงเริ่มแสดง "มูลปริยายสูตร" หรือพระสูตรว่าด้วยรากเหง้าแห่งสรรพสิ่ง ทรงตรัสถามถึงความเข้าใจเกี่ยวกับ ดิน น้ำ ไฟ ลม และธรรมะในระดับต่างๆ ที่ลึกซึ้งเกินกว่าที่ตำราใดจะเคยจารึกไว้

Page 8/12

เมื่อพระพุทธองค์ทรงจำแนกความรู้สภาวะของปุถุชน พระเสขะ และพระอรหันต์ ภารทวาชะก็เริ่มเหงื่อซึม เขาพบว่าคำถามที่พระองค์ทรงถามนั้น ตัวเขาไม่สามารถตอบได้เลยแม้แต่ข้อเดียว ความมั่นใจที่เคยมีเริ่มพังทลาย

Page 9/12

พระพุทธองค์ทรงสอนว่า "ผู้ที่ยึดติดในความรู้ว่า 'สิ่งนี้เป็นของเรา' หรือ 'เราเป็นสิ่งนี้' ย่อมไม่อาจเข้าถึงความจริงที่แท้จริงได้" ภารทวาชะตั้งใจฟังทุกถ้อยคำ ราวกับน้ำทิพย์ที่รดลงบนดินที่แห้งผาก

Page 10/12

กัสสปะเองก็ตระหนักได้ว่า ความรู้ที่เขาเคยสะสมมานั้นเป็นเพียงเศษเสี้ยวของมหาสมุทรแห่งปัญญา เขาละทิ้งทิฐิมานะ และก้มลงกราบแทบพระบาทด้วยความซาบซึ้งในพระมหากรุณาธิคุณ

Page 11/12

ภารทวาชะได้เข้าเฝ้าพระพุทธองค์และทูลสารภาพผิด "ข้าพระองค์โง่เขลาที่หลงผิดคิดว่าตนรู้แจ้ง วันนี้ข้าพระองค์ขอวางมานะทิฐิลง และขอเริ่มต้นศึกษาธรรมที่แท้จริงจากพระองค์" พระพุทธองค์ทรงยิ้มด้วยความเมตตา

Page 12/12

จากวันนั้น ภารทวาชะและเหล่าพราหมณ์กลายเป็นภิกษุที่เคร่งครัดและอ่อนน้อม พวกเขาเข้าใจแล้วว่า รากเหง้าที่แท้จริงของปัญญาไม่ได้มาจากตำรา แต่มาจากการละวางตัวตนและการเปิดใจรับความจริงอันยิ่งใหญ่
