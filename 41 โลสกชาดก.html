วิบากกรรมของพระโลสกะ: บทเรียนแห่งความริษยา

By wolf tbmx

Page 1/12

นานมาแล้วในสมัยพุทธกาล มีพระภิกษุรูปหนึ่งนามว่า "โลสกะ" ท่านเป็นผู้ที่มีความเพียรในการปฏิบัติธรรมอย่างมาก แต่ทว่าท่านกลับเป็นผู้ที่มีโชคน้อยกว่าใครเพื่อน ไม่ว่าท่านจะไปบิณฑบาตที่ไหน ท่านมักจะได้อาหารเพียงน้อยนิดจนแทบไม่พออิ่มท้องเสมอ เพื่อนภิกษุต่างสงสัยว่าเหตุใดพระผู้ปฏิบัติดีเช่นนี้จึงต้องเผชิญกับความหิวโหยอยู่เป็นนิจ

Page 2/12

เรื่องราวทั้งหมดเริ่มต้นขึ้นจากอดีตชาติอันไกลโพ้น ในยุคของพระกัสสปพุทธเจ้า โลสกะเคยเกิดเป็นภิกษุผู้ดูแลอารามแห่งหนึ่งนามว่า "สุมนะ" ท่านอาศัยอยู่ในวัดที่สุขสบายและได้รับการอุปัฏฐากจากชาวบ้านอย่างดี จนกระทั่งวันหนึ่งมีพระเถระผู้ทรงธรรมรูปหนึ่งจาริกมาพักที่วัดแห่งนั้น

Page 3/12

พระเถระผู้มาเยือนนามว่า "ภารทวาชะ" ท่านเป็นพระอรหันต์ผู้มีกิริยาที่สงบและน่าเลื่อมใส เมื่อชาวบ้านเห็นพระภารทวาชะ พวกเขาต่างพากันมากราบไหว้และเตรียมภัตตาหารชั้นเลิศมาถวายด้วยความศรัทธา ทำให้พระสุมนะเริ่มรู้สึกไม่พอใจที่ความสำคัญของตนลดน้อยลง

Page 4/12

ความริษยาเริ่มกัดกินหัวใจของพระสุมนะ ท่านเกรงว่าชาวบ้านจะเลิกใส่ใจท่านและไปเลื่อมใสพระผู้มาใหม่แทน "ถ้าพระรูปนี้ยังอยู่ที่นี่ต่อไป ลาภสักการะของเราคงต้องหมดสิ้นไปแน่ๆ" ท่านคิดในใจขณะเฝ้ามองชาวบ้านจัดเตรียมสำรับอาหารอันประณีตเพื่อถวายพระภารทวาชะในเช้าวันรุ่งขึ้น

Page 5/12

เมื่อถึงเวลาเช้า พระสุมนะแกล้งทำเป็นเคาะระฆังเบาๆ เพื่อไม่ให้พระภารทวาชะได้ยิน จากนั้นท่านก็รีบนำอาหารที่ชาวบ้านเตรียมไว้ไปทิ้งลงในกองไฟที่ยังคุกรุ่นอยู่ ท่านหวังจะให้พระผู้มาเยือนไม่มีอาหารฉันและต้องจากวัดนี้ไปในที่สุด ด้วยวิบากกรรมนี้เองที่ติดตามท่านไปทุกภพทุกชาติ

Page 6/12

หลังจากสิ้นอายุขัย พระสุมนะต้องไปชดใช้กรรมในนรกยาวนาน จนกระทั่งมาเกิดเป็นมนุษย์ในหมู่บ้านชาวประมงที่ยากจน ท่านเกิดมาพร้อมกับความหิวโหย ตั้งแต่วันที่ท่านเกิดมา คนในหมู่บ้านก็หาปลาไม่ได้เลย ฝนไม่ตกต้องตามฤดูกาล และความแห้งแล้งก็เข้าปกคลุมหมู่บ้านแห่งนั้น

Page 7/12

หัวหน้าหมู่บ้านเชื่อว่ามีเด็กกาลกิณีเกิดมาในหมู่บ้าน จึงทำการเสี่ยงทายจนพบว่าเป็นครอบครัวของโลสกะ พ่อแม่ของท่านถูกบีบบังคับให้พาท่านออกจากหมู่บ้านไป โลสกะต้องเร่ร่อนไปตามลำพัง อาศัยเศษอาหารเพียงเล็กน้อยประทังชีวิตไปวันๆ ราวกับถูกสาปไม่ให้เคยอิ่มท้อง

Page 8/12

แม้จะมีความทุกข์ยากเพียงใด แต่ในใจของโลสกะยังคงมีบุญเก่าหนุนนำ ท่านได้พบกับพระสารีบุตรเถระ อัครสาวกเบื้องขวาของพระพุทธเจ้า พระสารีบุตรผู้เปี่ยมด้วยเมตตาเห็นเด็กน้อยผู้น่าสงสารจึงนำท่านมาอุปสมบทเป็นพระภิกษุในพระพุทธศาสนา

Page 9/12

ถึงแม้จะเป็นพระภิกษุแล้ว กรรมเก่าจากการทิ้งอาหารก็ยังตามมาหลอนหลอน เวลาพระโลสกะออกบิณฑบาต อาหารที่คนตั้งใจจะใส่บาตรให้มักจะหายไป หรือบาตรของท่านจะดูเหมือนเต็มไปด้วยอาหารทั้งที่จริงๆ แล้วว่างเปล่า ทำให้ท่านได้รับอาหารเพียงเล็กน้อยแค่พอประทังชีวิตเท่านั้น

Page 10/12

วันหนึ่ง พระสารีบุตรทราบว่าพระโลสกะใกล้จะสิ้นอายุขัยแล้ว ท่านปรารถนาจะให้ลูกศิษย์ได้ฉันอิ่มเป็นมื้อสุดท้าย ท่านจึงนำอาหารประณีตที่ได้รับมาไปส่งให้พระโลสกะ แต่พอยื่นให้ อาหารในบาตรกลับอันตรธานหายไปต่อหน้าต่อตาด้วยอำนาจแห่งกรรม

Page 11/12

พระสารีบุตรจึงใช้วิธีสุดท้าย ท่านถือบาตรนั้นไว้ด้วยมือของท่านเอง แล้วบอกให้พระโลสกะฉันอาหารจากบาตรในขณะที่ท่านยังจับอยู่ ด้วยบารมีของพระอัครสาวกทำให้กรรมนั้นทำอะไรไม่ได้ พระโลสกะจึงได้ฉันอาหารจนอิ่มหนำเป็นครั้งแรกและครั้งสุดท้ายในชีวิตของท่าน

Page 12/12

หลังจากฉันอาหารอิ่มแล้ว พระโลสกะได้พิจารณาธรรมและบรรลุเป็นพระอรหันต์ ก่อนจะดับขันธปรินิพพานในวันนั้นเอง เรื่องราวของท่านเป็นบทเรียนสอนใจชาวพุทธเสมอมาว่า "ความริษยาและการขัดขวางลาภผู้อื่น เป็นเหตุแห่งความเสื่อมและดวงตาที่มืดบอด"
