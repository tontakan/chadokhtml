วิมลนกกระทาผู้ใฝ่ธรรม: บทเรียนเรื่องเจตนา

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในป่าหิมพานต์อันกว้างใหญ่ มีนกกระทาตัวหนึ่งชื่อว่า "วิมล" เขามีขนที่สวยงามเป็นลวดลายประณีตและมีจิตใจที่ใฝ่ในธรรม วิมลใช้ชีวิตอย่างสงบสุข ท่ามกลางแมกไม้ที่เขียวขจีและสายน้ำที่ไหลเย็น เขาหมั่นสำรวมระวังระกายวาจาใจอยู่เสมอเพื่อไม่ให้เบียดเบียนผู้ใด

Page 2/12

อยู่มาวันหนึ่ง วิมลถูกพรานป่าใจร้ายที่ชื่อ "ลุททะ" จับตัวไป ลุททะไม่ได้จับวิมลไปเพื่อเป็นอาหาร แต่เขานำวิมลไปขังไว้ในกรงเพื่อใช้เป็น "นกต่อ" สำหรับล่อให้นกกระทาตัวอื่นๆ บินเข้ามาหา เพื่อที่ลุททะจะได้ทอดแหจับนกเหล่านั้นไปขายและฆ่ากิน

Page 3/12

ทุกครั้งที่ลุททะพาวิมลเข้าป่า เขาจะกระตุ้นให้วิมลส่งเสียงร้อง เมื่อเพื่อนนกกระทาตัวอื่นๆ ได้ยินเสียงร้องของวิมล พวกมันก็คิดว่าเป็นเสียงเรียกของเพื่อนจึงพากันบินเข้ามาหา ทันใดนั้น ลุททะก็จะทอดแหจับนกเหล่านั้นไปต่อหน้าต่อตาวิมล

Page 4/12

วิมลรู้สึกทุกข์ระทมใจเป็นอย่างยิ่ง เขามีความกังวลว่าการที่เขาส่งเสียงร้องจนทำให้นกตัวอื่นๆ ถูกจับนั้น จะถือว่าเป็นบาปหรือไม่ "เราไม่ได้อยากให้เพื่อนๆ ถูกจับเลย แต่เพราะเสียงของเรา พวกเขาจึงต้องเดือดร้อน" วิมลเฝ้าถามตัวเองด้วยความรู้สึกผิด

Page 5/12

วันเวลาผ่านไป วิมลตัดสินใจว่าเขาจะต้องหาคำตอบให้ได้ว่าสิ่งที่เกิดขึ้นนั้นเป็นบาปสำหรับเขาหรือไม่ เขาเฝ้ารอโอกาสที่จะได้พบกับผู้ทรงความรู้ จนกระทั่งวันหนึ่ง ลุททะพาวิมลไปวางไว้ใกล้กับอาศรมของดาบสผู้บำเพ็ญตบะในป่า

Page 6/12

ที่อาศรมนั้นมีพระดาบสนามว่า "อิสิละ" ท่านเป็นบัณฑิตผู้มีความเมตตาและรอบรู้ในข้อธรรมอย่างลึกซึ้ง วิมลเห็นว่าเป็นโอกาสดี จึงตัดสินใจเอ่ยปากถามพระดาบสเมื่อลุททะเผลอหลับไปใต้ต้นไม้ใกล้ๆ

Page 7/12

วิมลถามด้วยความนอบน้อมว่า "ข้าแต่ท่านผู้เจริญ ข้าพเจ้าต้องส่งเสียงร้องตามหน้าที่ แต่เสียงนั้นทำให้เพื่อนนกของข้าพเจ้าต้องพินาศ การกระทำของข้าพเจ้านี้ถือเป็นบาปหรือไม่? จิตของข้าพเจ้าเร่าร้อนเหลือเกิน"

Page 8/12

อิสิละนิ่งฟังด้วยความเมตตาแล้วจึงกล่าวตอบว่า "ดูก่อนนกกระทาผู้มีใจบริสุทธิ์ บาปและบุญนั้นสำคัญอยู่ที่ 'เจตนา' หากใจของท่านไม่ได้มีความปรารถนาจะให้ผู้อื่นเดือดร้อน บาปย่อมไม่แปดเปื้อนถึงท่าน"

Page 9/12

"เหมือนกับน้ำที่กลิ้งอยู่บนใบบัว ย่อมไม่ติดใบบัวฉันใด" อิสิละอธิบายต่อ "หากใจของท่านไม่ยินดีในการจับนกของพราน และท่านไม่ได้มีจิตมุ่งร้ายต่อเพื่อนของท่าน การกระทำนั้นก็เป็นเพียงกิริยาที่เกิดจากความจำเป็น ไม่ใช่บาปกรรมที่จะติดตามท่านไป"

Page 10/12

วิมลถามต่อด้วยความสงสัยว่า "แล้วพรานลุททะล่ะท่าน? เขาจับนกเพื่อเลี้ยงชีพ เขาจะบาปหรือไม่?" อิสิละตอบว่า "พรานมีเจตนาเบียดเบียนชีวิตผู้อื่นเพื่อประโยชน์ส่วนตน จิตของเขามีความละโมบและมุ่งร้าย บาปนั้นย่อมตกอยู่กับเขาผู้มีเจตนา"

Page 11/12

"จำไว้เถิดวิมล" อิสิละย้ำ "เมื่อใดที่ใจสะอาด เจตนาก็จะบริสุทธิ์ เมื่อเจตนาบริสุทธิ์ การกระทำนั้นก็ไม่นำมาซึ่งความทุกข์ใจ จงรักษาจิตของท่านให้มั่นคงในเมตตา และอย่าได้กังวลในสิ่งที่ท่านไม่ได้ตั้งใจให้เกิดขึ้นเลย"

Page 12/12

เมื่อวิมลได้ฟังคำสอนของอิสิละ ใจที่เคยเร่าร้อนก็กลับสงบเย็นเหมือนได้อาบน้ำทิพย์ เขาขอบคุณพระดาบสและใช้ชีวิตนกต่ออย่างสำรวมระวัง โดยมีเจตนาที่บริสุทธิ์และแผ่เมตตาให้แก่ทุกชีวิตเสมอมา
