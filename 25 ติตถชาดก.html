ติตถชาดก: บทเรียนแห่งความภาคภูมิของพญาเมฆ

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งในนครพาราณสี พระเจ้าพรหมทัตทรงมีม้าศึกคู่พระทัยนามว่า "สินธพ" ซึ่งเป็นม้าสายพันธุ์ดี สง่างาม และเปี่ยมด้วยความกล้าหาญเหนือม้าใดในแผ่นดิน สินธพไม่เพียงแต่เป็นกำลังหลักในการศึก แต่ยังเป็นสัญลักษณ์แห่งเกียรติยศของราชสำนักด้วย

Page 2/12

ทุกๆ วัน นายควาญม้านามว่า "เมฆิยะ" จะเป็นผู้ดูแลพาสินธพไปอาบน้ำและดื่มกินที่ท่าประจำในแม่น้ำคงคา เมฆิยะดูแลสินธพด้วยความประณีต ราวกับดูแลอัญมณีล้ำค่าของอาณาจักร

Page 3/12

ในเช้าวันหนึ่ง ก่อนที่สินธพจะมาถึง มีม้าแก่รูปร่างผอมโซและสกปรกนามว่า "ขลุงกะ" ถูกคนดูแลม้าชั้นเลวพามารออาบน้ำที่ท่าเดียวกับที่ม้าศึกหลวงใช้ประจำ ขลุงกะลงไปแช่น้ำจนโคลนตมและคราบสกปรกกระจายไปทั่วบริเวณ

Page 4/12

เมื่อเมฆิยะพาสินธพมาถึงท่าพิทักษ์น้ำ สินธพหยุดชะงักทันทีที่เห็นขลุงกะกำลังอาบน้ำอยู่ ม้าศึกผู้สง่างามเชิดหน้าขึ้นและพ่นลมหายใจอย่างแรง ดวงตาของเขาฉายแววไม่พอใจอย่างเห็นได้ชัด

Page 5/12

หลังจากม้าขลุงกะจากไป เมฆิยะพยายามจูงสินธพลงไปที่ท่าน้ำเพื่อให้มันดื่มน้ำที่ใสสะอาดขึ้น แต่สินธพกลับถอยหนีและไม่ยอมก้มลงแตะต้องผิวน้ำนั้นเลยแม้แต่หยดเดียว เขาเพียงแต่มองดูสายน้ำด้วยความรังเกียจ

Page 6/12

เมฆิยะพยายามอยู่เนิ่นนานแต่ก็ไม่สำเร็จ เขาจึงรีบกลับไปยังพระราชวังเพื่อกราบทูลพระเจ้าพรหมทัตด้วยความกังวลใจว่า ม้าศึกคู่พระทัยอาจจะล้มป่วยหรือมีอาการผิดปกติบางอย่าง

Page 7/12

พระเจ้าพรหมทัตทรงเรียก "สุมะธะ" อำมาตย์ผู้ปรีชาและเป็นโพธิสัตว์ให้เข้าพบ เพื่อให้ไปตรวจดูอาการของสินธพ สุมะธะผู้มีความเข้าใจในจิตใจของทั้งคนและสัตว์จึงรับอาสาไปดูที่ท่าน้ำนั้น

Page 8/12

เมื่อสุมะธะมาถึงริมแม่น้ำ เขาไม่ได้เข้าไปบังคับม้า แต่กลับเดินสำรวจรอบๆ ท่าพิทักษ์น้ำและสังเกตท่าทางของสินธพอย่างละเอียด เขาเห็นสินธพยังคงยืนตัวตรงและมองไปยังที่ที่ม้าขลุงกะเคยอยู่

Page 9/12

สุมะธะเดินเข้าไปใกล้สินธพและมองสบตากับม้าศึก เขาเข้าใจทันทีว่านี่ไม่ใช่ความเจ็บป่วยทางกาย แต่เป็นความทระนงในศักดิ์ศรี สินธพรู้สึกว่าท่าพิทักษ์น้ำนี้แปดเปื้อนเพราะม้าที่สกปรกได้มาใช้ก่อนหน้า

Page 10/12

สุมะธะหันไปบอกเมฆิยะว่า "ม้าศึกผู้สูงศักดิ์นี้เปรียบเสมือนนักรบผู้รักความสะอาด เขาจะไม่ยอมใช้สิ่งของร่วมกับผู้ที่ไร้วินัย จงพามันไปที่ท่าอื่นเถิด"

Page 11/12

เมฆิยะทำตามคำแนะนำ เขาพาสินธพไปยังต้นน้ำที่ยังไม่มีม้าตัวใดไปเหยียบย่ำ ทันทีที่เห็นสายน้ำที่ใสสะอาดบริสุทธิ์และเงียบสงบ สินธพก็ก้มลงดื่มน้ำอย่างกระหายและสง่างาม

Page 12/12

พระเจ้าพรหมทัตทรงชื่นชมในปัญญาของสุมะธะ และทรงเข้าใจว่าแม้แต่สัตว์ก็ยังมีเกียรติยศที่ต้องรักษา ตั้งแต่นั้นมา สินธพก็กลับมาแข็งแกร่งและนำชัยชนะมาสู่พระนครสืบไป
