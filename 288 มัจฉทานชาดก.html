อนันต์กับวิมล และของขวัญจากพญานาค

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว มีพี่น้องสองคนชื่อ อนันต์ และ วิมล ทั้งคู่กำลังเดินทางไกลเพื่อไปค้าขายในเมืองใหญ่ อนันต์ผู้เป็นพี่ชายเป็นคนมีจิตใจเมตตา ส่วนวิมลผู้เป็นน้องชายมักจะกังวลเรื่องข้าวของและเงินทองอยู่เสมอ พวกเขาเดินลัดเลาะไปตามริมฝั่งแม่น้ำคงคาที่ไหลเย็น

Page 2/12

เมื่อถึงเวลาพัก อนันต์นำข้าวสุกที่เตรียมไว้ส่วนหนึ่งออกมา เขาไม่ได้กินเองทั้งหมด แต่กลับโปรยทานให้แก่ฝูงปลาในแม่น้ำ "มาเถิดเหล่านกและปลาทั้งหลาย กินให้อิ่มเถิด" อนันต์กล่าวด้วยรอยยิ้ม ขณะที่ปลานับร้อยพากันฮุบกินอาหารอย่างร่าเริง

Page 3/12

หลังจากให้อาหารปลาแล้ว อนันต์ได้หลับตาลงและตั้งจิตอธิษฐาน "ขอส่วนบุญส่วนกุศลจากการให้อาหารปลานี้จงสำเร็จแก่เหล่าเทวดาและพญานาคที่ดูแลแม่น้ำแห่งนี้ด้วยเถิด" เขาแบ่งปันความดีที่ทำส่งต่อไปยังผู้ที่มองไม่เห็นด้วยใจที่บริสุทธิ์

Page 4/12

ลึกลงไปใต้บาดาล พญานาคภะนี ผู้ครองวังวารีได้รับกระแสแห่งบุญนั้น ท่านรู้สึกถึงความสุขและความสว่างไสวที่แผ่ซ่านเข้ามา "ช่างเป็นมนุษย์ที่มีใจประเสริฐยิ่งนัก" พญานาคภะนีรำพึงด้วยความเลื่อมใสในไมตรีจิตของอนันต์

Page 5/12

ฝ่ายวิมลเมื่อเห็นพี่ชายทำเช่นนั้นก็ขมวดคิ้ว "พี่ท่าน ท่านช่างสิ้นเปลืองข้าวนัก เราต้องเดินทางอีกไกล เก็บไว้กินเองไม่ดีกว่าหรือ" วิมลบ่นพึมพำและกอดถุงเงินทองของเขาไว้แน่น ไม่ยอมแบ่งปันสิ่งใดให้ใครเลย

Page 6/12

ในขณะที่สองพี่น้องกำลังพักผ่อนอยู่นั้น โจรตัสกรที่แอบซุ่มอยู่หลังพุ่มไม้ก็ย่องเข้ามาเงียบๆ โจรตัสกรจ้องมองถุงเงินในมือของวิมลด้วยสายตาหิวกระหาย เขาฉวยจังหวะที่วิมลเผลอเข้ามายื้อแย่งถุงเงินนั้นทันที

Page 7/12

ด้วยแรงยื้อยุด ถุงเงินหลุดจากมือแล้วตกลงไปในแม่น้ำคงคาที่ไหลเชี่ยว โจรตัสกรเห็นท่าไม่ดีจึงรีบวิ่งหนีหายเข้าไปในป่า ทิ้งให้วิมลร้องไห้เสียดายเงินทองที่จมหายไปในกระแสน้ำลึก "เงินของเรา! หมดสิ้นกันแล้ว!" วิมลคร่ำครวญ

Page 8/12

พญานาคภะนีซึ่งเฝ้าดูอยู่ใต้พรายน้ำ เห็นเหตุการณ์ทั้งหมดจึงแปลงกายเป็นปลาตัวใหญ่ แหวกว่ายไปคาบถุงเงินนั้นไว้ก่อนที่จะถูกทรายทับถม ท่านจำได้ว่านี่คือถุงเงินของชายผู้แบ่งปันบุญให้แก่ท่าน

Page 9/12

อนันต์เดินเข้ามาปลอบใจน้องชาย "น้องข้า เงินทองเป็นของนอกกาย อย่าได้เศร้าโศกไปเลย เรายังมีชีวิตอยู่ก็สร้างมันขึ้นใหม่ได้" แม้อิมันจะเสียดายแต่มองเห็นความสงบในดวงตาของพี่ชาย เขาก็เริ่มสงบใจลง

Page 10/12

ทันใดนั้น ผิวน้ำก็เกิดประกายรุ้ง พญานาคภะนีในร่างมนุษย์ผู้สง่างาม สวมศิราภรณ์ทองคำ เดินขึ้นมาจากแม่น้ำ ในมือของท่านถือถุงเงินที่เปียกโชกส่งคืนให้แก่อนันต์ "ข้าขอมอบสิ่งนี้คืนแก่เจ้า ผู้มีใจอารี"

Page 11/12

"เพราะเจ้าแบ่งปันอาหารแก่ปลา และแบ่งปันบุญกุศลแก่ข้า บุญนั้นจึงคุ้มครองเจ้าให้พ้นภัย" พญานาคภะนีกล่าว วิมลได้ยินดังนั้นก็นิ่งอึ้ง เขาเข้าใจแล้วว่า การแบ่งปันไม่ได้ทำให้สิ่งใดลดน้อยลงเลย แต่กลับนำมาซึ่งความปลอดภัยและมิตรภาพ

Page 12/12

ตั้งแต่นั้นมา ทุกครั้งที่เดินทางผ่านแหล่งน้ำ อนันต์และวิมลจะร่วมใจกันให้อาหารปลาและแบ่งปันบุญให้แก่สรรพสัตว์เสมอ พวกเขาเดินทางถึงจุดหมายอย่างปลอดภัย พร้อมกับหัวใจที่เต็มเปี่ยมไปด้วยความสุขจากการเป็นผู้ให้
