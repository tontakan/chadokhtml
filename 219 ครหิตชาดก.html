วานรินกับบทเรียนแห่งความโลภ

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในป่าอันกว้างใหญ่เขียวขจี มีลิงตัวหนึ่งชื่อ "วานริน" เขาเคยถูกมนุษย์จับไปเลี้ยงไว้ในวังเป็นเวลานาน บัดนี้วานรินได้รับอิสรภาพแล้ว เขากระโดดลงจากเกวียนของพ่อค้าที่มาปล่อยเขาไว้ที่ชายป่า ด้วยความรู้สึกที่เต็มไปด้วยความสุขและโล่งใจ

Page 2/12

เมื่อวานรินกลับเข้าสู่ใจกลางป่า เพื่อนลิงทั้งหลายต่างพากันตื่นเต้น "อรัณย์" ลิงผู้อาวุโสที่เป็นผู้นำฝูง รีบเข้ามาทักทายวานรินด้วยความดีใจ อรัณย์ถามถึงชีวิตในเมืองมนุษย์ที่วานรินได้ไปเผชิญมาตลอดหลายปี

Page 3/12

ลิงตัวอื่นๆ เริ่มมารวมตัวกันเพื่อฟังเรื่องราว วานรินเริ่มเล่าด้วยน้ำเสียงที่เคร่งขรึม "เพื่อนเอ๋ย ชีวิตในเมืองมนุษย์นั้นช่างวุ่นวายนัก พวกเขามีสิ่งของมากมายแต่กลับไม่มีความสุขเลย" วานรินขยับมือท่าทางประกอบการเล่า

Page 4/12

วานรินย้อนความหลังให้ฟังว่า ในวังนั้น "พระเจ้าพรหมทัต" ทรงเมตตาเขามาก พระองค์มอบอาหารเลิศรสและถาดทองคำให้เขาใช้ แต่วานรินกลับสังเกตเห็นบางอย่างที่น่าเศร้าในดวงตาของมนุษย์เหล่านั้น

Page 5/12

"ในเมืองนั้น มนุษย์มักจะแก่งแย่งชิงดีกัน" วานรินเล่าต่อ เขาเห็นพระเจ้าพรหมทัตกำลังถกเถียงกับ "ธนัญ" เสนาบดีคนสนิท เรื่องภาษีและสมบัติพัสถาน ทั้งที่พวกเขามีทองคำกองเท่าภูเขา แต่ก็ยังอยากได้เพิ่มขึ้นอีก

Page 6/12

ไม่ใช่แค่คนรวยเท่านั้นที่โลภ แม้แต่ชาวบ้านอย่าง "ยศ" ที่เป็นคนรับใช้ในครัว ก็ยังแอบเถียงกับธนัญเรื่องส่วนแบ่งอาหารและเศษทองเล็กๆ น้อยๆ วานรินบอกว่ามนุษย์มักจะพูดคำว่า "ของฉัน" และ "ตัวฉัน" อยู่ตลอดเวลาจนเป็นกิจวัตร

Page 7/12

วานรินหันไปบอกอรัณย์ว่า "มนุษย์เหล่านั้นถูกจองจำด้วยกรงขังที่มองไม่เห็น นั่นคือความโลภ พวกเขาไม่เคยรู้จักคำว่าพอ" อรัณย์ฟังแล้วก็ได้แต่ถอนหายใจด้วยความสงสารมนุษย์เหล่านั้น

Page 8/12

"นิล" ลิงน้อยอีกตัวที่นั่งฟังอยู่ด้วย ขนลุกซู่เมื่อได้ยินเรื่องราวความวุ่นวาย อรัณย์จึงหันไปปลอบนิลว่า "ในป่าของเรา เรามีผลไม้สุกตามฤดูกาล มีน้ำดื่มสะอาดจากลำธาร เราแบ่งปันกันโดยไม่ต้องสะสม"

Page 9/12

วานรินสรุปบทเรียนว่า "ความทุกข์ของมนุษย์เกิดจากการยึดมั่นถือมั่น เมื่อได้มาก็กลัวเสียไป เมื่อยังไม่ได้ก็ดิ้นรนหามา ใจของพวกเขาจึงเหมือนไฟที่ไม่เคยดับ" เขาหลับตาลงนึกถึงภาพความโกลาหลในวัง

Page 10/12

"ข้าดีใจเหลือเกินที่ได้กลับมาสู่ป่าที่สงบสุขแห่งนี้" วานรินกล่าวพร้อมกับยิ้มให้นิล ลิงน้อยเริ่มเข้าใจแล้วว่าความสุขที่แท้จริงไม่ได้อยู่ในถาดทองคำ แต่อยู่ที่หัวใจที่รู้จักพอ

Page 11/12

อรัณย์กล่าวปิดท้ายว่า "ให้เรื่องของวานรินเป็นบทเตือนใจพวกเราทุกคน จงพอใจในสิ่งที่ตนมี และจงใช้ชีวิตอย่างเกื้อกูลกัน อย่าได้นำความโลภของมนุษย์มาเข้าสู่ป่าของเราเลย"

Page 12/12

แล้วฝูงลิงทั้งหมดก็ใช้ชีวิตอยู่ในป่าอย่างเป็นสุขสืบไป พวกเขาดูแลกันและกัน แบ่งปันอาหารและที่พำนัก โดยมีอรัณย์และนิลเป็นผู้นำพาความสงบสุขมาสู่เพื่อนพ้อง ลิงทุกตัวต่างระลึกถึงคำสอนของวานรินเสมอ
