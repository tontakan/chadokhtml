กปีชาดก: บทเรียนของลิงผู้โอหัง

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในป่าหิมพานต์อันกว้างใหญ่ ฤดูหนาวมาเยือนพร้อมลมพัดแรงจนยอดไม้สั่นไหว ฝูงลิงต่างพากันนั่งกอดเข่า ตัวสั่นงันงกด้วยความหนาวเหน็บ ชัญชลา ลิงหนุ่มผู้ร่าเริงพยายามหาทางทำให้เพื่อนๆ อุ่นขึ้น แต่ลมหนาวก็ยังคงกัดกินผิวหนังของพวกมันจนแทบจะทนไม่ไหว

Page 2/12

ชัญชลามองฝ่าความมืดออกไป และสังเกตเห็นแสงสว่างสีส้มเรืองรองออกมาจากถ้ำที่อยู่ไม่ไกลนัก "นั่นต้องเป็นไฟแน่ๆ!" เขาอุทานออกมาด้วยความดีใจ ความอบอุ่นที่เขาโหยหากำลังรออยู่ตรงนั้น ชัญชลาตัดสินใจมุ่งหน้าไปยังถ้ำเพียงลำพังเพื่อขอความช่วยเหลือ

Page 3/12

ภายในถ้ำนั้น ท่านมุนี ผู้ทรงศีลกำลังนั่งบำเพ็ญภาวนาอย่างสงบนิ่ง ข้างกายของท่านมีกองไฟเล็กๆ ที่ส่งเปลวเพลิงสีทองร่ายรำไปมา ความเงียบสงบและเมตตาธรรมแผ่ซ่านออกมาจากตัวท่านมุนี ราวกับว่าความหนาวเหน็บภายนอกไม่สามารถทำอะไรท่านได้เลย

Page 4/12

ชัญชลาคลานเข้าไปหาท่านมุนีด้วยท่าทางนอบน้อมผิดปกติ เขาพนมมือและทำหน้าตาเศร้าสร้อย "ท่านผู้เจริญ โปรดเมตตาพวกเราด้วยเถิด เพื่อนๆ ของข้าพเจ้ากำลังจะแข็งตายเพราะความหนาว ขอแบ่งปันไฟให้พวกเราสักนิดได้หรือไม่?" ชัญชลาแสร้งทำเป็นลิงที่สุภาพที่สุดในโลก

Page 5/12

ท่านมุนีลืมตาขึ้นช้าๆ และมองดูลิงน้อยด้วยความเอ็นดู ท่านรับรู้ถึงความหนาวเหน็บที่สัตว์น้อยใหญ่ต้องเผชิญ ท่านยิ้มด้วยความเมตตาและพร้อมที่จะแบ่งปันความอบอุ่นนี้โดยไม่หวังสิ่งตอบแทน เพราะท่านเชื่อว่าการช่วยเหลือผู้อื่นคือบุญกุศลอันยิ่งใหญ่

Page 6/12

ท่านมุนีใช้ไม้เขี่ยถ่านไฟที่ยังมีไฟลุกโชนยื่นให้แก่ชัญชลา "จงนำไฟนี้ไป และใช้มันอย่างระมัดระวังนะเจ้าลิงน้อย ความอบอุ่นนี้จะช่วยให้เจ้าและเพื่อนๆ ผ่านพ้นคืนที่โหดร้ายไปได้" ท่านมุนีกล่าวด้วยน้ำเสียงนุ่มนวล

Page 7/12

ชัญชลารีบนำถ่านไฟกลับไปหาฝูงลิง ทันทีที่ไฟถูกก่อขึ้น เพื่อนลิงคนสนิทของเขาก็เข้ามาล้อมวงรับความอบอุ่น "ดูสิ! ข้าไปเอาไฟมาจากนักบวชแก่คนนั้นได้ง่ายๆ เลย" ชัญชลาเริ่มโอ้อวด ท่าทางนอบน้อมเมื่อครู่หายไปสิ้น

Page 8/12

เมื่อร่างกายเริ่มอบอุ่น นิสัยเสียของชัญชลาก็เริ่มปรากฏ เขาเริ่มเต้นระบำรอบกองไฟและทำท่าทางล้อเลียนท่านมุนี "ดูข้าสิ ข้าฉลาดกว่านักบวชคนนั้นตั้งเยอะ แค่ทำหน้าเศร้าเขาก็เชื่อข้าแล้ว!" เขาหัวเราะร่าอย่างลำพองใจโดยไม่นึกถึงพระคุณ

Page 9/12

ชัญชลาเกิดความคิดพิเรนทร์ เขาเดินกลับไปที่ถ้ำของท่านมุนีอีกครั้ง แต่คราวนี้เขาไม่ได้ไปเพื่อขอบคุณ เขาเดินส่ายก้นไปมาและกระโดดขึ้นไปบนหินใกล้ๆ ที่ท่านมุนีนั่งอยู่ แล้วเริ่มทำเสียงเจี๊ยกจ๊ากก่อกวนสมาธิของท่าน

Page 10/12

ไม่เพียงเท่านั้น ชัญชลายังหยิบก้อนหินเล็กๆ ขว้างลงไปใกล้กองไฟของท่านมุนี และถ่มน้ำลายใส่เปลวไฟที่เคยให้ความอบอุ่นแก่เขา เขาแสดงกิริยาหยาบคายและดูหมิ่นถิ่นแคลนความใจดีที่ท่านมุนีมอบให้เพียงเพื่อความสนุกสนานชั่วครั้งชั่วคราว

Page 11/12

ท่านมุนีลืมตาขึ้นอีกครั้ง แต่คราวนี้ดวงตาของท่านเต็มไปด้วยความเด็ดขาด ท่านเห็นว่าลิงตัวนี้ไม่มีความกตัญญูและไม่รู้จักที่ต่ำที่สูง "เจ้าลิงผู้โง่เขลา ความเมตตาของข้ามีไว้สำหรับผู้ที่รู้จักคุณค่า เมื่อเจ้าไม่เคารพไฟและผู้ให้ เจ้าก็ไม่ควรได้รับมัน" ท่านมุนีใช้ไม้เท้าชี้ไปทางทางออกถ้ำ

Page 12/12

ชัญชลาถูกขับไล่ออกมาจากถ้ำและไม่มีใครยอมให้ไฟแก่เขาอีกเลย ลมหนาวกลับมาพัดแรงอีกครั้ง คราวนี้เขาต้องนั่งตัวสั่นอยู่เพียงลำพังใต้แสงจันทร์ เขาจึงได้รู้ซึ้งว่า ความอบอุ่นที่แท้จริงหายไปพร้อมกับความหยาบคายของเขานั่นเอง
