กัณฑินะชาดก: บทเรียนแห่งความลุ่มหลง

By wolf tbmx

Page 1/12

ในป่าหิมพานต์อันกว้างใหญ่ที่เต็มไปด้วยแมกไม้นานาพันธุ์ มีกวางหนุ่มตัวหนึ่งชื่อว่า "กัณฑินะ" เขามีเขาสวยงามเป็นสง่าและมีพละกำลังวังชา กัณฑินะใช้ชีวิตอย่างสงบสุขท่ามกลางฝูงกวางเพื่อนพ้องในป่าลึกที่ห่างไกลจากผู้คน

Page 2/12

วันหนึ่ง กัณฑินะได้พบกับแม่กวางสาวตัวหนึ่งชื่อ "ลลิตา" เธอมีดวงตากลมโตเป็นประกายและท่าทางเยื้องกรายที่ดูอ่อนหวาน กัณฑินะรู้สึกหลงรักลลิตาตั้งแต่แรกเห็น และไม่สามารถละสายตาจากเธอได้เลย

Page 3/12

ลลิตาเริ่มชักชวนให้กัณฑินะเดินตามเธอออกไปนอกเขตป่าที่เขาเคยอาศัยอยู่ แม้เพื่อนๆ ในฝูงจะร้องเตือนว่าชายป่าเป็นที่อันตรายและมีนายพรานคอยดักซุ่ม แต่อารมณ์รักและหลงทำให้กัณฑินะไม่ฟังคำทัดทานใดๆ

Page 4/12

บนต้นไม้ใหญ่ใกล้ทางเดิน มีรุกขเทวดานามว่า "วสุมนต์" สถิตอยู่ ท่านเฝ้ามองดูพฤติกรรมของกวางหนุ่มด้วยความห่วงใย วสุมนต์รับรู้ด้วยทิพยจักษุว่ามีอันตรายใหญ่หลวงรออยู่ข้างหน้าจากการที่กัณฑินะลุ่มหลงในตัวแม่กวางสาวจนขาดสติ

Page 5/12

ลลิตานำกัณฑินะเดินไปตามเส้นทางที่แคบลงเรื่อยๆ จนถึงบริเวณที่นายพรานได้ขุดหลุมพรางและขึงตาข่ายเอาไว้ เธอแสร้งทำเป็นเดินนำทางด้วยความร่าเริงเพื่อให้กัณฑินะตายใจและเดินตามเธอไปในจุดที่เสี่ยงอันตรายที่สุด

Page 6/12

ในพุ่มไม้หนาทึบไม่ไกลจากนั้น นายพราน "พยัคฆ์" กำลังหมอบซุ่มอยู่ด้วยความใจจดใจจ่อ เขาถือคันธนูไม้ที่ทำจากไม้เนื้อแข็งและเตรียมลูกศรที่อาบยาพิษไว้พร้อมสรรพ สายตาของเขาจ้องเขม็งไปที่กวางหนุ่มที่กำลังเดินเข้ามาใกล้

Page 7/12

เมื่อกัณฑินะเดินเข้ามาอยู่ในระยะยิง ลลิตาที่เห็นนายพรานซุ่มอยู่แล้วกลับแกล้งทำเป็นตกใจและวิ่งกระโดดหนีไปข้างหน้าอย่างรวดเร็ว ทิ้งให้กัณฑินะยืนอยู่เพียงลำพังท่ามกลางความว่างเปล่า กลายเป็นเป้านิ่งที่เห็นได้ชัดเจน

Page 8/12

นายพรานพยัคฆ์ไม่รอช้า เขาปล่อยลูกศรพุ่งออกจากคันธนูทันที ลูกศรแหวกอากาศพุ่งตรงไปยังกัณฑินะด้วยความเร็วและแม่นยำ

Page 9/12

ลูกศรปักเข้าที่กลางลำตัวของกัณฑินะอย่างจัง เขาพยายามจะวิ่งตามลลิตาไปแต่ก็สิ้นแรงล้มลงกับพื้น ลลิตาที่วิ่งนำไปก่อนหน้านั้นไม่ได้หันกลับมามองกัณฑินะเลยแม้แต่น้อย เธอหายเข้าไปในป่าลึกโดยไม่แยแสในชะตากรรมของเขา

Page 10/12

กัณฑินะนอนหายใจโรยรินอยู่บนพื้นดินที่เปื้อนเลือด เขาได้แต่เสียใจและเสียดายที่ตนเองหลงเชื่อคำล่อลวงของแม่กวางสาวจนต้องมาจบชีวิตลงเช่นนี้ เขาตระหนักได้ว่าความรักที่ปราศจากสติคือหนทางสู่ความหายนะ

Page 11/12

วสุมนต์รุกขเทวดาปรากฏกายขึ้นเบื้องหน้ากัณฑินะที่กำลังจะสิ้นใจ ท่านได้กล่าวให้โอวาทว่า "ดูก่อนกวางผู้ลุ่มหลง การคบหาบุคคลที่หวังเพียงประโยชน์ส่วนตนหรือนำพาเราไปในทางเสื่อม ย่อมนำมาซึ่งความทุกข์ระทมเช่นนี้เสมอ"

Page 12/12

เรื่องราวของกัณฑินะสอนให้เรารู้จักใช้สติพิจารณาในการเลือกคบมิตร และอย่าได้ปล่อยให้ความหลงครอบงำจิตใจจนมองไม่เห็นความจริงและความหวังดีของคนรอบข้าง ป่าหิมพานต์ยังคงงดงามต่อไป แต่บทเรียนนี้จะคงอยู่ตลอดกาล
