กาดำเจ้าเล่ห์กับบทเรียนแห่งสติ

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ณ ป่าชายหาดที่อุดมสมบูรณ์ ฝูงนกนับร้อยอาศัยอยู่ร่วมกันอย่างมีความสุข ภายใต้การดูแลของ "ธรรมิยะ" พญานกผู้เปี่ยมด้วยสติปัญญาและเมตตา ท่านมักจะเตือนบริวารเสมอว่า "ความประมาทเป็นหนทางแห่งอันตราย"

Page 2/12

วันหนึ่ง มีกาดำตัวหนึ่งชื่อว่า "คัณหะ" บินมายังชายหาดแห่งนี้ เขามีนิสัยเกียจคร้านและเจ้าเล่ห์ คัณหะเห็นฝูงนกอ้วนท้วนสมบูรณ์ก็เกิดความโลภ อยากจะจับกินเป็นอาหาร แต่รู้ดีว่าหากจู่โจมตรงๆ คงไม่สำเร็จ

Page 3/12

คัณหะเริ่มแผนการร้ายด้วยการแสร้งทำตัวเป็นนักบุญ เขายืนนิ่งบนขาทั้งสองข้างหันหน้าไปทางดวงอาทิตย์ อ้าปากค้างไว้ราวกับกำลังบำเพ็ญตบะอย่างเคร่งครัด ไม่ยอมขยับเขยื้อนไปไหนตลอดทั้งวัน

Page 4/12

นกน้อยชื่อ "ปีนะ" ผู้มีความรู้น้อยและมองโลกในแง่ดี บินมาเห็นท่าทางของกาดำเข้าก็เกิดความเลื่อมใส ปีนะค่อยๆ บินเข้าไปใกล้ด้วยความสงสัยว่ากาดำตัวนี้กำลังทำอะไรอยู่

Page 5/12

"ท่านผู้เจริญ เหตุใดท่านจึงต้องยืนอ้าปากสู้แสงแดดเช่นนี้หรือ?" ปีนะเอ่ยถาม คัณหะแสร้งตอบด้วยน้ำเสียงสั่นเครือว่า "เรากำลังกินลมเป็นอาหาร และที่ยืนสองขาเพื่อให้มั่นใจว่าเราจะไม่เหยียบย่ำมดแมลงบนพื้นดิน"

Page 6/12

ปีนะหลงเชื่อคำลวงจึงรีบไปบอกธรรมิยะและนกตัวอื่นๆ ว่ามีนักบุญผู้ยิ่งใหญ่มาเยือน ฝูงนกต่างพากันมาสรรเสริญคัณหะ และยอมอนุญาตให้เขาพักอยู่ใกล้ๆ รังนกของพวกตน

Page 7/12

เมื่อราตรีมาถึงและฝูงนกหลับใหล คัณหะก็เผยธาตุแท้ เขาแอบย่องไปยังท้ายฝูงแล้วจับนกที่หลับลึกกินทีละตัว จากนั้นก็กลับไปยืนท่าเดิมในตอนเช้า ทำเป็นนักบุญผู้เคร่งครัดเช่นเคย

Page 8/12

เวลาผ่านไปหลายวัน นกในฝูงเริ่มหายไปทีละตัว ธรรมิยะสังเกตเห็นความผิดปกติจึงเริ่มสงสัย เขาเรียกประชุมและเตือนให้ทุกคนมีสติ "จงอย่าเชื่อในสิ่งที่ตาเห็นเพียงภายนอก" ท่านกล่าวด้วยความกังวล

Page 9/12

ธรรมิยะตัดสินใจเฝ้าสังเกตพฤติกรรมของคัณหะอย่างใกล้ชิดในตอนกลางคืน เขาซ่อนตัวอยู่หลังพุ่มไม้หนา ในขณะที่คัณหะเริ่มขยับตัวออกจากท่าทางนักบุญเพื่อออกล่าเหยื่ออีกครั้ง

Page 10/12

ธรรมิยะบินไปสำรวจบริเวณโขดหินที่คัณหะพำนักอยู่ แล้วเขาก็ต้องตกใจเมื่อพบกองกระดูกและขนของนกที่หายไปซ่อนอยู่ซอกหิน ความจริงถูกเปิดเผยแล้วว่านักบุญผู้นี้คือพาลในคราบนักบุญ

Page 11/12

เมื่อแสงอรุณมาถึง ธรรมิยะประกาศความจริงต่อหน้าฝูงนก คัณหะตกใจจนลืมตัวพยายามจะบินหนี แต่ก็ถูกฝูงนกที่ตื่นตัวและมีสติล้อมจับเอาไว้ได้ทันท่วงที

Page 12/12

คัณหะถูกขับไล่ออกจากป่าไปตลอดกาล ฝูงนกกลับมาอยู่ร่วมกันอย่างปลอดภัย ธรรมิยะสอนปีนะและนกทุกตัวว่า "สติและการสังเกตจะช่วยให้เราพ้นจากคนพาลที่แสร้งทำเป็นคนดี"
