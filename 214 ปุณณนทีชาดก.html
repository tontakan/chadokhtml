ปุณณนทีชาดก: ลำน้ำแห่งน้ำใจและปัญญา

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ณ ดินแดนชมพูทวีปอันไกลโพ้น มีแม่น้ำสายใหญ่ชื่อว่า "ปุณณนที" ไหลผ่านหุบเขาและป่าลึก กระแสน้ำในฤดูฝนนั้นเชี่ยวกรากและน่าเกรงขามจนไม่มีใครกล้าข้ามไป แต่นักเดินทางผู้มีนามว่า "วสุ" ผู้เปี่ยมด้วยปัญญาและเมตตา กลับมีความตั้งใจมั่นที่จะข้ามไปยังฝั่งตรงข้ามเพื่อนำยามารักษาผู้คนในหมู่บ้านของเขา

Page 2/12

ที่ริมฝั่งแม่น้ำ วสุได้พบกับเด็กหนุ่มชื่อ "อรุณ" ผู้ซึ่งกำลังนั่งเศร้าสร้อยเพราะไม่สามารถข้ามแม่น้ำไปหาครอบครัวได้ อรุณมองดูกระแสน้ำด้วยความหวาดกลัว วสุเดินเข้าไปหาเด็กหนุ่มแล้ววางมือบนไหล่อย่างแผ่วเบา "อย่ากลัวไปเลยเจ้าหนุ่ม ความกลัวจะทำให้เรามองไม่เห็นหนทาง แต่ปัญญาจะเปิดประตูให้เราเสมอ" วสูกล่าวด้วยรอยยิ้ม

Page 3/12

ไม่ไกลกันนั้น มีชายชราผู้หนึ่งชื่อ "วฤทธา" กำลังพยายามยกท่อนไม้หนักๆ เพื่อจะนำมาสร้างแพ แต่อรุณเห็นว่าวฤทธาเริ่มหมดแรง เขาจึงรีบเข้าไปช่วยพยุงและช่วยยกท่อนไม้นั้น แม้ตนเองจะตัวเล็กกว่าแต่ความกตัญญูและน้ำใจทำให้เขามีกำลังมหาศาล "เราต้องช่วยกันนะท่านตา" อรุณบอกกับชายชรา

Page 4/12

วสุเริ่มลงมือออกแบบแพโดยใช้ปัญญาพิจารณาจากทิศทางลมและกระแสน้ำ เขาเรียกอรุณมาช่วยกันมัดหวายเข้ากับท่อนไม้ "การสร้างแพไม่ใช่แค่การเอาไม้มาวางรวมกัน" วสุสอน "แต่คือการร้อยเรียงความสามัคคีให้เป็นหนึ่งเดียว" เขาสอนให้อรุณรู้จักการผูกปมที่แน่นหนาและยืดหยุ่นไปตามคลื่น

Page 5/12

เมื่อวฤทธาเห็นทั้งคู่ทำงานหนัก เขาจึงสละไม้ส่วนที่เขาเก็บสะสมไว้มามอบให้วสุ "เอาไม้ของข้าไปเถิด เพื่อให้แพของพวกเจ้าแข็งแรงขึ้น" วสุรับไม้มาด้วยความเคารพ น้ำใจของชายชราทำให้หัวใจของทุกคนพองโต วสุและวฤทธาช่วยกันจัดวางไม้เหล่านั้นจนแพเริ่มเป็นรูปเป็นร่างที่แข็งแกร่งที่สุดเท่าที่เคยเห็นมา

Page 6/12

ในคืนนั้น ขณะที่วสุนอนหลับอยู่ริมฝั่ง "พญานาคราช" ผู้พิทักษ์แม่น้ำปุณณนทีได้ปรากฏกายขึ้นจากกระแสน้ำวน ร่างของท่านเปล่งประกายสีทองเจิดจ้าและมีเศียรแผ่พังพานงดงาม พญานาคราชจ้องมองมาที่วสุเพื่อทดสอบหัวใจของนักเดินทางผู้กล้าหาญคนนี้

Page 7/12

พญานาคราชเอ่ยถามวสุด้วยเสียงก้องกังวาน "เจ้าจะข้ามน้ำนี้ไปเพื่ออะไร หากเพื่อตัวเจ้าเอง ข้าจะจมแพของเจ้าเสีย" วสุตอบอย่างสงบว่า "ข้าข้ามไปเพื่อผู้อื่น ด้วยน้ำใจจากเพื่อนร่วมทางและปัญญาที่ข้ามี ข้าขออาราธนาความดีนี้เป็นเกราะป้องกัน" พญานาคราชได้ยินดังนั้นจึงคลายความโกรธลงและประทานพรให้

Page 8/12

เช้าวันรุ่งขึ้น แพเสร็จสมบูรณ์ วสุและอรุณช่วยกันพยุงวฤทธาขึ้นสู่แพที่มั่นคง "เตรียมตัวให้ดี" วสุกระซิบ "แม่น้ำจะทดสอบเรา แต่เรามีน้ำใจต่อกันเป็นเข็มทิศ" วสุยืนประจำที่ท้ายแพเพื่อคอยคัดท้าย ขณะที่อรุณช่วยดูทางน้ำข้างหน้าอย่างขะมักเขม้น

Page 9/12

กลางแม่น้ำ พายุพัดกระหน่ำและคลื่นยักษ์ซัดเข้าหาแพ อรุณหวาดกลัวจนตัวสั่น วฤทธาจึงเข้าไปกอดและปลอบโยนเด็กหนุ่ม "หลับตาเถิดเจ้าหนุ่ม เชื่อในน้ำใจที่เราสร้างมาด้วยกัน" วฤทธาใช้ร่างของตนเองกำบังลมหนาวให้แก่อรุณ ความอบอุ่นในใจทำให้อรุณหายหวาดกลัว

Page 10/12

วสุใช้ปัญญาพิจารณาคลื่นน้ำ เขาไม่ฝืนกระแสน้ำที่เชี่ยวที่สุด แต่ใช้วิธีพายเฉียงเพื่อให้แพไหลไปตามแรงน้ำอย่างมีจังหวะ อรุณเห็นความใจเย็นของวสุจึงลุกขึ้นมาช่วยส่งสัญญาณบอกทิศทาง "ทางซ้ายมีโขดหิน ทางขวาน้ำนิ่ง!" อรุณตะโกนบอกวสุด้วยความกล้าหาญ

Page 11/12

ในที่สุด แพก็ลอยเข้าสู่เขตน้ำนิ่ง และเข้าเทียบท่าฝั่งตรงข้ามได้อย่างปลอดภัย แสงอาทิตย์ยามเช้าสาดส่องลงมาที่ชายหาดทรายสีทอง วสุและอรุณก้าวลงจากแพด้วยความปิติยินดี "เราทำสำเร็จแล้ว" อรุณตะโกนด้วยความดีใจพร้อมกับชูแขนขึ้นสู่ท้องฟ้า

Page 12/12

วสุมองกลับไปที่แม่น้ำปุณณนที เขาเห็นพญานาคราชโผล่พ้นน้ำขึ้นมาสั้นๆ เพื่อเป็นการอำลา "น้ำใจคือแพที่ไม่มีวันจม และปัญญาคือพายที่ไม่มีวันหัก" วสูกล่าวสอนทุกคนที่ข้ามน้ำมาด้วยกัน ก่อนที่จะแยกย้ายกันไปทำหน้าที่ของตนเองในดินแดนแห่งความสงบสุขนี้
