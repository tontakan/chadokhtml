ปริศนาข้าวเดนแห่งเมืองพาราณสี

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งในนครพาราณสี มีพราหมณ์หนุ่มนามว่า "โสมะ" เขาเป็นคนขยันหมั่นเพียรและซื่อสัตย์ โสมะอาศัยอยู่ในเรือนหลังเล็กกับ "วิมลา" ภรรยาผู้มีรูปโฉมงดงาม ทั้งสองดูเหมือนจะเป็นคู่ครองที่น่าอิจฉาในสายตาเพื่อนบ้าน แต่ลึกๆ แล้วในใจของวิมลากลับซ่อนความลับบางอย่างไว้

Page 2/12

วันหนึ่งโสมะต้องออกไปทำงานต่างเมืองเป็นเวลานาน เขาจัดเตรียมข้าวของและร่ำลาภรรยาด้วยความรัก "ดูแลตัวเองให้ดีนะวิมลา ข้าจะรีบกลับมาพร้อมกับสินจ้างเพื่อชีวิตที่ดีของเรา" โสมะกล่าวพร้อมรอยยิ้ม ก่อนจะก้าวเดินลับตาไปตามเส้นทางที่คดเคี้ยว

Page 3/12

เมื่อสามีลับตาไป วิมลาก็เผยตัวตนที่แท้จริง เธอแอบคบหากับชายหนุ่มอีกคนนามว่า "กาละ" ผู้ซึ่งรอคอยโอกาสนี้อยู่แล้ว วิมลาเชื้อเชิญกาละเข้ามาในบ้าน ทั้งคู่ใช้เวลาอยู่ร่วมกันอย่างประมาท โดยคิดว่าโสมะจะไม่ออกเดินทางกลับมาอีกนาน

Page 4/12

ในทุกๆ วัน วิมลาจะจัดเตรียมสำรับอาหารอย่างดีที่สุดเพื่อเลี้ยงดูกาละ ทั้งข้าวสุกที่หุงอย่างประณีตและกับข้าวรสเลิศ พวกเขานั่งล้อมวงรับประทานอาหารกันอย่างมีความสุขภายในห้องหับที่มิดชิด โดยไม่เฉลียวใจเลยว่าโสมะกำลังเดินทางกลับมาก่อนกำหนด

Page 5/12

ทันใดนั้น เสียงเคาะประตูบ้านก็ดังขึ้น "วิมลา ข้ากลับมาแล้ว!" เสียงของโสมะดังมาจากด้านนอก ทั้งวิมลาและกาละต่างตกใจขวัญเสีย วิมลารีบกวาดสายตามองหาที่ซ่อน แล้วเธอก็ผลักกาละเข้าไปซ่อนในตะกร้าสานใบใหญ่ที่มุมห้อง พร้อมกับรีบจัดแจงเสื้อผ้าให้เรียบร้อย

Page 6/12

วิมลาเดินไปเปิดประตูด้วยใบหน้าที่พยายามทำเป็นปกติ "ท่านพี่ ทำไมกลับมาเร็วนักล่ะจ๊ะ?" เธอถามด้วยน้ำเสียงสั่นเครือเล็กน้อย โสมะเดินเข้ามาในบ้านด้วยความเหนื่อยล้า เขาไม่ได้สังเกตเห็นความผิดปกติในทันที แต่เขาสัมผัสได้ถึงกลิ่นอายของบางอย่างที่เปลี่ยนไป

Page 7/12

โสมะนั่งลงและมองไปที่ถาดอาหารที่วางอยู่กลางห้อง เขาเห็นข้าวสุกที่เหลืออยู่ในถาดเพียงครึ่งเดียว และร่องรอยของการรับประทานที่ดูไม่เป็นระเบียบ สายตาของเขาจ้องเขม็งไปที่ "เศษข้าวเดน" เหล่านั้น ซึ่งดูเหมือนจะมีคนเพิ่งจะลุกไปไม่นาน

Page 8/12

"วิมลา ข้าวในถาดนี้ดูเหมือนมีคนกินไปแล้วนะ" โสมะถามเสียงเรียบ วิมลารีบแก้ตัว "อ๋อ...นั่นคือข้าวที่ข้ากินเหลือไว้เองจ้ะท่านพี่ ข้าหิวมากจนทนไม่ไหว" เธอพยายามยิ้ม แต่หัวใจกลับเต้นรัวด้วยความกลัวว่าความลับจะถูกเปิดเผย

Page 9/12

โสมะเริ่มสังเกตเห็นความผิดปกติรอบตัว เขาเหลือบไปเห็นตะกร้าใบใหญ่ที่มุมห้องซึ่งดูเหมือนจะขยับได้เล็กน้อย เขาเดินเข้าไปใกล้ตะกร้าใบนั้นช้าๆ ในขณะที่วิมลาพยายามเดินเข้ามาขวางทางไว้

Page 10/12

ในขณะนั้น "ท่านบัณฑิต" ผู้รอบรู้ซึ่งเป็นเพื่อนบ้านและเป็นผู้ทรงศีลได้เดินผ่านมาเห็นเหตุการณ์พอดี ท่านบัณฑิตสัมผัสได้ถึงสถานการณ์ที่ตึงเครียด จึงก้าวเข้ามาในบ้านเพื่อช่วยคลี่คลายปัญหาด้วยสติปัญญา

Page 11/12

โสมะรู้ทันกลอุบาย เขาพูดเสียงดังเพื่อให้คนในตะกร้าได้ยิน "ข้าวเดนนี้บอกข้าได้ทุกอย่าง วิมลาเอ๋ย ความจริงนั้นซ่อนไม่ได้หรอก" ทันใดนั้น เขาก็เปิดฝาตะกร้าออก เผยให้เห็นกาละที่นั่งคุดคู้ตัวสั่นด้วยความอับอายต่อหน้าทุกคน

Page 12/12

ท่านบัณฑิตกล่าวสอนใจว่า "ความซื่อสัตย์คือรากฐานของชีวิตคู่ การหลอกลวงอาจซ่อนได้ชั่วคราว แต่ความจริงย่อมปรากฏในที่สุด" โสมะให้อภัยแต่เลือกที่จะเริ่มต้นชีวิตใหม่ด้วยปัญญา ส่วนวิมลาและกาละต่างก็ได้เรียนรู้บทเรียนราคาแพงจากการกระทำของตน
