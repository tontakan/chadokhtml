ศรัทธาเหนือเปลวเพลิง: ขาทยังคารชาดก

By wolf tbmx

Page 1/12

นานมาแล้ว ณ เมืองพาราณสีอันรุ่งเรือง มีเศรษฐีผู้หนึ่งนามว่า "วสุ" ท่านเป็นผู้ที่มีจิตใจเปี่ยมไปด้วยความเมตตาและศรัทธาในพระธรรม วสุใช้ทรัพย์สินของท่านสร้างโรงทานไว้ถึงหกแห่งเพื่อช่วยเหลือผู้ยากไร้และเหล่านักบวชที่เดินทางผ่านไปมาในเมืองนี้อย่างไม่ขาดสาย

Page 2/12

เช้าวันหนึ่ง วสุและภรรยาผู้ใจบุญนามว่า "อมรา" ได้เตรียมภัตตาหารอันประณีตบรรจุลงในถาดทองคำ ทั้งคู่ตั้งใจว่าจะถวายทานนี้แก่พระปัจเจกพุทธเจ้าผู้เสด็จมาจากภูเขาคันธมาทน์ อมราประคองถาดอาหารด้วยความเคารพ ขณะที่วสุกำลังตรวจดูความเรียบร้อยของสถานที่ด้วยจิตใจที่ผ่องใส

Page 3/12

ในขณะนั้นเอง พระปัจเจกพุทธเจ้าผู้มีใบหน้าสงบเยือกเย็นและเปี่ยมด้วยรัศมีแห่งธรรม ได้เสด็จมาหยุดยืนอยู่ที่หน้าประตูบ้านของเศรษฐีวสุ ท่านถือบาตรดินเผาด้วยกิริยาที่สำรวม สงบนิ่ง ราวกับดอกบัวที่เบ่งบานท่ามกลางสระน้ำที่เงียบสงบ

Page 4/12

ทันใดนั้น ท้องฟ้าที่เคยแจ่มใสกลับมืดครึ้ม พญามารนามว่า "กาละ" ผู้ไม่ต้องการให้วสุได้ทำบุญใหญ่ครั้งนี้ ได้ปรากฏกายขึ้นบนอากาศ กาละพยายามจะขัดขวางทางเดินของวสุด้วยฤทธานุภาพอันน่าสะพึงกลัว เพื่อทดสอบแรงศรัทธาของมหาเศรษฐีผู้ใจบุญ

Page 5/12

ด้วยอำนาจของกาละ พื้นดินระหว่างวสุและพระปัจเจกพุทธเจ้าได้แยกออก กลายเป็นบ่อถ่านเพลิงขนาดใหญ่ที่ลึกถึงแปดสิบศอก เปลวไฟสีแดงฉานพุ่งขึ้นสูง ส่งความร้อนแรงไปทั่วบริเวณ ราวกับจะเผาผลาญทุกอย่างที่เข้าใกล้ให้มอดไหม้เป็นจุณ

Page 6/12

วสุมองดูบ่อถ่านเพลิงที่ขวางกั้นระหว่างเขากับพระปัจเจกพุทธเจ้าด้วยใจที่เด็ดเดี่ยว แม้เปลวไฟจะร้อนแรงเพียงใด แต่น้ำใจของเขาที่ปรารถนาจะถวายทานนั้นกลับมั่นคงยิ่งกว่า ท่านไม่ยอมถอยหลังกลับและยืนประจันหน้ากับกองเพลิงด้วยความสงบนิ่ง

Page 7/12

กาละตะโกนลงมาจากฟากฟ้าด้วยเสียงอันดังก้องว่า "ท่านเศรษฐี! หากท่านก้าวลงไปในบ่อเพลิงนี้ ท่านจะต้องตายอย่างทรมาน จงถอยกลับไปเสียเถิด แล้วชีวิตและทรัพย์สินของท่านจะยังคงปลอดภัย!" กาละพยายามเกลี้ยกล่อมวสุให้ละทิ้งความตั้งใจ

Page 8/12

อมราที่ยืนมองอยู่ไม่ไกล มีความกังวลใจเป็นอย่างมาก นางมองสามีด้วยความรักแต่ก็เปี่ยมด้วยความศรัทธาในความดีที่ทั้งสองร่วมทำกันมา นางส่งแรงใจให้วสุสามารถข้ามผ่านอุปสรรคครั้งนี้ไปได้ เพื่อจุดมุ่งหมายอันยิ่งใหญ่คือการทำนุบำรุงพระศาสนา

Page 9/12

วสุกล่าวตอบพญามารด้วยน้ำเสียงที่นุ่มนวลแต่ทรงพลัง "ท่านมาร ชีวิตนี้เป็นของชั่วคราว แต่บุญกุศลนั้นคงอยู่ตลอดไป แม้ฉันจะต้องมอดไหม้ในบ่อเพลิงนี้ ฉันก็ยินดีที่จะทำทานเพื่อเข้าถึงพระนิพพาน!" เมื่อกล่าวจบ วสุก็ก้าวเท้าลงไปในบ่อถ่านเพลิงทันที

Page 10/12

ทันใดนั้นเอง ปาฏิหาริย์ก็บังเกิด! เมื่อเท้าของวสุสัมผัสกับเปลวไฟ ดอกบัวทองคำขนาดมหึมาได้ผุดขึ้นมาจากก้นบ่อถ่านเพลิงเพื่อรองรับเท้าของเขา ดอกบัวนั้นเย็นชุ่มฉ่ำและส่งกลิ่นหอมฟุ้งกระจายไปทั่ว ปกป้องวสุจากความร้อนแรงของเพลิงกัลป์

Page 11/12

วสุเดินบนดอกบัวจนถึงหน้าพระปัจเจกพุทธเจ้า เขาได้น้อมถวายภัตตาหารอันประณีตลงในบาตรด้วยความเคารพสูงสุด พระปัจเจกพุทธเจ้าทรงรับทานนั้นและประทานพรแก่เขา ท่ามกลางความตกตะลึงของพญามารที่พ่ายแพ้ต่อพลังแห่งศรัทธา

Page 12/12

เมื่อวสุถวายทานเสร็จสิ้น บ่อถ่านเพลิงและพญามารก็อันตรธานหายไป ทุกอย่างกลับสู่สภาพปกติ วสุและอมราได้อยู่ร่วมกันอย่างมีความสุข และประกอบคุณงามความดีสืบไป เรื่องราวศรัทธาอันยิ่งใหญ่ของวสุเศรษฐีจึงเป็นตำนานเล่าขานมาจนถึงทุกวันนี้
