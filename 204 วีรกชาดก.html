วีรกชาดก: บทเรียนของกานักเลียนแบบ

By wolf tbmx

Page 1/12

ณ สระโบกขรณีอันกว้างใหญ่ที่เต็มไปด้วยดอกบัวบานสะพรั่ง มีนกน้ำตัวหนึ่งชื่อว่า "วีรกะ" เขาเป็นนกที่มีพละกำลังและสง่างาม วีรกะใช้ชีวิตอย่างสงบสุขท่ามกลางสายน้ำที่ใสสะอาดและเย็นฉ่ำ

Page 2/12

ที่ริมสระน้ำนั้นเอง มีนกกาตัวหนึ่งชื่อว่า "สวกะ" เขามักจะเฝ้ามองวีรกะด้วยความอิจฉา สวกะเบื่อหน่ายกับการคุ้ยเขี่ยหาเศษอาหารตามพื้นดิน และปรารถนาอยากจะกินปลาสดๆ รสเลิศเหมือนอย่างที่วีรกะกินทุกวัน

Page 3/12

ทุกเช้า วีรกะจะบินโฉบลงมาจากท้องฟ้า แล้วดำดิ่งลงไปใต้ผืนน้ำอย่างรวดเร็วและนุ่มนวล เพื่อจับปลาที่ว่ายวนอยู่ด้านล่าง ท่วงท่าของเขาดูมั่นใจและชำนาญยิ่งนัก

Page 4/12

เพียงครู่เดียว วีรกะก็โผล่พ้นน้ำขึ้นมาพร้อมกับปลาตัวใหญ่ในจะงอยปาก เขาบินกลับไปที่รังเพื่ออิ่มอร่อยกับอาหารมื้อนั้น สวกะเห็นดังนั้นก็คิดในใจว่า "ถ้าเจ้าวีรกะทำได้ ข้าที่แข็งแรงกว่าก็น่าจะทำได้เหมือนกัน!"

Page 5/12

วันหนึ่ง สวกะตัดสินใจบินเข้าไปหาเจ้าวีรกะ แล้วพูดด้วยท่าทางอวดดีว่า "ท่านวีรกะ ท่านสอนวิธีดำน้ำจับปลาให้ข้าบ้างได้ไหม ข้าเบื่ออาหารบนบกเต็มทีแล้ว"

Page 6/12

วีรกะมองเพื่อนบ้านด้วยความเป็นห่วงและตอบว่า "เพื่อนสวกะเอ๋ย ธรรมชาติของเจ้าคือการหากินบนบก ร่างกายของเจ้าไม่ได้ถูกสร้างมาเพื่อดำน้ำลึก อย่าพยายามฝืนธรรมชาติเลย มันจะเกิดอันตรายได้"

Page 7/12

แต่สวกะไม่ได้ฟังคำเตือนเลยแม้แต่น้อย เขาบินกลับไปที่กิ่งไม้สูงด้วยความขุ่นเคือง "วีรกะคงจะหวงวิชาล่ะสิ กลัวว่าข้าจะเก่งกว่า ความจริงการดำน้ำมันก็แค่กระโดดลงไปเท่านั้นเอง!"

Page 8/12

สวกะเริ่มฝึกซ้อมอยู่บนบก เขาพยายามทำท่าทางโผบินและมุดหัวลงกับพื้นหญ้า เลียนแบบทุกกระบวนท่าที่เขาเคยเห็นวีรกะทำ เขาเชื่อมั่นว่าตนเองพร้อมแล้วสำหรับภารกิจใหญ่ในวันนี้

Page 9/12

สวกะบินขึ้นไปบนต้นไม้ที่สูงที่สุดริมสระ เขาหลับตาลงนึกถึงภาพปลาตัวใหญ่ แล้วรวบรวมพละกำลังทั้งหมดพุ่งดิ่งลงสู่กลางสระน้ำอย่างสุดแรงเกิด "ดูข้าให้ดีเถิด วีรกะ!" เขาร้องลั่น

Page 10/12

"ตู้ม!" สวกะกระแทกกับผิวน้ำอย่างแรง ร่างของเขาจมดิ่งลงไป แต่แทนที่จะเจอเนื้อปลาหวานฉ่ำ จะงอยปากของเขากลับปักลึกลงไปในโคลนตมที่ก้นสระ ขนปีกที่เปียกชุ่มทำให้เขาไม่สามารถขยับตัวได้

Page 11/12

วีรกะที่บินผ่านมาเห็นเหตุการณ์พยายามมองหาเพื่อนของเขา แต่เขาเห็นเพียงฟองอากาศที่พุ่งขึ้นมาและผิวน้ำที่เริ่มนิ่งสนิท วีรกะเศร้าใจนักที่คำเตือนของเขาไม่มีความหมายสำหรับสวกะเลย

Page 12/12

นิทานเรื่องนี้สอนให้รู้ว่า การไม่รู้จักประมาณตนและพยายามเลียนแบบผู้อื่นในสิ่งที่ไม่ใช่ธรรมชาติของตน ย่อมนำมาซึ่งความเดือดร้อน เหมือนกับนกกาสวกะที่ต้องพบจุดจบเพราะความดื้อรั้นและอวดดี
