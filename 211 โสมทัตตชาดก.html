บทเรียนของท่านพ่อกัสสปะ

By wolf tbmx

Page 1/12

นานมาแล้ว ณ เมืองพาราณสี มีชายหนุ่มผู้เฉลียวฉลาดนามว่า "โสมทัต" เขาเป็นข้ารับใช้คนสนิทของพระเจ้าพรหมทัต โสมทัตเป็นที่รักของทุกคนในวัง เพราะเขามีกิริยามารยาทที่งดงามและวาจาที่อ่อนหวาน

Page 2/12

แม้จะทำงานในวัง แต่โสมทัตก็ไม่เคยลืม "กัสสปะ" บิดาชราของเขาที่อาศัยอยู่ในชนบท ทุกวันหยุดเขาจะเดินทางไปเยี่ยมบิดาเพื่อนำอาหารและข้าวของเครื่องใช้ไปให้เสมอ

Page 3/12

อยู่มาวันหนึ่ง โคที่เป็นแรงงานเพียงตัวเดียวของกัสสปะได้ตายลง ทำให้ชายชราเศร้าโศกเสียใจมาก เพราะเขาไม่มีกำลังพอที่จะไถนาเลี้ยงชีพได้อีกต่อไป

Page 4/12

เมื่อโสมทัตทราบเรื่อง เขาจึงบอกบิดาว่า "ท่านพ่อ อย่ากังวลเลย ข้าจะพาไปเข้าเฝ้าพระราชา พระองค์ทรงเมตตาและต้องพระราชทานโคตัวใหม่ให้ท่านอย่างแน่นอน"

Page 5/12

โสมทัตเกรงว่าบิดาจะประหม่าเมื่ออยู่ต่อหน้าพระพักตร์ เขาจึงสอนคำพูดที่ถูกต้องให้ว่า "ท่านพ่อต้องพูดว่า 'ขอเดชะพระองค์ผู้ทรงพระคุณอันประเสริฐ โคของข้าพระพุทธเจ้าตายเสียแล้ว ขอพระองค์ทรงเมตตาประทานโคตัวใหม่ให้ด้วยเถิด'"

Page 6/12

กัสสปะตั้งใจท่องจำคำพูดนั้นทั้งวันทั้งคืน เขาเฝ้าพร่ำบ่นประโยคนั้นซ้ำไปซ้ำมาเพื่อให้ขึ้นใจ "โคของข้าพระพุทธเจ้าตายเสียแล้ว ขอพระองค์ประทานโคตัวใหม่ให้ด้วยเถิด..."

Page 7/12

เพื่อความมั่นใจ กัสสปะนำมัดหญ้ามามัดรวมกันแล้วสมมติว่าเป็นพระเจ้าพรหมทัต เขาซ้อมกราบไหว้และพูดประโยคนั้นต่อหน้ามัดหญ้าจนคล่องแคล่ว

Page 8/12

วันที่รอคอยมาถึง โสมทัตพากัสสปะเดินทางมายังพระราชวัง กัสสปะตื่นตาตื่นใจกับความหรูหราของปราสาทราชมนทีที่มีการปิดทองอร่ามไปทั่วทุกแห่ง

Page 9/12

เมื่อเข้าไปถึงท้องพระโรง พระเจ้าพรหมทัตทรงประทับรออยู่ด้วยรอยพระสรวลที่เมตตา โสมทัตถวายบังคมอย่างสง่างาม

Page 10/12

ถึงเวลาที่กัสสปะต้องพูด แต่ทันทีที่เขาเห็นสายพระเนตรอันทรงพลังของพระราชา เขาก็เกิดอาการประหม่าอย่างหนัก หัวใจเต้นรัวจนลืมสิ่งที่ซ้อมมาเสียสิ้น

Page 11/12

กัสสปะลนลานจนพูดสลับประโยคไปมา แทนที่จะขอโค เขากลับพูดว่า "ขอเดชะ โคของข้าพระพุทธเจ้ามีอยู่สองตัว ขอพระองค์ทรงเลือกเอาไปเสียตัวหนึ่งเถิด!"

Page 12/12

พระเจ้าพรหมทัตทรงทราบความจริงจากโสมทัต พระองค์ทรงเอ็นดูในความซื่อและความรักที่โสมทัตมีต่อบิดา จึงพระราชทานโคให้ถึง 16 ตัว พร้อมทรัพย์สินอีกมากมาย กัสสปะจึงเรียนรู้ว่าความตั้งใจนั้นดี แต่สติและความมั่นใจสำคัญยิ่งกว่าสิ่งใด
