หริตชรผู้หลงถิ่น

By wolf tbmx

Page 1/12

ในป่าลึกที่เต็มไปด้วยพรรณไม้แปลกตา มีงูเขียวหนุ่มตัวหนึ่งนามว่า "หริตชร" เขามีลำตัวสีเขียวสดใสประดุจใบไม้ที่เพิ่งแตกใบอ่อน หริตชรมักจะเลื้อยผ่านกิ่งไม้ด้วยท่าทางที่สง่างาม และเชื่อว่าตนเองคือสิ่งมีชีวิตที่วิเศษที่สุดในป่าแห่งนี้

Page 2/12

วันหนึ่ง หริตชรเลื้อยลงมาที่ริมสระน้ำขนาดใหญ่ เขาชะโงกหน้ามองเงาของตัวเองในน้ำ "ข้าช่างดูดีเหลือเกิน" เขาคิดในใจ ความทะนงตนทำให้เขาคิดว่าไม่ว่าที่ไหนๆ เขาก็ควรจะเป็นเจ้าของและผู้ยิ่งใหญ่ได้ทั้งนั้น

Page 3/12

ขณะที่เลื้อยไปตามตลิ่งที่ชุ่มชื้น หริตชรเหลือบไปเห็นรูขนาดใหญ่ใต้รากไม้ที่จมอยู่ใต้น้ำครึ่งหนึ่ง เขาคิดว่ามันน่าจะเป็นห้องนอนที่เย็นสบายและหรูหรา เหมาะกับงูผู้สูงส่งเช่นเขา โดยไม่เฉลียวใจเลยว่านั่นไม่ใช่ที่ถิ่นของตน

Page 4/12

"ข้าจะเข้าไปพักผ่อนในนั้น ใครๆ ก็ต้องเกรงกลัวข้าอยู่แล้ว" หริตชรพึมพำแล้วเลื้อยปราดเข้าไปในรูมืดนั้นทันที เขามั่นใจว่าความน่าเกรงขามของเขาจะทำให้สัตว์ตัวเล็กตัวน้อยในนั้นต้องยอมสยบ

Page 5/12

แต่เมื่อเข้าไปข้างใน หริตชรกลับพบว่ามันไม่ได้ว่างเปล่าอย่างที่คิด ในความสลัวนั้น เขาเผชิญหน้ากับ "ชลามณี" ปลาตัวใหญ่ที่เป็นหัวหน้าฝูงปลาในบริเวณนั้น ชลามณีจ้องมองผู้บุกรุกด้วยดวงตาที่ดุดัน

Page 6/12

"นี่ไม่ใช่ที่ของเจ้า งูเขียว!" ชลามณีส่งสัญญาณบอกเพื่อนพ้องของเธอ ปลาตัวอื่นๆ เริ่มว่ายวนรอบตัวหริตชร พวกเขาไม่เกรงกลัวงูที่หลงเข้ามาในน้ำ เพราะที่นี่คือบ้านที่พวกเขารู้จักดีที่สุด

Page 7/12

หริตชรพยายามจะขู่ แต่ในน้ำเขาเคลื่อนไหวได้ไม่ถนัดนัก ชลามณีพุ่งเข้ากัดที่หางของหริตชรเพื่อปกป้องที่อยู่อาศัย งูหนุ่มเริ่มรู้สึกตัวว่าเขาไม่ได้เป็นผู้ยิ่งใหญ่ในสถานที่แห่งนี้เสียแล้ว

Page 8/12

หริตชรเลื้อยหนีลึกเข้าไปอีกหวังจะหาทางออกอื่น แต่เขากลับไปพบกับ "ทัททระ" กบเฒ่าผู้เป็นหัวหน้าฝูงกบที่อาศัยอยู่ในโพรงไม้ส่วนที่แห้งกว่า ทัททระยืนจันก้าแสดงท่าทีขึงขังไม่ยอมให้ผู้บุกรุกผ่านไปได้ง่ายๆ

Page 9/12

"พวกเราอยู่อย่างสงบมานาน เจ้าเข้ามาทำไม?" ทัททระถามด้วยเสียงก้องกังวาน เขาพองลมที่คอจนโตแสดงถึงพลังอำนาจในถิ่นของตน หริตชรเริ่มตระหนักว่าเขาคิดผิดที่ดูถูกสัตว์ตัวเล็กๆ เหล่านี้

Page 10/12

ทัททระกระโดดเข้าใส่หริตชร พร้อมกับฝูงกบที่กรูเข้ามาช่วยกันรุมล้อม หริตชรถูกกบและปลาช่วยกันกัดและดึงรั้งเขาไว้ ความหยิ่งทะนงของเขามลายหายไป เหลือเพียงความปรารถนาที่จะหนีไปให้พ้นจากที่นี่

Page 11/12

หลังจากความพยายามอย่างหนัก หริตชรก็เลื้อยออกมาจากรูนั้นได้ในสภาพสะบักสะบอม เกล็ดสีเขียวมรกตของเขาเปื้อนโคลนและมีรอยกัดเต็มไปหมด เขาเลื้อยหนีกลับขึ้นไปบนต้นไม้อย่างรวดเร็ว

Page 12/12

เมื่ออยู่บนกิ่งไม้ที่ปลอดภัย หริตชรมองลงมาที่สระน้ำด้วยความสำนึกผิด เขาเข้าใจแล้วว่าสัตว์ทกชนิดมีที่ของตน และความเก่งกาจในที่หนึ่งไม่ได้หมายความว่าจะยิ่งใหญ่ได้ทุกที่ การเคารพถิ่นฐานของผู้อื่นคือสิ่งที่เขาต้องเรียนรู้
