สสปัณฑิตชาดก: ตำนานกระต่ายบนดวงจันทร์

By wolf tbmx

Page 1/12

นานมาแล้ว ในป่าหิมพานต์อันอุดมสมบูรณ์และเงียบสงบ มีสัตว์สี่สหายเป็นเพื่อนรักกัน ประกอบด้วยกระต่ายผู้มีปัญญาสูงส่ง นาก สุนัขจิ้งจอก และลิง พวกเขาอาศัยอยู่ร่วมกันอย่างสันติ หมั่นบำเพ็ญศีลและครองตนด้วยธรรมะอยู่เสมอ

Page 2/12

สสากะผู้เป็นหัวหน้าสหายมักจะสอนธรรมะให้แก่เพื่อนๆ อยู่เสมอ วันหนึ่งเขาได้กล่าวแก่เพื่อนทั้งสามว่า "สหายเอ๋ย วันพรุ่งนี้เป็นวันอุโบสถ พวกเราควรสละการหาอาหารเพื่อตนเอง และตั้งใจบำเพ็ญทานแก่ผู้ที่ตกทุกข์ได้ยาก"

Page 3/12

เมื่อแสงจันทร์เต็มดวงสาดส่องลงมาในคืนวันพระ สัตว์ทั้งสี่ต่างแยกย้ายกันไปเตรียมอาหารเพื่อรอรับผู้แสวงบุญ สสากะมองขึ้นไปบนดวงจันทร์ที่สว่างจ้า เขารู้สึกเบิกบานใจที่จะได้มีโอกาสสร้างมหาทานในวันอันศักดิ์สิทธิ์นี้

Page 4/12

อุทุม นากผู้คล่องแคล่ว เดินไปที่ริมตลิ่งและพบปลาตะเพียนเจ็ดตัวที่ชาวประมงลืมทิ้งไว้ เขาประกาศก้องว่า "หากใครหิวโหย โปรดมารับปลาเหล่านี้ไปกินเถิด ข้าขออุทิศสิ่งนี้เป็นทาน" แล้วเขาก็นั่งเฝ้าปลาเหล่านั้นไว้

Page 5/12

ฝ่ายมายุ สุนัขจิ้งจอก เข้าไปในกระท่อมร้างและพบเนื้อย่างสองไม้กับหม้อน้ำนม เขาจึงคาบสิ่งเหล่านั้นกลับมา "ข้าได้อาหารที่เลิศรสมาแล้ว หากมีผู้ทรงศีลผ่านมา ข้าจะมอบให้ท่านได้รับประทานอย่างอิ่มหนำ"

Page 6/12

กะปิน ลิงน้อยผู้ปราดเปรียว กระโดดขึ้นไปบนยอดไม้เพื่อเก็บมะม่วงป่าที่สุกงอม "มะม่วงเหล่านี้หวานหอมยิ่งนัก ข้าจะเก็บมันไว้เพื่อมอบเป็นทานแด่ผู้จาริกแสวงบุญ" เขาประคองผลไม้ด้วยความทะนุถนอม

Page 7/12

ส่วนสสากะกลับมายังที่พักด้วยความกังวล "ข้ามีเพียงหญ้าแพรกในรัง แต่มนุษย์ไม่กินหญ้า... ข้าไม่มีสิ่งใดจะให้ได้เลย นอกจากเลือดเนื้อและร่างกายของข้าเอง" เขาตัดสินใจอย่างเด็ดเดี่ยวว่าจะสละชีวิตตนเอง

Page 8/12

ความปรารถนาอันแรงกล้าของสสากะทำให้บัลลังก์ของท้าวสักกะเทวราชร้อนรุ่ม พระองค์จึงแปลงกายเป็นพราหมณ์เฒ่าผู้หิวโหย เดินเข้ามาในป่าเพื่อทดสอบจิตใจของสัตว์ทั้งสี่

Page 9/12

พราหมณ์เฒ่าเดินมาหาพญากระต่ายและเอ่ยว่า "ท่านกระต่าย ข้าหิวโหยและเหนื่อยล้าเหลือเกิน ท่านพอจะมีอาหารมอบให้ข้าบ้างไหม?" สสากะตอบด้วยความดีใจว่า "ท่านพราหมณ์ ท่านมาได้จังหวะดียิ่งนัก วันนี้ข้าจะมอบสิ่งที่ประเสริฐที่สุดแก่ท่าน"

Page 10/12

สสากะบอกให้พราหมณ์เตรียมก่อไฟ เมื่อกองไฟลุกโชนขึ้น สสากะก็สะบัดขนของตนเองถึงสามครั้งเพื่อเกรงว่าจะมีแมลงตัวเล็กๆ ติดอยู่ในขนและต้องตายไปพร้อมกับเขา "ขอให้ร่างกายของข้าเป็นทานที่บริสุทธิ์เถิด"

Page 11/12

ทันทีที่สสากะกระโดดเข้าสู่กองไฟที่ลุกโชน ความมหัศจรรย์ก็บังเกิดขึ้น! เปลวไฟนั้นกลับเย็นเฉียบราวกับน้ำแข็ง ไม่ได้ทำอันตรายแก่ขนแม้เพียงเส้นเดียวของเขา สสากะแปลกใจมากจึงถามพราหมณ์ถึงเหตุผล

Page 12/12

ท้าวสักกะเผยร่างจริงที่งดงามและตรัสว่า "สสากะ ความเสียสละของท่านช่างยิ่งใหญ่นัก ข้าจะจารึกความดีนี้ไว้บนดวงจันทร์ให้โลกได้รับรู้ตลอดไป" พระองค์ทรงวาดรูปกระต่ายไว้บนดวงจันทร์ด้วยยางไม้ศักดิ์สิทธิ์ นับแต่นั้นมา เราจึงเห็นรูปกระต่ายปรากฏอยู่บนดวงจันทร์ในคืนวันเพ็ญ
