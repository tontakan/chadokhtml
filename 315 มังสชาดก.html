วาจาเป็นเลิศ: บทเรียนจากมังสชาดก

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในดินแดนชมพูทวีปอันรุ่งโรจน์ มีสหายสี่คนร่วมเดินทางผ่านป่าลึกเพื่อไปยังเมืองพาราณสี ท่ามกลางหมู่ไม้และเสียงนกร้อง "ไมตรี" ชายหนุ่มผู้มีจิตใจเมตตาเดินนำหน้าพร้อมกับ "ตึกษณะ" เพื่อนผู้มีนิสัยมุทะลุและโอหัง ทั้งสี่กำลังหิวโหยและมองหาอาหารเพื่อประทังชีวิตในระหว่างการเดินทางอันยาวนาน

Page 2/12

ทันใดนั้น พวกเขาได้พบกับ "ธนู" นายพรานผู้แข็งแกร่ง เขากำลังจูงเกวียนที่เต็มไปด้วยเนื้อกวางสดใหม่ที่เพิ่งล่ามาได้ "สหายา" เพื่อนคนที่สามผู้รักความสนุกสนานตื่นเต้นเมื่อเห็นอาหารอยู่ตรงหน้า เขาชี้ให้เพื่อนดูเกวียนของนายพรานธนูที่จอดพักอยู่ใต้ร่มไม้ใหญ่ นายพรานกำลังจัดเตรียมเนื้ออย่างขะมักเขม้น

Page 3/12

ตึกษณะผู้โอหังเดินรี่เข้าไปหาเป็นคนแรก เขาตะโกนสั่งด้วยเสียงอันดังว่า "เฮ้ย! เจ้าพราน แบ่งเนื้อให้ข้ากินสักชิ้นสิ!" คำพูดที่ไร้ความเคารพนั้นกระแทกใจนายพรานธนูยิ่งนัก นายพรานเงยหน้าขึ้นมองด้วยสายตาเย็นชา รู้สึกถึงความไม่ให้เกียรติที่พวยพุ่งออกมาจากวาจาของชายผู้นี้

Page 4/12

นายพรานธนูหยิบเนื้อชิ้นที่แย่ที่สุดขึ้นมา มันเป็นเพียงเศษเนื้อติดพังผืดและกระดูกที่แข็งกระด้าง เขาส่งให้ตึกษณะพร้อมกล่าวว่า "คำพูดของเจ้านั้นแข็งกระด้างเหมือนพังผืดและไร้รสชาติเหมือนกระดูก ข้าจึงให้เนื้อที่คู่ควรกับวาจาของเจ้า" ตึกษณะรับชิ้นเนื้อไปด้วยความไม่พอใจแต่ก็ทำอะไรไม่ได้

Page 5/12

ต่อมา สหายาเดินเข้าไปหานายพรานด้วยรอยยิ้มและกล่าวว่า "พี่ชายจ๊ะ พี่ช่างเก่งกาจในการล่าสัตว์เสียนี่กะไร พอจะแบ่งเนื้อให้ข้าน้องชายผู้นี้สักหน่อยได้ไหม?" นายพรานธนูฟังแล้วรู้สึกเบาสบายใจขึ้นเล็กน้อย เพราะคำว่า "พี่ชาย" เป็นคำที่ฟังดูสนิทสนมแต่ยังขาดความลึกซึ้ง

Page 6/12

นายพรานธนูเลือกเนื้อส่วนขาหลังที่มีเนื้อนุ่มพอประมาณและมอบให้แก่สหายา "เจ้าร้องเรียกข้าว่าพี่ชาย เนื้อส่วนนี้ถือเป็นรางวัลที่เจ้ามองเห็นข้าเป็นคนคุ้นเคย" นายพรานกล่าว สหายารับเนื้อนั้นมาด้วยความยินดีที่ได้ผลลัพธ์ดีกว่าตึกษณะ

Page 7/12

จากนั้น "ปิตฤ" เพื่อนคนที่สี่ผู้มีใจอ่อนโยนเดินเข้าไปหา เขาคุกเข่าลงแล้วกล่าวด้วยเสียงสั่นเครือว่า "คุณพ่อครับ ข้าพเจ้าออกเดินทางไกลจนหิวโหยเหลือเกิน หากคุณพ่อพอจะมีเมตตาแบ่งปันอาหารให้ลูกชายคนนี้บ้าง จะเป็นพระคุณอย่างยิ่งครับ" คำว่า "พ่อ" สัมผัสไปถึงความโหยหาในใจของพรานธนู

Page 8/12

นายพรานธนูรู้สึกตื้นตันเหมือนได้พบลูกชายจริงๆ เขาจึงมอบเนื้อส่วนลำตัวและซี่โครงชั้นดีให้แก่ปิตฤ "คำว่าพ่อของเจ้านั้นยิ่งใหญ่นัก มันทำให้ใจข้าอ่อนโยนลงอย่างประหลาด จงเอาเนื้อส่วนที่อร่อยที่สุดในเกวียนนี้ไปเถิด" พรานธนูพึมพำด้วยความเอ็นดู

Page 9/12

สุดท้าย ไมตรีเดินเข้าไปหานายพรานด้วยความสงบ เขาไม่หมอบกราบและไม่ประจบประแจง แต่จ้องมองลึกลงไปในดวงตาของนายพรานและกล่าวว่า "เพื่อนยากเอ๋ย หัวใจของเรานั้นเป็นหนึ่งเดียวกัน ความหิวของข้าก็เหมือนความหิวของท่าน เราต่างเป็นสหายร่วมทุกข์ในโลกกว้างใบนี้ มีสิ่งใดที่เพื่อนจะแบ่งปันให้เพื่อนได้บ้าง?"

Page 10/12

นายพรานธนูถึงกับน้ำตาคลอด้วยความซาบซึ้ง เขาไม่เคยได้ยินคำพูดที่เสมอกันและจริงใจเช่นนี้มาก่อน "คำว่าเพื่อนของเจ้านั้นคือสิ่งที่ข้าโหยหามาทั้งชีวิต เจ้าไม่ได้มองข้าเป็นพรานชั้นต่ำ แต่เจ้ามองเห็นหัวใจของข้า จงเอาเนื้อกวางทั้งหมดและเกวียนเล่มนี้ไปเถิดสหายของข้า!"

Page 11/12

ไม่เพียงแต่เนื้อและเกวียนเท่านั้น นายพรานธนูยังได้ตัดสินใจติดตามไมตรีไปเพื่อช่วยเหลือในการเดินทาง ทั้งคู่ร่วมกินอาหารและสนทนากันอย่างมีความสุขในค่ำคืนนั้น มิตรภาพที่เกิดจากวาจาอันชาญฉลาดและจริงใจได้เปลี่ยนศัตรูให้เป็นมิตร และเปลี่ยนคนแปลกหน้าให้เป็นคู่ชีวิต

Page 12/12

เมื่อเดินทางถึงจุดหมาย ไมตรีได้สอนเพื่อนทั้งสามว่า "วาจานั้นสะท้อนถึงระดับจิตใจ ใครที่พูดจาหยาบช้าจะได้เพียงเศษซาก ใครที่พูดจาไพเราะจะได้เนื้อที่ดี แต่ใครที่พูดด้วยจิตที่เสมอภาคและรักใคร่จะได้หัวใจของมนุษย์ทั้งหมด" สหายทั้งสี่และพรานธนูจึงใช้ชีวิตร่วมกันอย่างมีความสุขสืบไป
