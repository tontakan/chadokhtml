กุฏวาณิชชาดก: ปริศนาหนูกินเหล็กกับเหยี่ยวคาบเด็ก

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในเมืองพาราณสีอันรุ่งเรือง มีพ่อค้าสองคนเป็นเพื่อนรักกัน คนหนึ่งชื่อ "ธนปาละ" เป็นคนซื่อสัตย์สุจริต ส่วนอีกคนชื่อ "กุฏิล" แม้ภายนอกจะดูใจดีแต่ภายในกลับแฝงไปด้วยความเจ้าเล่ห์ ทั้งสองมักจะตกลงทำการค้าด้วยกันเสมอในตลาดที่คลาคล่ำไปด้วยผู้คนและช้างม้า

Page 2/12

วันหนึ่ง ธนปาละมีความจำเป็นต้องเดินทางไปค้าขายในต่างเมืองเป็นเวลานาน เขามีผาลไถเหล็กจำนวนห้าร้อยเล่มซึ่งเป็นสมบัติล้ำค่า จึงนำไปฝากไว้กับกุฏิล "เพื่อนเอ๋ย ข้าฝากผาลเหล็กเหล่านี้ไว้หน่อย เมื่อข้ากลับมาแล้วจะมาขอคืน" กุฏิลยิ้มรับอย่างยินดีและรับปากว่าจะดูแลอย่างดีที่สุด

Page 3/12

หลายปีผ่านไป เมื่อธนปาละกลับมา เขาตรงไปหาเพื่อนเพื่อขอผาลเหล็กคืน แต่กุฏิลกลับทำหน้าเศร้าแล้วบอกว่า "แย่เหลือเกินเพื่อนรัก ผาลเหล็กของเจ้าวางไว้ในห้องเก็บของนานเกินไป จนพวกหนูพากันมากัดกินจนหมดสิ้น ไม่เหลือแม้แต่เล่มเดียวเลย" กุฏิลแสร้งทำเป็นเสียใจอย่างสุดซึ้ง

Page 4/12

ธนปาละรู้ทันทีว่าเพื่อนกำลังโกหก เพราะหนูที่ไหนจะกินเหล็กได้? แต่เขาไม่โต้ตอบด้วยความโกรธ เขาแสร้งทำเป็นเชื่อแล้วกล่าวว่า "ไม่เป็นไรหรอกเพื่อนรัก ในเมื่อหนูกินไปแล้วจะทำอย่างไรได้" จากนั้นเขาก็หันไปเห็น "นันทา" ลูกชายตัวน้อยของกุฏิล จึงเอ่ยชวนว่า "นันทาเอ๋ย ไปอาบน้ำที่แม่น้ำกับลุงไหม?"

Page 5/12

ธนปาละพานันทาไปยังแม่น้ำที่ห่างไกล เมื่อสบโอกาสเขาก็พาน้องน้อยไปซ่อนไว้ในถ้ำที่ปลอดภัยแห่งหนึ่งในป่า พร้อมกับหาขนมและน้ำมาให้ "เจ้าอยู่ที่นี่สักครู่นะนันทา ลุงจะไปทำธุระแล้วจะกลับมารับ" ธนปาละกล่าวด้วยความเอ็นดู ก่อนจะปิดปากถ้ำไว้อย่างมิดชิด

Page 6/12

เมื่อธนปาละกลับมาที่บ้านของกุฏิลเพียงลำพัง กุฏิลรีบวิ่งออกมาถามด้วยความตกใจ "เพื่อนรัก ลูกชายของข้าไปไหนเสียล่ะ? ทำไมเจ้ากลับมาคนเดียว?" กุฏิลเริ่มกระวนกระวายใจ สายตามองหาลูกชายสุดที่รักที่ไม่ได้เดินตามหลังเพื่อนกลับมา

Page 7/12

ธนปาละถอนหายใจยาวแล้วตอบว่า "ช่างน่าเศร้าเหลือเกินเพื่อนรัก ขณะที่ข้ากำลังพานันทาอาบน้ำที่ริมตลิ่ง จู่ๆ ก็มีเหยี่ยวยักษ์ตัวหนึ่งบินโฉบลงมาคาบลูกชายของเจ้าบินลับหายไปบนท้องฟ้า ข้าพยายามไล่ตามแล้วแต่ก็ไม่ทันจริงๆ"

Page 8/12

กุฏิลโกรธจัดจนตัวสั่น "เจ้าพูดโกหก! เหยี่ยวที่ไหนจะมีกำลังมากพอจะคาบเด็กตัวโตๆ ไปได้? เรื่องแบบนี้มันเป็นไปไม่ได้เด็ดขาด เจ้าเอาลูกชายข้าไปซ่อนไว้ที่ไหน บอกมาเดี๋ยวนี้นะ!" เขาร้องตะโกนเสียงดังจนชาวบ้านเริ่มพากันมามุงดู

Page 9/12

ธนปาละตอบกลับด้วยน้ำเสียงเรียบๆ แต่แฝงไปด้วยข้อคิดว่า "โธ่...เพื่อนรัก ในเมืองที่หนูสามารถกัดกินผาลไถเหล็กจนหมดสิ้นได้ เหตุใดเหยี่ยวจะคาบเด็กไปไม่ได้เล่า? ถ้าหนูกินเหล็กได้จริง เหยี่ยวก็คาบเด็กได้เช่นกัน" คำพูดนี้ทำให้กุฏิลชะงักไปชั่วครู่

Page 10/12

ทั้งสองคนตกลงไปหา "ท่านตุลาการ" ผู้มีปัญญาเพื่อขอให้ช่วยตัดสินความ กุฏิลรีบฟ้องร้องทันที "ท่านใต้เท้า พ่อค้าคนนี้ลักพาตัวลูกชายข้าไป แล้วยังมาโกหกหน้าตายว่าเหยี่ยวคาบเด็กไป ขอท่านโปรดให้ความเป็นธรรมแก่ข้าด้วยเถิด!"

Page 11/12

ท่านตุลาการหันมาถามธนปาละ ซึ่งเขาก็เล่าเรื่องราวทั้งหมดให้ฟังอย่างละเอียด ตั้งแต่เรื่องผาลเหล็กที่ถูกหนูกินไปจนถึงเรื่องเหยี่ยวคาบเด็ก "ในเมื่อโลกนี้มีหนูที่กินเหล็กได้ การที่เหยี่ยวจะคาบเด็กไปก็ไม่ใช่เรื่องแปลกมิใช่หรือท่าน?" ธนปาละกล่าวสรุป

Page 12/12

ท่านตุลาการหัวเราะชอบใจในปัญญาของธนปาละ และสั่งให้กุฏิลนำผาลเหล็กมาคืนเสีย กุฏิลยอมรับผิดด้วยความอับอายและคืนผาลเหล็กทั้งหมดให้เพื่อน ธนปาละจึงพานันทากลับมาส่งสู่อ้อมกอดของพ่อ ทั้งสองกลับมาเป็นเพื่อนกันอีกครั้งบนพื้นฐานของความซื่อสัตย์สืบไป
