อัสสกชาดก: บทเรียนจากหนอนตัวน้อย

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ณ แคว้นกาสี มีพระราชาผู้ทรงพระนามว่า พระเจ้าอัสสกะ พระองค์ทรงมีพระมเหสีที่สิริโฉมงดงามยิ่งนัก นามว่า พระนางอุพพรี ทั้งสองพระองค์ทรงรักกันมากและใช้ชีวิตร่วมกันอย่างมีความสุขในพระราชวังที่วิจิตรบรรจง

Page 2/12

แต่แล้วความวิปโยคก็มาเยือน เมื่อพระนางอุพพรีทรงประชวรหนักและสิ้นพระชนม์ลงอย่างกะทันหัน พระเจ้าอัสสกะทรงเศร้าโศกเสียใจอย่างที่สุด พระองค์ไม่สามารถทำใจยอมรับการจากไปของมเหสีอันเป็นที่รักได้

Page 3/12

ด้วยความอาลัยรัก พระราชาทรงให้เก็บพระศพของพระนางไว้ในหีบแก้ว และทรงนำไปวางไว้ใต้พระแท่นบรรทม พระองค์ไม่ยอมเสวยพระกระยาหารและไม่ยอมออกไปปฏิบัติพระราชกรณียกิจใดๆ ทรงเอาแต่ร่ำไห้คิดถึงพระนางทุกวันคืน

Page 4/12

ในเวลานั้น มีพระโพธิสัตว์นามว่า นารทดาบส บำเพ็ญเพียรอยู่ในป่าหิมพานต์ ท่านทรงทราบด้วยญาณวิเศษถึงความทุกข์ระทมของพระเจ้าอัสสกะ จึงตั้งใจจะเสด็จมายังพระราชอุทยานเพื่อช่วยเตือนสติพระราชาให้พ้นจากความหลงผิด

Page 5/12

นารทดาบสได้เข้าพบพระเจ้าอัสสกะในพระราชอุทยาน ท่านกล่าวกับพระราชาว่า "มหาบพิตร พระองค์ทรงเศร้าโศกถึงคนที่ตายไปแล้วเพื่ออะไร? พระนางอุพพรีได้ไปเกิดใหม่แล้วตามยถากรรมของพระนาง" แต่พระราชาทรงไม่เชื่อและปรารถนาจะพบพระนางอีกครั้ง

Page 6/12

นารทดาบสจึงใช้ฤทธิ์แสดงให้เห็นว่าพระนางอุพพรีไปเกิดที่ไหน ท่านชี้ไปที่กองมูลสัตว์ในสวน แล้วตรัสว่า "พระนางผู้สิริโฉมของพระองค์ บัดนี้ได้เกิดเป็นหนอนขี้หมูอยู่ในกองมูลนี้เอง" พระราชาทรงตกพระทัยและไม่เชื่อสายตา

Page 7/12

นารทดาบสใช้ฤทธิ์เรียกหนอนขี้หมูตัวเมีย ซึ่งก็คือพระนางอุพพรีในชาติก่อน ให้คลานออกมาพร้อมกับสามีของนางที่เป็นหนอนขี้หมูตัวผู้ ทั้งสองคลานออกมาจากกองมูลสัตว์ท่ามกลางสายตาที่ไม่อยากเชื่อของพระราชา

Page 8/12

นารทดาบสประทานพรให้หนอนตัวนั้นพูดภาษามนุษย์ได้ ท่านถามหนอนตัวเมียว่า "เจ้าจำได้หรือไม่ว่าในชาติก่อนเจ้าคือใคร? และเจ้ายังรักพระเจ้าอัสสกะ สามีเก่าของเจ้าอยู่หรือไม่?"

Page 9/12

หนอนขี้หมู (อดีตพระนางอุพพรี) ตอบอย่างไม่ลังเลว่า "ข้าแต่มหาดาบส ในชาติก่อนข้าอาจเคยเป็นมเหสีของพระราชาและเราเคยรักกันมากก็จริง แต่บัดนี้ข้าเป็นหนอน และข้าก็รักสามีหนอนตัวนี้ของข้ามากกว่าพระเจ้าอัสสกะเสียอีก!"

Page 10/12

หนอนตัวเมียกล่าวต่อไปว่า "แม้แต่เลือดจากลำคอของพระเจ้าอัสสกะ ข้ายังอยากจะเอามาล้างเท้าให้สามีหนอนของข้าเลย" คำพูดนี้เปรียบเสมือนสายฟ้าฟาดลงที่กลางใจของพระราชา ความหลงใหลในกามและความยึดติดในรูปลักษณ์เดิมมลายหายไปสิ้น

Page 11/12

นารทดาบสสอนว่า "มหาบพิตร ดูเถิด ความรักและความผูกพันนั้นไม่เที่ยงแท้ เมื่อเปลี่ยนชาติภพ ความรู้สึกก็เปลี่ยนไปตามสภาพชีวิตใหม่ ขอพระองค์จงละความโศกเศร้าและใช้ชีวิตเพื่อทำประโยชน์แก่ราษฎรเถิด"

Page 12/12

พระเจ้าอัสสกะทรงเข้าใจในสัจธรรมของชีวิต พระองค์สั่งให้นำพระศพของพระนางอุพพรีไปจัดการตามประเพณี และทรงปกครองบ้านเมืองด้วยความยุติธรรมและความไม่ประมาทสืบไป ทรงระลึกถึงบทเรียนจากหนอนตัวน้อยที่เป็นเครื่องเตือนใจให้พระองค์พ้นจากความทุกข์
