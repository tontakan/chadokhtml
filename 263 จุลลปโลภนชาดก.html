บ่วงเสน่หาแห่งอนิชกุมาร: บทเรียนจากจุลลปโลภนชาดก

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งในนครพาราณสี มีพระกุมารองค์หนึ่งนามว่า "อนิช" พระองค์ทรงเป็นผู้ที่มีรูปโฉมงดงามยิ่งนัก แต่ทว่าพระองค์กลับมีลักษณะพิเศษที่แปลกกว่าผู้ใด นั่นคือการรังเกียจสตรีมาตั้งแต่ยังเยาว์วัย พระองค์ไม่ยอมให้สตรีคนใดเข้าใกล้ แม้แต่นางนมหรือนางสนมกำนัล เพียงแค่ได้ยินเสียงหรือเห็นชายพัสตราภรณ์ของสตรี พระองค์ก็จะทรงปิดพระเนตรและหลีกหนีไปทันที

Page 2/12

พระเจ้า "พรหมทัต" ผู้เป็นพระราชบิดา ทรงเฝ้ามองพระราชบุตรด้วยความวิตกกังวล พระองค์ทรงดำริว่า หากพระกุมารยังทรงรังเกียจสตรีเช่นนี้ต่อไป ใครเล่าจะมาสืบทอดราชบัลลังก์และดูแลอาณาจักรต่อจากพระองค์ ความเงียบเหงาปกคลุมไปทั่วพระราชวัง เมื่อพระราชาทรงทอดถอนพระทัยกับชะตากรรมของราชวงศ์ที่ดูเหมือนจะสิ้นสุดลงที่พระกุมารผู้นี้

Page 3/12

ในที่สุด พระเจ้าพรหมทัตจึงทรงเรียก "คันธะ" เสนาบดีผู้เฒ่าที่เปี่ยมด้วยสติปัญญามาปรึกษา "ท่านเสนาบดี เราจะทำอย่างไรดีให้อนิชกุมารยอมเปิดใจรับไมตรีจากสตรีบ้าง?" เสนาบดีคันธะทูลตอบว่า "ข้าแต่มหาราช ธรรมชาติของจิตย่อมพ่ายแพ้ต่อรูป รส กลิ่น เสียง ที่เย้ายวน หากเราหาสตรีที่เพียบพร้อมด้วยศิลปะการร่ายรำมาดึงดูด บางทีพระกุมารอาจจะทรงเปลี่ยนพระทัย"

Page 4/12

ในนครพาราณสีนั้น มีนางรำผู้เลื่องชื่อนามว่า "ลาวัณย์" นางมิเพียงแต่มีรูปโฉมที่งดงามราวกับนางสวรรค์ แต่ยังมีทักษะในการร่ายรำและขับร้องที่สามารถสะกดใจผู้ฟังได้ทุกคน ลาวัณย์ถูกเรียกตัวเข้าเฝ้าและรับอาสาที่จะทำภารกิจนี้ นางมั่นใจในเสน่ห์และฝีมือของนางว่าจะสามารถทำให้พระกุมารผู้เย็นชาหันมามองนางได้

Page 5/12

ลาวัณย์เริ่มแผนการโดยการไปตั้งกระโจมอยู่ใกล้กับอุทยานที่อนิชกุมารมักจะเสด็จไปพักผ่อนเพียงลำพัง ทุกๆ เช้าและเย็น นางจะเริ่มขับร้องเพลงที่มีท่วงทำนองอ่อนหวาน และร่ายรำอย่างนุ่มนวลท่ามกลางมวลหมู่ไม้และดอกไม้ที่บานสะพรั่ง กลิ่นหอมของดอกไม้ป่าผสมผสานกับเสียงเพลงของนางลอยไปตามลมจนถึงโสตประสาทของพระกุมาร

Page 6/12

อนิชกุมารผู้เคยเงียบขรึม เริ่มรู้สึกถึงความเปลี่ยนแปลงบางอย่างในพระทัย เสียงเพลงที่ลาวัณย์ขับร้องนั้นช่างไพเราะและแปลกประหลาดกว่าเสียงใดที่พระองค์เคยได้ยินมา ทรงเริ่มเกิดความสงสัยว่า เจ้าของเสียงที่ไพเราะเช่นนี้จะมีรูปร่างหน้าตาเป็นอย่างไร ความถือตัวที่เคยมีเริ่มสั่นคลอนด้วยความอยากรู้อยากเห็นที่ก่อตัวขึ้นทีละน้อย

Page 7/12

วันหนึ่ง อนิชกุมารตัดสินใจเสด็จออกจากตำหนักเพื่อตามหาที่มาของเสียง และเมื่อพระองค์ทรงเห็นนางลาวัณย์ร่ายรำอยู่กลางแสงแดดอ่อนๆ พระองค์ก็ทรงตะลึงงันไปชั่วขณะ ความงดงามของนางรำที่พระองค์เคยรังเกียจ กลับกลายเป็นสิ่งดึงดูดใจอย่างที่พระองค์ไม่เคยคาดคิด ลาวัณย์แสร้งทำเป็นไม่เห็นพระองค์และยังคงร่ายรำต่อไปอย่างวิจิตรบรรจง

Page 8/12

ในที่สุด อนิชกุมารก็ก้าวเข้าไปหานางลาวัณย์ ความรังเกียจที่เคยมีมลายหายไปสิ้น ทรงตกอยู่ในห้วงแห่งความหลงใหลในทันที พระองค์ทรงลืมสิ้นทุกอย่าง ไม่ว่าจะเป็นคำสอนของพระอาจารย์ หรือความตั้งใจเดิมที่จะประพฤติพรหมจรรย์ ทรงวิงวอนให้นางลาวัณย์อยู่เคียงคู่พระองค์และไม่จากไปไหน

Page 9/12

จากพระกุมารที่เคยเคร่งครัด อนิชกุมารกลับกลายเป็นคนละคน พระองค์ทรงละทิ้งการศึกษาและการปฏิบัติภารกิจของบ้านเมือง ทรงใช้เวลาทั้งหมดอยู่กับนางลาวัณย์ในอุทยาน ทรงดื่มด่ำกับความสุขทางโลกจนไม่ลืมหูลืมตา พระเจ้าพรหมทัตและเหล่าเสนาบดีที่เคยหวังให้พระองค์เปิดใจ กลับเริ่มมองเห็นปัญหาใหม่ที่ใหญ่กว่าเดิม นั่นคือ "ความหลงผิด"

Page 10/12

ความหลงใหลแปรเปลี่ยนเป็นความหึงหวงที่บ้าคลั่ง อนิชกุมารทรงไม่อยากให้บุรุษใดได้เห็นหน้าลาวัณย์เลยแม้แต่เพียงเสี้ยววินาที พระองค์ทรงถือดาบเฝ้าคุ้มกันนางไว้ตลอดเวลา ความสงบสุขในพระทัยสูญสิ้นไป แทนที่ด้วยความหวาดระแวงและความเร่าร้อนจากไฟแห่งกามราคะที่เผาผลาญจิตใจของพระองค์จนไม่เป็นอันกินอันนอน

Page 11/12

พระเจ้าพรหมทัตและเสนาบดีคันธะเฝ้ามองเหตุการณ์อยู่ห่างๆ ด้วยความสลดใจ พระราชาทรงตระหนักได้ว่า "ความสุดโต่ง" ไม่ว่าจะเป็นการเกลียดจนสุดโต่งหรือรักจนสุดโต่ง ล้วนนำมาซึ่งความทุกข์ระทม อนิชกุมารที่เคยเป็นที่พึ่งของราษฎร บัดนี้กลับตกเป็นทาสของกิเลสจนเสียสติไป

Page 12/12

เรื่องราวของจุลลปโลภนชาดกสอนให้รู้ว่า จิตใจของคนเรานั้นหากขาดสติกำกับ ย่อมตกเป็นทาสของตัณหาได้ง่ายเปรียบดั่งไม้ขีดไฟที่พร้อมจะลุกโชน อนิชกุมารได้เรียนรู้บทเรียนอันล้ำค่าว่า การใช้ชีวิตอย่างพอดีและรู้เท่าทันอารมณ์คือหนทางแห่งสันติสุขที่แท้จริง ก่อนที่ทุกอย่างจะสายเกินไป พระองค์จึงทรงสละความหลงใหลและกลับมาคืนสู่ความสงบแห่งจิตใจอีกครั้ง
