พญาปลาผู้พิชิตความแล้งด้วยสัจจวาจา

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในสระน้ำใหญ่ที่รายล้อมด้วยพฤกษาเขียวขจีในแคว้นโกศล เป็นที่อยู่อาศัยของฝูงปลานับพัน โดยมี "อนันต์" พญาปลาผู้เปี่ยมด้วยศีลธรรมเป็นผู้นำ เขาปกครองบริวารด้วยความเมตตาและไม่เคยเบียดเบียนผู้ใด ทำให้สระน้ำแห่งนี้สงบสุขเรื่อยมา

Page 2/12

แต่แล้ววันหนึ่ง ฤดูกาลกลับผันแปรอย่างน่าประหลาด ฝนที่ควรจะตกตามฤดูกาลกลับหายไปจากท้องฟ้า ดวงอาทิตย์ส่องแสงแผดเผาจนน้ำในสระเริ่มลดน้อยลงทุกวัน อนันต์เฝ้ามองดูผืนน้ำที่เหือดแห้งด้วยความกังวลใจยิ่งนัก

Page 3/12

ความแห้งแล้งทวีความรุนแรงขึ้นจนน้ำที่เคยลึกเหลือเพียงแอ่งโคลนตมตื้นๆ ลมร้อนพัดผ่านเอาความชุ่มชื้นไปหมดสิ้น เหล่าปลาต่างพากันดิ้นรนหายใจอย่างยากลำบาก อนันต์พยายามว่ายไปรอบๆ เพื่อสำรวจความเดือดร้อนของบริวาร

Page 4/12

เมื่อน้ำแห้งขอดจนเห็นก้นสระ เหล่านกกาและฝูงนกยางที่หิวโหยก็พากันมาจับเจ่าอยู่ริมขอบสระ พวกมันคอยจ้องมองหาจังหวะที่จะโฉบกินปลาที่ติดอยู่ในโคลน ศิลาปลาตัวน้อยพยายามมุดตัวลงใต้ใบบัวที่เหี่ยวเฉาด้วยความหวาดกลัว

Page 5/12

อนันต์เห็นเพื่อนพ้องและบริวารต้องทุกข์ทรมานและล้มตายไปต่อหน้าต่อตา เขาตระหนักดีว่าพละกำลังของเขาเพียงอย่างเดียวไม่สามารถต่อสู้กับภัยแล้งที่โหดร้ายนี้ได้ เขาจึงตัดสินใจที่จะใช้พลังแห่งความดีที่สั่งสมมาทั้งชีวิตเพื่อช่วยทุกคน

Page 6/12

อนันต์เรียกศิลามาใกล้ๆ แล้วกระซิบด้วยน้ำเสียงอ่อนโยน "อย่าเพิ่งหมดหวังนะเจ้าตัวน้อย ข้าจะขอใช้สัจจวาจาเรียกฝนฟ้ามาช่วยพวกเราให้รอดพ้นจากภัยครั้งนี้" ศิลามองดูพญาปลาด้วยความเคารพและมีความหวังขึ้นมาอีกครั้ง

Page 7/12

พญาปลาอนันต์รวบรวมกำลังใจที่แน่วแน่ เขาแหวกโคลนตมขึ้นมาอยู่เหนือพื้นดินที่แตกระแหง ใจของเขามั่นคงดั่งขุนเขา ไม่มีความโกรธแค้นต่อธรรมชาติ มีเพียงความปรารถนาที่จะช่วยเหลือชีวิตผู้อื่นให้รอดพ้นจากความตาย

Page 8/12

อนันต์เงยหน้าขึ้นมองท้องฟ้าที่ว่างเปล่าแล้วกล่าวด้วยเสียงอันดังว่า "ตั้งแต่ข้าเกิดมา ข้าไม่เคยจงใจเบียดเบียนสิ่งมีชีวิตใดเลย ด้วยอำนาจแห่งสัจจวาจาที่ข้าถือมั่นมาตลอด ขอให้ฝนตกลงมาเพื่อชุบชีวิตบริวารของข้าด้วยเถิด!"

Page 9/12

ทันใดนั้น ท้องฟ้าที่เคยแจ่มใสกลับมืดครึ้มด้วยเมฆฝน "ปัชชุนนะ" เทพแห่งฝนผู้มีผิวกายสีนิลและเครื่องประดับทองคำ ปรากฏกายขึ้นเหนือหมู่เมฆ ทรงสดับฟังคำร้องขออันบริสุทธิ์และสัจวาจาที่เปี่ยมด้วยบารมีของพญาปลา

Page 10/12

ฝนเริ่มโปรยปรายลงมาเป็นสายน้ำเย็นฉ่ำในทันที หยดน้ำแต่ละหยดร่วงหล่นลงสู่พื้นดินที่ร้อนระอุ ศิลาและเหล่าปลาต่างพากันกระโดดโลดเต้นด้วยความดีใจท่ามกลางหยาดฝนที่ชโลมดินให้กลับมามีชีวิตอีกครั้ง

Page 11/12

สายฝนตกลงมาอย่างหนักจนน้ำในสระเต็มเปี่ยมดังเดิม เหล่านกกาที่เคยรังแกปลาก็พากันบินหนีหายไปในม่านฝน อนันต์และศิลากลับมาว่ายน้ำเคียงคู่กันอย่างสง่างามในบ้านที่กลับมาอุดมสมบูรณ์อีกครั้ง

Page 12/12

เทพปัชชุนนะอำนวยพรให้สระน้ำแห่งนี้ไม่แห้งแล้งอีกเลย อนันต์ได้สอนบริวารทุกคนว่า "ความสัตย์จริงและความเมตตา คือเกราะป้องกันภัยที่ยิ่งใหญ่ที่สุดที่ไม่มีสิ่งใดทำลายได้" สระน้ำแห่งนั้นจึงเต็มไปด้วยความสุขตลอดไป
