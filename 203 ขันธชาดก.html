ขันธชาดก: บทเรียนแห่งความประมาทและอสรพิษ

By wolf tbmx

Page 1/12

ในป่าหิมพานต์อันเงียบสงบ มีดาบสนามว่า "กัสสปะ" ผู้บำเพ็ญเพียรอยู่เพียงลำพัง ท่านเป็นผู้มีเมตตาต่อสรรพสัตว์รอบกาย ท่ามกลางแมกไม้ที่เขียวชอุ่มและลำธารที่ไหลเอื่อย กัสสปะใช้ชีวิตอย่างเรียบง่าย มุ่งหวังเพียงความสงบทางจิตใจและการบรรลุธรรม

Page 2/12

ทุกวันกัสสปะจะออกเดินบิณฑบาตผลไม้และน้ำสะอาดจากป่า ท่านมักจะแบ่งปันส่วนหนึ่งให้กับนกและสัตว์เล็กสัตว์น้อยที่แวะเวียนมาหา ความใจดีของท่านทำให้เหล่าสัตว์ในป่าต่างไว้วางใจและไม่เกรงกลัวมนุษย์ผู้นี้เลยแม้แต่น้อย

Page 3/12

วันหนึ่ง ขณะที่กัสสปะกำลังทำความสะอาดบริเวณอาศรม ท่านได้พบกับงูเหลือมตัวน้อยตัวหนึ่งที่ดูอ่อนแรงและหิวโหย งูตัวนั้นมีลวดลายที่สวยงามแปลกตา ท่านตั้งชื่อให้มันว่า "กุณฑละ" ด้วยความสงสาร ท่านจึงนำอาหารมาให้และยอมให้มันอาศัยอยู่ใกล้ๆ

Page 4/12

กัสสปะเริ่มผูกพันกับกุณฑละมากขึ้น ท่านมักจะพูดคุยกับมันราวกับเป็นสหายสนิท ท่านหลงลืมไปว่าโดยธรรมชาติแล้ว งูคืออสรพิษที่มีสัญชาตญาณสัตว์ป่า ความคุ้นเคยทำให้ท่านเริ่มละเลยความระมัดระวังที่ควรจะมีต่อสัตว์อันตราย

Page 5/12

นกยูงนามว่า "สกุณะ" ซึ่งอาศัยอยู่บนต้นไม้ใกล้ๆ เฝ้าสังเกตพฤติกรรมของดาบสด้วยความกังวล สกุณะพยายามส่งเสียงร้องเตือนกัสสปะอยู่บ่อยครั้งว่า สัตว์ร้ายอย่างไรก็คือสัตว์ร้าย แต่อคติที่เกิดจากความรักทำให้กัสสปะมองข้ามคำเตือนนั้นไป

Page 6/12

เวลาผ่านไปหลายเดือน กุณฑละเติบโตขึ้นอย่างรวดเร็ว ลำตัวของมันหนาและแข็งแรง ลวดลายบนหลังชัดเจนและเงางาม มันไม่ใช่ลูกงูตัวเล็กๆ อีกต่อไป แต่มันคือพญางูเหลือมที่ทรงพลังซึ่งซ่อนเร้นสัญชาตญาณนักล่าไว้ภายใต้ท่าทีสงบนิ่ง

Page 7/12

กัสสปะยังคงมีใจประมาท ท่านเชื่อมั่นในความเมตตาของตนว่าจะสามารถสยบธรรมชาติของงูได้ ท่านมักจะนั่งหลับตาสมาธิอยู่ใกล้ๆ กุณฑละ โดยไม่คาดคิดเลยว่าภัยเงียบกำลังคืบคลานเข้ามาหาท่านในยามที่ท่านเผลอตัว

Page 8/12

ในคืนหนึ่งที่อากาศหนาวเย็น กุณฑละต้องการความอบอุ่น มันค่อยๆ เลื้อยเข้าไปหาดัสสปะที่กำลังนอนหลับใหล ความหิวและสัญชาตญาณเริ่มครอบงำจิตใจของมัน มันมองเห็นร่างของดาบสเป็นเพียงเหยื่อที่ให้ความอบอุ่นและอาหารได้

Page 9/12

ทันใดนั้น กุณฑละก็เริ่มรัดพันร่างกายของกัสสปะอย่างรวดเร็วและรุนแรง ความเจ็บปวดทำให้กัสสปะสะดุ้งตื่นขึ้นมาด้วยความตกใจ ท่านพยายามดิ้นรน แต่ยิ่งดิ้น กุณฑละก็ยิ่งรัดแน่นขึ้น ราวกับจะบีบคั้นลมหายใจของท่านให้สิ้นไป

Page 10/12

"กุณฑละ ลูกรัก ทำไมเจ้าถึงทำกับเราเช่นนี้?" กัสสปะเอ่ยถามด้วยเสียงที่แผ่วเบา แต่ไม่มีคำตอบจากอสรพิษ มันเพียงแค่ทำตามธรรมชาติของมันเท่านั้น ในนาทีวิกฤต กัสสปะจึงได้ตระหนักถึงความจริงว่า ความประมาทในอสรพิษคือต้นเหตุแห่งภัยครั้งนี้

Page 11/12

กัสสปะใช้ลมหายใจสุดท้ายกำหนดสติ ท่านไม่ได้โกรธแค้นกุณฑละ แต่กลับตำหนิตนเองที่มองข้ามหลักการแห่งความระมัดระวัง ท่านพิจารณาเห็นว่าชีวิตนี้ไม่เที่ยง และความประมาทคือหนทางแห่งความตายอย่างแท้จริง

Page 12/12

เรื่องราวของกัสสปะและกุณฑละกลายเป็นบทเรียนแก่ผู้บำเพ็ญเพียรและคนทั่วไปว่า "ขึ้นชื่อว่าอสรพิษ ไม่ควรไว้วางใจแม้จะเลี้ยงดูมาดีเพียงใด" ความเมตตาต้องมาคู่กับปัญญาและความไม่ประมาท เพื่อป้องกันมิให้ภัยมาถึงตัวดั่งดาบสผู้นี้
