ปริศนาแห่งศีลและสิริมงคล

By wolf tbmx

Page 1/12

ในนครมิถิลาอันรุ่งเรือง มีชายสองคนที่เป็นที่รู้จักไปทั่ว ชายคนแรกชื่อว่า สิริ เขาเป็นผู้ที่เกิดมาพร้อมกับโชคลาภและความร่ำรวย ส่วนชายคนที่สองชื่อว่า มันฑะ เขาเป็นผู้ที่มีปัญญาเฉลียวฉลาดและยึดมั่นในศีลธรรม ทั้งสองต่างเชื่อว่าสิ่งที่ตนมีนั้นประเสริฐที่สุดในโลก

Page 2/12

สิริใช้ชีวิตอยู่ในคฤหาสน์ที่ประดับประดาด้วยอัญมณี เขามักจะอวดอ้างว่า "ความโชคดีและทรัพย์สินคือสิ่งที่บันดาลทุกอย่างได้ ใครที่มีโชคย่อมมีอำนาจเหนือผู้อื่นเสมอ" เขาเชื่อว่าทองคำสามารถซื้อความสุขและความเคารพจากผู้คนได้ทุกเมื่อ

Page 3/12

ในขณะเดียวกัน มันฑะใช้เวลาส่วนใหญ่ไปกับการศึกษาธรรมะและช่วยเหลือผู้คน เขามักสอนชาวบ้านว่า "ทรัพย์สินอาจสูญหายได้ตามกาลเวลา แต่ศีลและความบริสุทธิ์ของจิตใจจะเป็นสมบัติที่ติดตามเราไปทุกภพทุกชาติ" ความสงบเย็นของเขาทำให้ผู้ที่อยู่ใกล้รู้สึกสบายใจ

Page 4/12

เรื่องราวของชายทั้งสองไปถึงพระกรรณของพระเจ้าวิเทหะ ผู้ครองนครมิถิลา พระองค์ทรงเกิดความสงสัยว่า ระหว่าง "สิริ" คือโชคลาภ และ "มันฑะ" คือปัญญาและศีลธรรม สิ่งใดกันแน่ที่มีคุณค่ามากกว่ากันและจะนำพาชีวิตไปสู่ความสุขที่แท้จริง

Page 5/12

พระราชาทรงเรียกตัวสิริมายังพระราชวังเพื่อทดสอบ "ดูก่อนสิริ ท่านจงบอกเราซิว่า โชคลาภของท่านจะช่วยท่านได้อย่างไรในยามที่เผชิญกับปัญหาที่มองไม่เห็น?" สิริยิ้มอย่างมั่นใจและตอบว่า "โชคของข้าพเจ้าจะบันดาลทางออกและผู้อุปถัมภ์ให้เองพะยะค่ะ"

Page 6/12

สิริพรรณนาถึงความโชคดีของเขาที่ทำให้เขาได้ครอบครองที่ดินมากมายและมีข้าทาสบริวารล้อมรอบ เขาเชื่อว่าตราบใดที่มีโชค แม้ทำผิดศีลธรรมไปบ้าง โชคลาภก็ยังจะปกป้องเขาให้พ้นจากภัยพิบัติได้เสมอ

Page 7/12

ต่อมาพระราชาทรงเรียกมันฑะเข้ามาสอบถาม "แล้วท่านล่ะมันฑะ ศีลและปัญญาของท่านมีประโยชน์อย่างไรในโลกที่คนส่วนใหญ่บูชาเงินตรา?" มันฑะประนมมือและตอบด้วยน้ำเสียงที่นุ่มนวลแต่หนักแน่น

Page 8/12

พระราชาทรงตั้งปริศนาธรรมว่า "หากนกตัวหนึ่งตกอยู่ในพายุที่มืดมิด ระหว่างขนที่สวยงามกับปีกที่แข็งแรง สิ่งใดจะช่วยให้นกตัวนั้นรอดชีวิต?" พระองค์ทรงมองดูคนทั้งสองเพื่อรอฟังคำตอบที่ลึกซึ้ง

Page 9/12

มันฑะตอบว่า "ขนที่สวยงามเปรียบเสมือนโชคลาภที่น่ามอง แต่ปีกที่แข็งแรงเปรียบเสมือนศีลและปัญญาที่พาเราฝ่าพายุไปได้ ศีลที่บริสุทธิ์คือเกราะป้องกันที่ไม่มีใครทำลายได้ และปัญญาคือประทีปในความมืด"

Page 10/12

สิริเริ่มรู้สึกสับสน เขาเห็นว่าแม้เขาจะร่ำรวย แต่ลึกๆ ในใจเขายังมีความกังวลว่าทรัพย์สินจะสูญหาย แต่เมื่อเขามองดูมันฑะ เขากลับพบเพียงความสงบที่เงินทองก็ซื้อไม่ได้ มันฑะจึงกล่าวต่อว่า "ผู้ที่มีศีลย่อมไม่หวาดระแวงต่อสิ่งใด"

Page 11/12

พระเจ้าวิเทหะทรงซาบซึ้งในคำตอบ พระองค์ทรงตระหนักว่าโชคลาภอาจนำมาซึ่งความสะดวกสบาย แต่ศีลธรรมและความบริสุทธิ์ใจต่างหากที่สร้างคุณค่าที่ยั่งยืนให้กับมนุษย์ พระองค์ทรงถวายรางวัลแก่บุญญภาพของมันฑะด้วยความเคารพ

Page 12/12

จากวันนั้น สิริเริ่มลดทอนความเย่อหยิ่งและหันมาศึกษาศีลธรรมจากมันฑะ นครมิถิลากลายเป็นดินแดนที่ผู้คนไม่ได้แข่งขันกันที่ความรวย แต่แข่งขันกันที่ความดีและความบริสุทธิ์ของศีลสัตย์สืบไป
