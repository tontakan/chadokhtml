บทเรียนจากต้นทองกวาวกับกาฝากผู้อาศัย

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในป่าหิมพานต์อันกว้างใหญ่ มีต้นทองกวาวผู้สง่างามชื่อว่า "กิมสุกะ" กิมสุกะมีลำต้นแข็งแรง กิ่งก้านแผ่ขยายให้ร่มเงาแก่เหล่าสรรพสัตว์ และมีดอกสีส้มแดงสดใสราวกับเปลวเพลิงที่กำลังเริงระบำท่ามกลางแสงแดด

Page 2/12

วันหนึ่ง นกพิราบตัวน้อยชื่อว่า "กโปตะ" บินมาพักผ่อนบนกิ่งของกิมสุกะ ในจะงอยปากของมันมีเมล็ดพืชเล็กๆ เมล็ดหนึ่งที่มันบังเอิญกินเข้าไปและกำลังจะถ่ายลงบนกิ่งไม้ที่แข็งแรงนั้น

Page 3/12

กโปตะ ถ่ายเมล็ดพืชนั้นทิ้งไว้ในซอกเปลือกไม้ของกิมสุกะ เมล็ดพืชจิ๋วหล่นลงไปในร่องลึกที่ชุ่มชื้น มันคือเมล็ดของกาฝากจอมเขมือบที่รอเวลาเติบโต

Page 4/12

ไม่นานนัก เมล็ดนั้นก็แตกหน่ออ่อนสีเขียวสดใสออกมา กิมสุกะมองดูเจ้าต้นไม้จิ๋วที่ชื่อว่า "ลดา" ด้วยความเอ็นดู เขาคิดว่าการมีเพื่อนตัวน้อยมาอาศัยอยู่น่าจะเป็นเรื่องดี ลดาเริ่มชอนไชรากเล็กๆ เข้าไปในเปลือกของกิมสุกะ

Page 5/12

รุกขเทวดาเพื่อนบ้านผู้มีนามว่า "วิทูร" ซึ่งสถิตอยู่ที่ต้นไม้ใกล้ๆ มองเห็นสิ่งนั้นจึงรีบมาเตือนกิมสุกะ "สหายเอ๋ย เจ้าจงระวังลดาให้ดี กาฝากนี้แม้ตอนนี้จะเล็ก แต่เมื่อมันโตขึ้น มันจะรัดเจ้าจนตาย"

Page 6/12

กิมสุกะหัวเราะเสียงดังด้วยความมั่นใจ "ท่านวิตกเกินไปแล้ววิทูร ข้าคือต้นทองกวาวผู้ยิ่งใหญ่ ลดาตัวน้อยจะทำอะไรข้าได้ นางเป็นเพียงผู้อาศัยที่น่ารักเท่านั้น" กิมสุกะไม่ยอมทำลายลดาทิ้งตามคำเตือน

Page 7/12

เวลาผ่านไป ลดา เติบโตอย่างรวดเร็ว เถาวัลย์ของนางเริ่มพันรอบกิ่งก้านของกิมสุกะ ลดาดูดกินน้ำเลี้ยงจากลำต้นของกิมสุกะเพื่อสร้างใบที่เขียวชอุ่มของตนเองจนบดบังแสงแดดที่จะส่องถึงใบของกิมสุกะ

Page 8/12

ลดาเริ่มแผ่ขยายจนปกคลุมยอดของกิมสุกะจนหมดสิ้น รากของนางชอนไชลึกเข้าไปถึงใจกลางลำต้น แย่งชิงสารอาหารทั้งหมดมาเป็นของตนเอง กิมสุกะเริ่มรู้สึกหนักและอ่อนแรงลงทุกวัน

Page 9/12

"โอ้... เพื่อนน้อยของข้า เจ้าช่างเติบโตเร็วเหลือเกิน" กิมสุกะพึมพำ แต่คราวนี้เสียงของเขาเบาหวิวและแหบพร่า เขาเริ่มรู้ตัวแล้วว่าความใจดีที่ขาดสติกำลังจะนำภัยมาสู่ตน

Page 10/12

ในค่ำคืนที่พายุหมุนพัดแรง ฝนตกหนักจนแผ่นดินสะเทือน กิมสุกะที่เหลือแต่เพียงร่างที่ผุพังเพราะถูกลดาแย่งกินน้ำเลี้ยง ไม่เหลือเรี่ยวแรงจะต้านทานลมพายุได้อีกต่อไป

Page 11/12

"เปรี้ยง!" เสียงกิ่งก้านของกิมสุกะหักโค่นลงสู่พื้นดิน ลดาที่เกาะกินเขาอยู่ก็ล่วงหล่นลงมาพร้อมกัน ความประมาททำให้ต้นทองกวาวผู้ยิ่งใหญ่ต้องพบกับจุดจบ วิทูรมองดูภาพนั้นด้วยความเศร้าสลด

Page 12/12

วิทูรได้แต่กล่าวทิ้งท้ายไว้เป็นบทเรียนว่า "ภัยอันตรายแม้เพียงเล็กน้อย หากปล่อยไว้ไม่แก้ไข ในที่สุดมันจะเติบโตจนทำลายเราได้ เหมือนกับกาฝากที่ทำลายต้นไม้ที่มันอาศัย"
