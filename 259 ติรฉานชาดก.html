กงเกวียนกำเกวียน: บทเรียนของวสุผู้โอหัง

By wolf tbmx

Page 1/12

ในหมู่บ้านที่รุ่งเรืองแถบเชิงเขาหิมาลัย มีชายคนหนึ่งชื่อว่า "วสุ" เขาเป็นผู้มั่งคั่งด้วยทรัพย์สินและที่ดิน แต่นิสัยกลับเต็มไปด้วยความถือตัว วสุเชื่อว่ากำลังและอำนาจคือสิ่งที่สำคัญที่สุดในโลก เขาใช้ชีวิตด้วยการกดขี่ผู้ที่อ่อนแอกว่าเพื่อแสดงความยิ่งใหญ่ของตนเอง

Page 2/12

ความใจแคบของวสุไม่ได้หยุดอยู่เพียงแค่กับเพื่อนมนุษย์ เขามักจะสนุกกับการรังแกสัตว์ตัวเล็กตัวน้อยที่เขาพบเห็น ไม่ว่าจะเป็นการขว้างหินใส่เหล่านกที่กำลังร้องเพลง หรือการแกล้งทำให้เหล่ากระต่ายตกใจกลัว วสุหัวเราะเสียงดังเสมอเมื่อเห็นพวกมันหวาดกลัวและหนีไป

Page 3/12

ท่ามกลางสัตว์ทั้งหลายในบ้านของเขา มีโคหนุ่มรูปร่างกำยำนามว่า "นันทิ" นันทิเป็นโคที่มีพละกำลังมหาศาลและมีจิตใจที่อ่อนโยน มันรับใช้บุพการีของวสุมานานด้วยความซื่อสัตย์ แม้จะถูกวสุใช้งานอย่างหนักหน่วงและทุบตีอยู่บ่อยครั้ง แต่นันทิก็ยังคงสงบนิ่งเสมอ

Page 4/12

วันหนึ่ง วสุต้องการอวดพละกำลังของโคของเขา เขาจึงจัดงานประลองขึ้นและบังคับให้นันทิลากเกวียนที่บรรจุหินหนักจนเต็มลำ วสุใช้ปฏักแหลมคมทิ่มแทงและด่าทอนันทิด้วยถ้อยคำหยาบคายเพื่อให้มันออกแรงมากขึ้นโดยไม่สนเลยว่านันทิจะเจ็บปวดเพียงใด

Page 5/12

ขณะที่วสุกำลังอาละวาดอยู่นั้น พระฤๅษีผู้ทรงศีลนามว่า "กัสสปะ" ได้เดินผ่านมาท่านหยุดมองเหตุการณ์ด้วยความเวทนา พระฤๅษีกัสสปะมีรัศมีแห่งความสงบแผ่ออกมาจนแม้แต่ความร้อนระอุในสนามประลองก็ดูจะเย็นลง

Page 6/12

พระฤๅษีกัสสปะเอ่ยเตือนวสุด้วยความเมตตาว่า "ท่านวสุเอย กรรมนั้นเหมือนกงเกวียนที่หมุนตามรอยเท้าโค ท่านทำร้ายผู้อื่นด้วยวาจาและกำลัง วันหนึ่งผลแห่งการกระทำนั้นจะย้อนกลับมาหาท่านเอง สัตว์ทั้งหลายก็รักชีวิตและศักดิ์ศรีไม่ต่างจากมนุษย์"

Page 7/12

วสุหัวเราะเยาะคำเตือนนั้น "ผลกรรมอะไรกัน? ข้ามีเงินทองและพละกำลัง ข้าจะทำอะไรก็ได้!" เขาหันกลับไปด่าทอนันทิหนักกว่าเดิม และท้าพนันกับเศรษฐีคนอื่นๆ ว่านันทิจะลากเกวียนพันเล่มนี้ให้เคลื่อนที่ได้ภายในพริบตา

Page 8/12

นันทิพยายามอย่างสุดความสามารถ แต่วสุกลับยิ่งด่าทอมันว่า "ไอ้โคโง่ ไอ้สัตว์ชั้นต่ำ ลากไปเดี๋ยวนี้!" เมื่อได้ยินคำดูหมิ่นศักดิ์ศรี นันทิก็หยุดชะงัก มันไม่ยอมก้าวเดินต่อแม้แต่ก้าวเดียว ทำให้เกวียนหนักอึ้งนั้นเริ่มเสียสมดุล

Page 9/12

ทันใดนั้น ล้อเกวียนที่บรรจุหินหนักเกินขนาดก็แตกออก หินมหาศาลหล่นลงมาทับขาของวสุที่ยืนอยู่ใกล้เกินไป วสุล้มลงกับพื้นด้วยความเจ็บปวดอย่างแสนสาหัส ไม่มีใครกล้าเข้าไปช่วยเขาเพราะเกวียนกำลังจะพังทลายลงมาทั้งหมด

Page 10/12

วสุนอนจมกองเลือดและดิน เขาหันไปเห็นงูเห่าตัวหนึ่งที่เขาเคยใช้ไม้เขี่ยเล่นด้วยความสนุกสนาน เลื้อยเข้ามาใกล้ขาที่บาดเจ็บของเขา วสุรู้สึกถึงความตายที่มาเยือนและตระหนักได้ว่า ในยามที่เขาลำบาก พละกำลังที่เขาเคยอวดอ้างกลับช่วยอะไรไม่ได้เลย

Page 11/12

ทันใดนั้น นันทิที่หลุดออกจากคานเกวียนได้เดินเข้ามา แต่มันไม่ได้เข้ามาเพื่อซ้ำเติม นันทิใช้หัวอันแข็งแกร่งของมันดันก้อนหินออกจากขาของวสุ และยืนบังร่างของเจ้านายไว้ไม่ให้หินก้อนอื่นหล่นลงมาโดน วสุหลั่งน้ำตาออกมาด้วยความสำนึกผิด

Page 12/12

พระฤๅษีกัสสปะเดินกลับมาอีกครั้งและกล่าวว่า "วสุเอย บัดนี้ท่านได้เห็นแล้วว่าความเมตตาต่างหากที่ช่วยชีวิตท่าน ไม่ใช่อำนาจบาตรใหญ่" ตั้งแต่นั้นมา วสุกลายเป็นคนใหม่ที่อ่อนโยนและใช้ชีวิตด้วยความเมตตาต่อสัตว์ทุกชนิด เพราะเขารู้ซึ้งแล้วว่า กฎแห่งกรรมนั้นเที่ยงธรรมเสมอ
