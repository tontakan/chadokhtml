สุธีกับมายา: บทเรียนของนางจิ้งจอกจอมละโมบ

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ท่ามกลางหุบเขาที่เขียวขจีในดินเดนอินเดียโบราณ มีแพะหนุ่มผู้เฉลียวฉลาดตัวหนึ่งชื่อว่า "สุธี" เขามักจะใช้เวลาในแต่ละวันเล็มหญ้าอ่อนตามไหล่เขาที่สูงชันอย่างมีความสุข สุธีไม่เคยประมาทและคอยระวังตัวจากสัตว์ร้ายอยู่เสมอ

Page 2/12

ที่ตีนเขาด้านล่าง นางจิ้งจอกจอมเจ้าเล่ห์นามว่า "มายา" กำลังซุ่มมองสุธีด้วยสายตาหิวกระหาย เธอพยายามหาวิธีที่จะจับสุธีมากินเป็นอาหาร แต่รู้ดีว่าสุธีนั้นว่องไวเกินกว่าจะวิ่งไล่จับได้ง่ายๆ มายาจึงเริ่มวางแผนการร้ายโดยใช้คำลวง

Page 3/12

มายาเดินออกมาจากที่ซ่อนแล้วร้องทักสุธีด้วยน้ำเสียงที่อ่อนหวาน "โอ้ ท่านสุธีผู้สง่างาม ข้าชื่นชมในความปราดเปรื่องของท่านมานาน ข้ามิได้มาเพื่อทำร้าย แต่มาเพื่อบอกข่าวดีว่าข้าได้ละเว้นการกินเนื้อสัตว์แล้ว และอยากเป็นเพื่อนกับท่าน"

Page 4/12

มายาพยายามสร้างความน่าเชื่อถือด้วยการนำพวงมาลัยดอกไม้มาสวมคอ เธอกล่าวอ้างว่าตนเองได้กลายเป็นผู้ถือศีลและต้องการจะปกป้องสัตว์ทั้งหลายในป่าแห่งนี้ "ดูสิ สุธี ข้าเปลี่ยนไปแล้วจริงๆ" เธอปั้นหน้าเศร้าสร้อยเพื่อเรียกร้องความสงสาร

Page 5/12

สุธีมองดูมายาจากที่สูง เขาไม่ได้หลงเชื่อคำพูดเหล่านั้นเลยแม้แต่น้อย เขารู้ทันทีว่านี่คือกับดัก แต่สุธีตัดสินใจที่จะดัดหลังนางจิ้งจอกจอมละโมบ เขาจึงแสร้งทำเป็นดีใจและกล่าวว่า "ถ้าเป็นเช่นนั้นจริง ข้าก็ยินดีเหลือเกินที่จะมีผู้พิทักษ์เช่นท่าน"

Page 6/12

"ท่านมายา" สุธีเรียก "หากท่านอยากพิสูจน์ความจริงใจ ท่านช่วยลงไปในถ้ำแคบๆ ใต้หน้าผานี้ได้หรือไม่? ในนั้นมีสมบัติล้ำค่าที่ข้าเก็บรักษาไว้ ข้าอยากมอบมันให้แก่ผู้มีศีลธรรมเช่นท่านเพื่อนำไปทำทาน" มายาได้ยินคำว่าสมบัติก็หูผึ่งทันที

Page 7/12

สุธีบอกรายละเอียดเพิ่มเติมว่า "ถ้ำนี้อาจจะแคบหน่อย แต่ถ้าท่านใช้ความพยายาม ท่านจะเข้าไปถึงห้องโถงทองคำด้านในได้" เขาแอบยิ้มในใจขณะที่เห็นมายาเริ่มกระวนกระวายด้วยความอยากได้สมบัติจนลืมความระมัดระวังไปสิ้น

Page 8/12

มายาไม่รอช้า เธอรีบมุดหัวเข้าไปในช่องแคบของถ้ำทันที ความโลภทำให้เธอลืมไปว่าร่างกายของเธอนั้นใหญ่กว่าช่องทางเข้ามาก เธอพยายามดันตัวเข้าไปอย่างสุดแรงเกิด โดยหวังว่าจะได้พบกับทองคำตามที่สุธีหลอกล่อ

Page 9/12

"ฮึบ! ฮึบ!" มายาส่งเสียงร้องขณะที่พยายามเบียดตัวเข้าไป แต่แล้วเธอก็พบว่าตัวเองติดแหง็กอยู่ตรงนั้น จะเข้าไปต่อก็ไม่ได้ จะถอยออกมาก็ติดกระดูกซี่โครง เธอเริ่มรู้สึกหวาดกลัวและตะโกนขอความช่วยเหลือ "สุธี ช่วยข้าด้วย! ข้าติดอยู่ตรงนี้!"

Page 10/12

สุธีเดินเข้าไปใกล้ๆ ด้วยความใจเย็น เขาไม่ได้ขยับเข้าไปช่วย แต่ยืนมองดูนางจิ้งจอกผู้โง่เขลาด้วยสายตาที่เปี่ยมไปด้วยความสมเพช "โอ้ ท่านมายาผู้ทรงศีล ไหนล่ะความสงบสำรวมของท่าน? เหตุใดความโลภถึงทำให้ท่านมาติดอยู่ในรูเล็กๆ นี้ได้?"

Page 11/12

"ท่านพยายามจะหลอกกินข้าด้วยคำพูดจอมปลอม" สุธีกล่าวต่อ "แต่สุดท้ายความละโมบของท่านเองนั่นแหละที่เป็นกับดักที่ดักตัวท่านไว้ ข้าขอให้ท่านติดอยู่ตรงนี้สักพักเพื่อทบทวนถึงสิ่งที่ท่านได้ทำลงไป Wisdom (ปัญญา) คือเกราะป้องกันที่ดีที่สุดของข้า"

Page 12/12

สุธีเดินกลับขึ้นไปยังยอดเขาด้วยความปลอดภัย เขาเล็มหญ้าต่อไปด้วยจิตใจที่สงบสุข ส่วนมายานั้นต้องใช้เวลานานกว่าจะดิ้นหลุดออกมาได้ และเธอก็ไม่กล้ากลับมาหลอกลวงใครอีกเลย นิทานเรื่องนี้สอนให้รู้ว่า "ปัญญาที่มาพร้อมความสติ จะช่วยให้เราพ้นภัยจากคนพาล"
