พันธนาคารชาดก: เครื่องจองจำแห่งใจ

By wolf tbmx

Page 1/12

นานมาแล้ว ณ หมู่บ้านอันเงียบสงบในอินเดียโบราณ ชายหนุ่มชื่อ พันธุ (Bandhu) ผู้มีจิตใจใฝ่ในธรรม มักนั่งครุ่นคิดถึงความสงบสุขที่แท้จริง เขารู้สึกว่าชีวิตทางโลกช่างวุ่นวายและอยากจะออกบวชเพื่อค้นหาสัจธรรม แต่เขายังคงติดภาระหน้าที่ในฐานะหัวหน้าครอบครัว

Page 2/12

วันหนึ่ง พันธุ เดินเข้าไปหา มาลตี (Malati) ภรรยาผู้เลอโฉมของเขา เขาตัดสินใจบอกความในใจว่า "น้องหญิง พี่ปรารถนาจะสละความวุ่นวายนี้ไปสู่ป่าเขา เพื่อแสวงหาความหลุดพ้น" มาลตีมองเขาด้วยสายตาที่เปี่ยมไปด้วยความรักและกังวล

Page 3/12

มาลตีบอกข่าวดีแก่เขาว่าเธอกำลังตั้งครรภ์ "ท่านพี่ โปรดรอจนกว่าบุตรของเราจะลืมตาดูโลกเถิด แล้วท่านค่อยไปตามทางที่ท่านเลือก" พันธุรับคำด้วยความยินดี แต่ในใจเขารู้สึกเหมือนมีสายใยบางๆ เริ่มพันธนาการเขาไว้

Page 4/12

เวลาผ่านไป บุตรชายตัวน้อยชื่อ อริน (Aryn) ได้ถือกำเนิดขึ้น พันธุมองดูทารกน้อยด้วยความรักที่มากล้น เขาบอกตัวเองว่า "รอให้อรินเดินได้ก่อนเถิด แล้วเราค่อยจากไป" ความรักที่มีต่อลูกกลายเป็นโซ่เส้นใหม่ที่เหนียวแน่นกว่าเดิม

Page 5/12

เมื่อ อริน เริ่มเดินและวิ่งเล่นได้ พันธุเตรียมตัวจะจากไปอีกครั้ง แต่เขาก็ต้องชะงักเมื่อเห็นลูกน้อยวิ่งเข้ามากอดขาและเรียกชื่อเขาด้วยเสียงเจื้อยแจ้ว มาลตีมองดูทั้งสองด้วยรอยยิ้มที่ทำให้ใจของพันธุไหวหวั่น

Page 6/12

คืนหนึ่ง พันธุนั่งมองมาลตีที่กำลังหลับใหล เขาเห็นความงามและความอ่อนโยนของเธอ แต่ในขณะเดียวกัน เขากลับเห็นภาพนิมิตว่าความรักและความผูกพันเหล่านี้ เป็นเหมือนด้ายสีทองที่มัดตรึงกายและใจของเขาไว้กับโลกไม่ให้ไปไหน

Page 7/12

วันรุ่งขึ้น พันธุเดินผ่านลานหมู่บ้านและเห็นนักโทษคนหนึ่งถูกจองจำด้วยโซ่เหล็กหนักอึ้ง นักโทษผู้นั้นมีใบหน้าเศร้าสร้อยและพยายามจะหักโซ่ทิ้งแต่ก็ทำไม่ได้ พันธุมองดูด้วยความเวทนา

Page 8/12

ทันใดนั้น พันธุก็เกิดความรู้แจ้ง เขาตระหนักได้ว่า "โซ่ที่ทำจากเหล็ก ไม้ หรือหญ้าปล้องนั้นไม่ได้แข็งแกร่งเลย เพราะคนยังพอจะหักมันได้ด้วยพละกำลัง" เขาเริ่มเปรียบเทียบสิ่งที่เห็นกับความรู้สึกในใจตนเอง

Page 9/12

"แต่เครื่องจองจำที่ทำด้วยความกำหนัดยินดีในทรัพย์สมบัติ บุตร และภรรยานี่ต่างหากที่เป็นเครื่องจองจำอันมั่นคง" พันธุรำพึงออกมา "มันดูเหมือนอ่อนนุ่มและปลดเปลื้องได้ง่าย แต่จริงๆ แล้วมันฉุดให้คนตกลงไปในวัฏสงสารได้ลึกที่สุด"

Page 10/12

พันธุตัดสินใจบอกลามาลตีและอรินด้วยความเมตตา เขาอธิบายถึงความจริงที่เขาค้นพบ มาลตีแม้จะเศร้าใจแต่เธอก็เข้าใจในจุดมุ่งหมายอันยิ่งใหญ่ของสามี เธอจึงยอมปล่อยเขาไปเพื่อแสวงหาธรรม

Page 11/12

พันธุออกบวชเป็นฤาษีและบำเพ็ญเพียรจนจิตใจสงบนิ่ง เขาได้สอนสั่งมิตรา (Mitra) ศิษย์คนสำคัญถึงเรื่องเครื่องจองจำแห่งใจ "ผู้ที่ตัดเครื่องจองจำอันเหนียวแน่นนี้ได้เท่านั้น จึงจะพบกับเสรีภาพที่แท้จริง"

Page 12/12

เรื่องราวของพันธุเตือนใจเราว่า ความรักและความผูกพันเป็นสิ่งสวยงาม แต่หากเรายึดติดจนกลายเป็นเครื่องพันธนาการ มันจะขวางกั้นเราจากสันติสุขที่ยั่งยืน การรู้จักปล่อยวางคือหนทางสู่ความหลุดพ้นอย่างแท้จริง
