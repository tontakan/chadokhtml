กาสาวะแห่งความเมตตา: บทเรียนของพญาช้างและพรานใจบาป

By wolf tbmx

Page 1/12

ในป่าหิมพานต์อันกว้างใหญ่และเขียวขจี เป็นที่อยู่อาศัยของพญาช้างนามว่า "วารณ" ผู้มีกายสีขาวบริสุทธิ์ดุจสังข์และมีพละกำลังมหาศาล วารณไม่ได้เป็นเพียงผู้นำโขลงเท่านั้น แต่เขายังเป็นโพธิสัตว์ผู้เปี่ยมด้วยความเมตตาและรักษาสีลธรรมอย่างเคร่งครัด ท่ามกลางแมกไม้โบราณและสายน้ำใสเย็น วารณมักจะเดินนำเหล่าช้างบริวารด้วยความสง่างาม

Page 2/12

ช่างโชคร้ายที่ความงดงามของวารณกลับดึงดูดสายตาของพราน "เวธิน" ผู้โลภมาก เวธินเฝ้าแอบดูอยู่หลังพุ่มไม้ เขาไม่ได้ชื่นชมในความใจดีของพญาช้าง แต่เขากลับจ้องมองไปที่งาสีขาวผ่องคู่สวยนั้นด้วยความละโมบ "ถ้าข้าได้งาคู่นั้นไปขาย ข้าคงจะร่ำรวยไปตลอดชีวิต" เขาพึมพำกับตัวเองพร้อมกระชับธนูในมือ

Page 3/12

เวธินสังเกตเห็นสิ่งหนึ่งที่น่าประหลาดใจ ทุกครั้งที่วารณและโขลงช้างเดินผ่านพระธุดงค์ที่สุ่มห่มผ้ากาสาวพัสตร์สีเหลืองอร่าม พญาช้างจะหยุดเดินแล้วคุกเข่าลงแสดงความเคารพอย่างนอบน้อมเสมอ "เจ้าช้างพวกนี้เคารพผ้าสีเหลืองนั่นยิ่งนัก" เวธินคิดแผนชั่วร้ายขึ้นมาได้ในทันที

Page 4/12

เวธินแอบไปขโมยผ้ากาสาวพัสตร์มาจากอารามร้างแห่งหนึ่ง เขาหัวเราะในใจกับอุบายที่แยบยล "ข้าจะปลอมตัวเป็นผู้ทรงศีล เมื่อพญาช้างเข้ามาใกล้เพื่อเคารพข้า ข้าก็จะยิงมันได้อย่างง่ายดาย" ความคิดที่ขาดซึ่งความเคารพต่อสิ่งศักดิ์สิทธิ์ไม่ได้ทำให้เขาเกรงกลัวต่อบาปแม้แต่น้อย

Page 5/12

เวธินตระเตรียมลูกศรที่อาบยาพิษร้ายแรง เขาตรวจเช็คคันธนูอย่างละเอียดเพื่อให้แน่ใจว่าการยิงครั้งนี้จะไม่พลาดเป้า ในใจของเขาเต็มไปด้วยภาพของทองคำและทรัพย์สินที่เขาจะได้จากการขายงา โดยไม่คำนึงถึงชีวิตที่เขากำลังจะพรากไป

Page 6/12

เช้าวันต่อมา เวธินนำผ้าสีเหลืองมาห่มคลุมกาย ปิดบังคันธนูและศรไว้ข้างล่าง เขาไปนั่งขัดสมาธิอยู่ริมทางที่โขลงช้างจะเดินผ่าน ทำทีเป็นนั่งสมาธิอย่างสงบนิ่ง แต่ดวงตาของเขากลับคอยสอดส่ายหาเหยื่อผ่านช่องว่างของผ้า

Page 7/12

พญาช้างวารณเดินนำหน้าโขลงมาตามปกติ เมื่อเขาเห็นร่างที่ห่มผ้ากาสาวพัสตร์อยู่ใต้ต้นไม้ เขาก็หยุดชะงักด้วยความเลื่อมใส วารณค่อยๆ ก้าวเข้าไปหาด้วยความสำรวม โดยไม่รู้เลยว่าภายใต้ผ้าสีเหลืองอันศักดิ์สิทธิ์นั้นคือมัจจุราชที่รอคอยเขาอยู่

Page 8/12

ในจังหวะที่วารณก้มศีรษะลงเพื่อแสดงความเคารพ เวธินก็ฉวยโอกาสนั้นชักธนูออกมาจากใต้ผ้าเหลืองแล้วยิงลูกศรพิษเข้าใส่พญาช้างอย่างจัง ลูกศรพุ่งแหวกอากาศเข้าปักที่ร่างกายของวารณ ความเจ็บปวดแล่นพล่านไปทั่วร่างทันที

Page 9/12

วารณร้องด้วยความเจ็บปวดและทรุดตัวลง เหล่าช้างบริวารต่างพากันแตกตื่นจะเข้าทำร้ายพรานชั่ว แต่วารณกลับห้ามไว้ "อย่าทำร้ายเขา! เขาสวมผ้ากาสาวพัสตร์อยู่" แม้จะได้รับบาดเจ็บสาหัส แต่วารณยังคงมีสติและยึดมั่นในความเคารพต่อสัญลักษณ์แห่งความดีงาม

Page 10/12

วารณมองดูเวธินด้วยดวงตาที่เศร้าสร้อยแต่ไม่มีความโกรธแค้น เขาเอ่ยถามด้วยเสียงอันสั่นเครือ "ท่านทำแบบนี้ทำไม? ผ้าที่ท่านห่มอยู่นั้นเป็นเครื่องหมายของผู้ที่ละวางความโลภ แต่ท่านกลับใช้มันเพื่อการฆ่าฟัน ท่านไม่ละอายใจบ้างหรือ?"

Page 11/12

"ถ้าท่านต้องการงาของข้าเพื่อเลี้ยงชีพ ข้าจะให้ท่าน" วารณกล่าวด้วยความเมตตาอันสูงสุด เขาใช้ชวงประคองงาสีขาวของตนเองไว้ พลางสอนเวธินว่า "ผ้ากาสาวพัสตร์เป็นของสูง ผู้ที่ควรค่าแก่การห่มต้องเป็นผู้ที่สะอาดทั้งกายและใจ ไม่ใช่ผู้ที่เต็มไปด้วยเลือดและกิเลสเช่นนี้"

Page 12/12

เวธินรับงาช้างไปพร้อมน้ำตาแห่งความสำนึกผิด เขาตระหนักได้ว่าความโลภได้บดบังดวงตาของเขาจนเกือบทำลายสิ่งที่มีค่าที่สุดไป วารณจากไปอย่างสงบ ทิ้งบทเรียนเรื่องความเมตตาและการเคารพในความดีไว้ให้พรานผู้กลับใจ ซึ่งต่อจากนี้จะใช้ชีวิตอย่างมีสีลธรรมสืบไป
