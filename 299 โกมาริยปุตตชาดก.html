วิถีแห่งความสงบ: บทเรียนจากโกมาริยปุตตระ

By wolf tbmx

Page 1/12

นานมาแล้ว ณ ป่าหิมพานต์อันไกลโพ้น มีฤๅษีผู้บำเพ็ญเพียรนามว่า "โกมาริยะ" ท่านใช้ชีวิตอย่างเรียบง่าย ท่ามกลางเสียงนกร้องและสายน้ำที่ไหลริน จิตใจของท่านเปี่ยมไปด้วยความสงบเยือกเย็น ปราศจากความกังวลในทางโลก ความสุขของท่านไม่ได้เกิดจากการครอบครอง แต่เกิดจากการปล่อยวาง

Page 2/12

วันหนึ่ง ท่านโกมาริยะได้เดินทางเข้าสู่เมืองใหญ่เพื่อแสวงหาเกลือและอาหารป่า ท่านเดินผ่านฝูงชนที่วุ่นวาย เห็นผู้คนต่างรีบเร่งแสวงหาทรัพย์สินและอำนาจ ท่านมองดูความโกลาหลนั้นด้วยสายตาที่เปี่ยมไปด้วยความเมตตา ท่ามกลางความวุ่นวายนั้น ท่านได้พบกับ "ธนกะ" สหายเก่าผู้เคยร่วมศึกษาเล่าเรียนมาด้วยกัน

Page 3/12

เมื่อธนกะเห็นสหายเก่า เขารีบเข้ามาทักทายด้วยความดีใจ แต่ใบหน้าของธนกะกลับดูทรุดโทรมและเต็มไปด้วยความวิตกกังวล ดวงตาของเขาหม่นหมองเหมือนคนที่ไม่เคยนอนหลับเต็มอิ่ม เขาอาราธนาให้พระฤๅษีเข้าไปพักผ่อนที่บ้านของเขา เพื่อหวังจะระบายความทุกข์ที่อัดอั้นอยู่ในใจ

Page 4/12

เมื่อมาถึงบ้าน ท่านโกมาริยะก็ได้เห็นต้นเหตุแห่งความทุกข์ของธนกะ บ้านที่เคยคิดว่าเป็นวิมาน กลับเต็มไปด้วยภาระ ธนกะต้องคอยแบกหามข้าวของ คอยดูแลกิจการที่วุ่นวาย และจัดการปัญหามากมายที่ประดังเข้ามาไม่หยุดหย่อน เขาดูเหมือนมดที่พยายามแบกเมล็ดข้าวที่ใหญ่เกินตัว

Page 5/12

ไม่เพียงแต่ภาระทางกาย "อิชานี" ภรรยาของเขาก็มีท่าทีที่หงุดหงิด นางคอยตำหนิและเรียกร้องสิ่งต่างๆ จากธนกะอยู่เสมอ ความรักที่เคยหวานชื่นกลับกลายเป็นบ่วงที่รัดรึง ทั้งเรื่องเงินทอง ชื่อเสียง และความสะดวกสบายที่นางโหยหา ทำให้ธนกะไม่มีเวลาแม้แต่จะหายใจอย่างเป็นสุข

Page 6/12

ท่านโกมาริยะเฝ้าสังเกตการณ์อยู่เงียบๆ ท่านเห็นความยึดติดที่ก่อให้เกิดความทุกข์ ท่านเห็นว่ายิ่งมีสิ่งของมาก ยิ่งมีคนใกล้ชิดที่ยังไม่ปล่อยวาง ความสงบทางใจก็ยิ่งห่างไกลออกไป ชีวิตคู่ที่ขาดความเข้าใจและการแสวงหาที่ไม่มีวันสิ้นสุด กลายเป็นกรงขังที่มองไม่เห็นสำหรับสหายของท่าน

Page 7/12

ในยามเย็น เมื่ออิชานีเดินจากไปเพื่อจัดการงานเรือน ธนกะก็นั่งลงที่ริมน้ำพุกลางบ้านด้วยความโดดเดี่ยว เขาถอนหายใจยาวและมองไปยังท้องฟ้าที่กำลังเปลี่ยนสี ความสำเร็จทางโลกที่เขาไขว่คว้ามาได้ กลับไม่ได้มอบความสุขที่แท้จริงให้แก่เขาเลยแม้แต่น้อย

Page 8/12

ท่านโกมาริยะเดินเข้าไปหาธนกะอย่างแผ่วเบา ท่านกล่าวว่า "สหายเอ๋ย การใช้ชีวิตครองเรือนนั้นเปรียบเสมือนการแบกภาระหนักไว้บนบ่าทั้งสองข้าง เมื่อใดที่มีผู้ร่วมทางที่เต็มไปด้วยความอยาก ความหนักนั้นจะเพิ่มเป็นทวีคูณ ความสุขที่เจ้าหาอยู่นั้นเสมือนพยับแดดที่มองเห็นแต่คว้าไม่ได้"

Page 9/12

"ลองดูนกอินทรีตัวนั้นสิ" ท่านฤๅษีชี้ให้ดูนกบนท้องฟ้า "เมื่อมันคาบชิ้นเนื้อไว้ในปาก นกตัวอื่นๆ จะรุมจิกตีมันเพื่อแย่งชิงเนื้อชิ้นนั้น มันจะทุกข์และเจ็บปวด แต่เมื่อใดที่มันปล่อยชิ้นเนื้อนั้นทิ้งไป มันจะบินได้อย่างอิสระและสงบสุข ชีวิตของนักบวชผู้สันโดษก็เช่นกัน"

Page 10/12

ในขณะนั้นเอง อิชานีได้เดินกลับเข้ามาหาสามีเพื่อเรียกเขาไปทำงานต่อ นางเห็นท่านฤๅษีกำลังสั่งสอนจึงหยุดยืนฟังอยู่ห่างๆ ใบหน้าของนางเริ่มเปลี่ยนจากความโกรธเคืองเป็นความครุ่นคิด คำพูดของพระฤๅษีเริ่มสั่นคลอนความยึดมั่นในใจของนางเช่นกัน

Page 11/12

ธนกะก้มลงกราบแทบเท้าท่านโกมาริยะ เขาเข้าใจแล้วว่าความสุขไม่ได้อยู่ที่การสะสม แต่อยู่ที่การลดละความโลภและความยึดติด แม้เขาจะยังไม่ออกบวชในตอนนี้ แต่เขาตั้งใจจะใช้ชีวิตด้วยความสติและไม่ยอมตกเป็นทาสของความอยากอีกต่อไป

Page 12/12

ท่านโกมาริยะอำลาสหายและเดินทางกลับสู่ป่าหิมพานต์ ท่านเดินจากไปพร้อมกับแสงตะวันลาลับทิ้งไว้เพียงความสงบที่แผ่ซ่านไปในอากาศ ท่านรู้ดีว่าแต่ละคนมีวาระแห่งการตื่นรู้แตกต่างกัน แต่หนทางแห่งความวิเวกและการสละออกนั้น คือหนทางสู่ความสันติที่แท้จริงตลอดกาล
