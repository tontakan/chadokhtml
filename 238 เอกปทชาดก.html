เอกปทชาดก: พลังแห่งคำเดียว

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในดินแดนที่เต็มไปด้วยภูเขาสูงและป่าไม้อันอุดมสมบูรณ์ มีเศรษฐีหนุ่มคนหนึ่งนามว่า ไวศรพ เขาอาศัยอยู่ในคฤหาสน์ที่งดงามประดับประดาด้วยอัญมณี แต่ในใจของเขากลับรู้สึกว่ายังขาดอะไรบางอย่างไป เขาอยากรู้วิธีที่จะรักษาความมั่งคั่งและพบกับความสุขที่แท้จริง

Page 2/12

ไวศรพเฝ้าถามตัวเองว่า "ทำอย่างไรข้าถึงจะประสบความสำเร็จในทุกเรื่อง โดยไม่ต้องท่องจำตำราเล่มโต?" เขาตัดสินใจออกเดินทางไปตามหาผู้รู้ที่จะมอบคำสอนสั้นๆ ที่เรียบง่ายที่สุดแต่ให้ประโยชน์สูงสุดแก่เขา

Page 3/12

เขาเดินทางผ่านหมู่บ้านและข้ามแม่น้ำสายกว้าง จนกระทั่งมาถึงศาลาไม้กลางป่าที่เงียบสงบ ที่นั่นเขาได้พบกับ โพธิน นักปราชญ์ผู้มีเมตตาซึ่งเป็นพระโพธิสัตว์ที่ผู้คนต่างเคารพนับถือ

Page 4/12

เมื่อพบกับโพธิน ไวศรพกราบลงที่พื้นด้วยความเคารพ แล้วเอ่ยถามว่า "ท่านผู้เจริญ มีคำสอนเพียงคำเดียวไหมที่สามารถคุ้มครองประโยชน์ได้ทุกประการ ทั้งความร่ำรวย ชื่อเสียง และความสุข?"

Page 5/12

ไวศรพเงยหน้าขึ้นสบตากับนักปราชญ์ แววตาของเขาเต็มไปด้วยความใฝ่รู้ เขาบอกว่า "ข้าพเจ้าไม่อาจจดจำบทสวดที่ยาวเหยียดได้ โปรดประทานเพียงคำเดียวที่เปลี่ยนชีวิตข้าพเจ้าได้เถิด"

Page 6/12

โพธินยิ้มอย่างอ่อนโยนแล้วยกนิ้วขึ้นหนึ่งนิ้ว พร้อมกล่าวคำสั้นๆ ว่า "ความขยัน" (อุฏฐานะ) คำนี้เพียงคำเดียวคือหัวใจของความสำเร็จทั้งปวง ไม่ว่าจะเป็นทางโลกหรือทางธรรม

Page 7/12

ไวศรพสงสัยจึงถามต่อ โพธินจึงอธิบายว่า "คนขยันย่อมหาทรัพย์ได้ ไม่ว่าอุปสรรคจะใหญ่เพียงใด หากเจ้าลงมือทำด้วยความพากเพียร ทรัพย์สินจะหลั่งไหลมาหาเจ้าเอง"

Page 8/12

"ความขยันยังนำมาซึ่งสุขภาพและสติปัญญา" โพธินกล่าวต่อ "ผู้ที่ขยันฝึกฝนร่างกายและจิตใจ ย่อมไม่ปล่อยให้ความเกียจคร้านมาทำลายชีวิต เขาจะกลายเป็นคนที่มีกำลังวังชาและฉลาดหลักแหลม"

Page 9/12

โพธินเน้นย้ำว่า "เมื่อเจ้าขยันทำความดีและขยันรักษาศีล ชื่อเสียงที่ดีงามจะติดตามเจ้าไปทุกที่ คำว่า 'ความขยัน' จึงเป็นเกราะคุ้มครองที่แข็งแกร่งที่สุด"

Page 10/12

ไวศรพเข้าใจอย่างถ่องแท้ เขาไม่ได้เพียงแค่จำคำว่า "ขยัน" ไว้ในหัว แต่เขาตั้งใจจะนำไปใช้ในทุกวันของชีวิต เขาลาโพธินด้วยหัวใจที่พองโตด้วยความสุข

Page 11/12

เมื่อกลับมาถึงบ้าน ไวศรพได้แบ่งปันคำสอนนี้ให้กับ นันท์ ชายหนุ่มเพื่อนบ้านที่เคยท้อแท้ "จำไว้นะนันท์ เพียงขยันในทางที่ถูก ชีวิตเจ้าจะเปลี่ยนไป" ทั้งสองคนเริ่มลงมือทำงานด้วยความมุ่งมั่นร่วมกัน

Page 12/12

ตั้งแต่นั้นมา ไวศรพก็กลายเป็นมหาเศรษฐีที่ผู้คนรักใคร่ เพราะเขามีทั้งทรัพย์และความดีที่เกิดจาก "ความขยัน" เพียงคำเดียวที่ได้รับจากพระโพธิสัตว์นั่นเอง
