ความงามแห่งแม่น้ำกับเต่าผู้รื่นเริง

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ในสายน้ำที่ไหลเอื่อยของแม่น้ำคงคาอันศักดิ์สิทธิ์ มีปลาตัวหนึ่งชื่อ "กังเกยะ" เขาเป็นปลาที่มีเกล็ดสีเหลืองทองอร่าม ทุกครั้งที่เขาว่ายน้ำ เกล็ดเหล่านั้นจะสะท้อนแสงอาทิตย์จนดูราวกับมีรัศมีล้อมรอบตัว กังเกยะภูมิใจในความงามของตนเองมาก เขาเชื่อว่าไม่มีปลาตัวใดในโลกจะงดงามไปกว่าเขาอีกแล้ว

Page 2/12

ไกลออกไปในแม่น้ำอีกสายหนึ่งที่น้ำใสสะอาดไม่แพ้กัน มีปลาอีกตัวหนึ่งชื่อ "ยามุน" เขามีลำตัวสีเงินยวงสว่างไสว และมีรูปร่างที่เพรียวบางน่ามอง ยามุนชอบว่ายน้ำลอดผ่านแสงจันทร์ในยามค่ำคืน เพราะมันทำให้ตัวเขาดูเหมือนทำมาจากแก้วมณีที่ล้ำค่าที่สุดในลำน้ำ ยามุนเองก็มั่นใจว่าตนคือที่หนึ่งในเรื่องความหล่อเหลา

Page 3/12

อยู่มาวันหนึ่ง กระแสน้ำได้พัดพาให้ปลาทั้งสองมาพบกัน ณ จุดที่แม่น้ำทั้งสองสายไหลมาบรรจบกัน กังเกยะและยามุนต่างหยุดชะงักเมื่อเห็นอีกฝ่าย ทั้งคู่จ้องมองกันด้วยความสงสัย ก่อนที่ความมั่นใจในตัวเองจะเปลี่ยนเป็นความรู้สึกอยากเอาชนะ

Page 4/12

กังเกยะเริ่มโอ้อวดขึ้นก่อน "เจ้าปลาแปลกหน้า ดูเกล็ดสีทองของข้าสิ! มันคือสีของดวงอาทิตย์ยามเช้า ข้าช่างงดงามราวกับสมบัติของเทวดาที่หลุดลอยมาในน้ำ เจ้าไม่มีทางเทียบข้าได้เลย" กังเกยะพองตัวขึ้นเพื่อให้เกล็ดของเขาสะท้อนแสงให้มากที่สุด

Page 5/12

ยามุนหัวเราะเบาๆ แล้วโต้กลับว่า "ทองคำของเจ้าน่ะหรือจะสู้สีเงินที่บริสุทธิ์ของข้าได้? ดูความเพรียวบางและสีสันที่ดูสะอาดตาของข้าสิ ข้าเหมือนกับแสงดาวที่เต้นระบำอยู่บนผิวน้ำ ใครเห็นก็ต้องเหลียวมองข้ามากกว่าเจ้าแน่นอน" ยามุนว่ายวนรอบกังเกยะเพื่อแสดงความคล่องแคล่ว

Page 6/12

ทั้งคู่โต้เถียงกันไม่หยุดจนน้ำรอบๆ เริ่มขุ่นมัว "ข้าสวยกว่า!" กังเกยะตะโกน "ไม่จริง ข้าต่างหากที่สง่างามกว่า!" ยามุนเถียงกลับ เสียงของพวกเขาดังก้องไปทั่วบริเวณนั้น จนฝูงกุ้งและหอยตัวเล็กๆ ต้องรีบว่ายหนีไปเพราะความรำคาญในการอวดอ้างของปลาทั้งสอง

Page 7/12

ใกล้ๆ กับจุดที่พวกเขาทะเลาะกัน มีเต่าชราตัวหนึ่งชื่อ "กะปะ" เขากำลังหมอบนิ่งอยู่บนโขดหินใต้พุ่มไม้ริมตลิ่ง กะปะเป็นเต่าที่มีอายุยืนยาวและผ่านโลกมามาก เขาฟังเสียงเถียงกันของปลาทั้งสองด้วยใบหน้าที่เรียบเฉยแต่ในใจกลับนึกสนุก

Page 8/12

กังเกยะเห็นเต่ากะปะจึงรีบว่ายเข้าไปหา "ท่านผู้เฒ่ากะปะ! ท่านช่วยมาตัดสินให้เราที ท่านอยู่มานานย่อมมีความยุติธรรม ท่านลองดูเกล็ดทองของข้าสิ มันช่างวิเศษที่สุดใช่ไหม?" กังเกยะมองเต่ากะปะด้วยสายตาที่คาดหวังคำชม

Page 9/12

ยามุนรีบแทรกขึ้นมาทันที "อย่าเพิ่งตัดสินนะท่านกะปะ! ท่านมองดูความนวลตาของสีเงินบนตัวข้าก่อน ความงามที่เรียบง่ายแต่สูงส่งแบบนี้ต่างหากที่เป็นที่สุด ท่านว่าจริงไหม?" ยามุนพยายามว่ายไปอยู่ข้างหน้ากะปะเพื่อให้เต่ามองเห็นเขาชัดๆ

Page 10/12

ปลาทั้งสองต่างเงียบเสียงลงและเฝ้ารอคำตอบจากเต่าผู้เฒ่า พวกเขาต่างใจเต้นระทึกและคิดว่าตัวเองต้องเป็นฝ่ายชนะแน่นอน "ท่านว่าอย่างไร? ใครในพวกเราที่งดงามที่สุดในแม่น้ำสายนี้?" ทั้งคู่ถามขึ้นพร้อมกัน

Page 11/12

เต่ากะปะหัวเราะออกมาดังลั่น "ฮ่าๆๆ! พวกเจ้าช่างน่าขบขันนัก ความงามของพวกเจ้าน่ะหรือ? สำหรับข้าแล้ว ร่างกายที่มีสี่ขาแข็งแรงและมีกระดองที่กำบังภัยได้รอบตัวอย่างข้านี่ต่างหากที่งดงามและยอดเยี่ยมที่สุดในปฐพี!" กะปะยืดคอขึ้นอย่างภูมิใจ

Page 12/12

กังเกยะและยามุนนิ่งอึ้งไป พวกเขาเพิ่งสำนึกได้ว่าความงามนั้นเป็นเรื่องของมุมมองส่วนบุคคล และการมานั่งเถียงกันเพื่อเอาชนะนั้นช่างเป็นเรื่องที่เสียเวลาเพียงใด ทั้งคู่หัวเราะให้ความเขลาของตนเอง แล้วชวนกันว่ายน้ำเล่นต่อไปในฐานะเพื่อนใหม่ที่มีหัวใจงดงาม
