วิธุรบัณฑิตกับการทดสอบหัวใจแห่งศีล

By wolf tbmx

Page 1/12

นานมาแล้ว ณ นครพาราณสี มีพระราชาผู้ทรงธรรมพระนามว่า "พระเจ้าพรหมทัต" พระองค์มีที่ปรึกษาคนสนิทชื่อว่า "วิธุรบัณฑิต" ผู้เป็นที่เลื่อมใสของชาวเมืองทุกคน เพราะท่านเป็นผู้มีความรู้ท่วมท้นและมีศีลธรรมอันบริสุทธิ์

Page 2/12

พระเจ้าพรหมทัตทรงเฝ้าสังเกตวิธุรบัณฑิตมานาน พระองค์ทรงสงสัยในใจว่า "ที่ผู้คนพากันยกย่องวิธุรบัณฑิตนั้น เป็นเพราะความรู้ที่เขามี หรือเป็นเพราะศีลธรรมที่เขาปฏิบัติกันแน่?" พระองค์จึงอยากหาคำตอบเพื่อพิสูจน์ความจริงนี้

Page 3/12

วันต่อมา พระองค์ทรงเรียกพนักงานรักษาคลังเงินมาเข้าเฝ้าเป็นการส่วนตัว และทรงวางแผนการทดสอบ โดยมีคำสั่งให้พนักงานแกล้งทำเป็นไม่เห็น หากเห็นวิธุรบัณฑิตหยิบฉวยสิ่งใดไปจากคลังเงินของหลวง

Page 4/12

เมื่อวิธุรบัณฑิตเดินผ่านคลังเงินในวันแรก ท่านแกล้งหยิบเงินเหรียญทองกษาปณ์ขึ้นมาหนึ่งเหรียญ พนักงานรักษาคลังเห็นเข้าแต่ก็แสร้งทำเป็นมองไม่เห็นและไม่กล่าวโทษใดๆ ตามที่พระราชาสั่งไว้

Page 5/12

ในวันที่สอง วิธุรบัณฑิตเดินมาที่คลังเงินอีกครั้ง คราวนี้ท่านหยิบเหรียญทองไปถึงสองเหรียญ พนักงานรักษาคลังก็ยังคงนิ่งเฉยไม่ทักท้วงเช่นเดิม ทำให้วิธุรบัณฑิตเริ่มเก็บข้อมูลในใจถึงสิ่งที่เกิดขึ้น

Page 6/12

เมื่อถึงวันที่สาม วิธุรบัณฑิตหยิบเงินกำมือใหญ่ใส่ในย่ามต่อหน้าต่อตาพนักงาน คราวนี้พนักงานรักษาคลังตะโกนเรียกทหารให้มาจับกุมท่านทันที "ท่านบัณฑิตผู้ได้รับความไว้วางใจ ทำไมท่านถึงกลายเป็นหัวขโมยไปได้!"

Page 7/12

วิธุรบัณฑิตถูกคุมตัวมาต่อหน้าพระเจ้าพรหมทัต ชาวเมืองต่างพากันมาดูด้วยความตกใจและเสียใจที่เห็นบัณฑิตที่พวกเขารักถูกจับกุมในข้อหาลักทรัพย์ พระราชาทรงแสร้งทำเป็นพิโรธและตรัสถามถึงเหตุผล

Page 8/12

"ท่านวิธุรบัณฑิต ผู้คนยกย่องท่านว่าเป็นผู้มีศีล เหตุใดท่านจึงทำการทุจริตเยี่ยงนี้?" พระราชาตรัสถาม วิธุรบัณฑิตยิ้มอย่างอ่อนโยนแล้วทูลตอบว่า "ข้าแต่มหาราช ข้าพระองค์เพียงต้องการทดสอบให้เห็นแจ้งว่า ศีลหรือวิชาความรู้ สิ่งใดสำคัญกว่ากัน"

Page 9/12

วิธุรบัณฑิตอธิบายต่อว่า "ตลอดสามวันที่ข้าพระองค์หยิบเงินไป ข้าพระองค์เพียงต้องการดูว่า ความรู้ที่ข้าพระองค์มีจะช่วยให้ข้าพระองค์พ้นผิดได้ไหม แต่ความจริงก็ปรากฏว่า ต่อให้มีความรู้มากเพียงใด หากขาดศีลธรรม ย่อมถูกลงโทษและสูญเสียความเคารพ"

Page 10/12

"วันนี้ข้าพระองค์ได้คำตอบแล้วว่า ศีลธรรมนั้นประเสริฐกว่าวิชาความรู้ เพราะคนที่มีแต่ความรู้แต่ไม่มีศีล ก็เหมือนกับต้นไม้ที่งดงามแต่มีพิษ ไม่สามารถให้ร่มเงาที่ปลอดภัยแก่ใครได้เลย" วิธุรบัณฑิตกล่าวสรุป

Page 11/12

เมื่อพระเจ้าพรหมทัตได้ทรงฟังเช่นนั้น ก็ทรงประจักษ์แจ้งในความจริง พระองค์ทรงขอโทษวิธุรบัณฑิตและประกาศต่อหน้าทุกคนว่า "บัณฑิตผู้นี้ไม่ได้เป็นหัวขโมย แต่เขาคือผู้ชี้ทางสว่างให้พวกเราได้เห็นคุณค่าของศีลธรรมที่แท้จริง"

Page 12/12

ตั้งแต่วันนั้นมา ชาวเมืองพาราณสีต่างยึดถือศีลธรรมเป็นที่ตั้งเหนือสิ่งอื่นใด เพราะพวกเขาได้เรียนรู้จากวิธุรบัณฑิตว่า ความรู้ทำให้คนเก่ง แต่ศีลธรรมต่างหากที่ทำให้คนเป็นมนุษย์ที่สมบูรณ์และมีความสุขที่ยั่งยืน
