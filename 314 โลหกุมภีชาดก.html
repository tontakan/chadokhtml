เสียงเตือนจากขุมนรก: โลหกุมภีชาดก

By wolf tbmx

Page 1/12

กาลครั้งหนึ่งนานมาแล้ว ณ เมืองพาราณสี ปกครองโดยพระเจ้าพรหมทัต พระองค์ทรงเป็นกษัตริย์ที่ครองราชย์ด้วยความสงบสุขมาอย่างยาวนาน จนกระทั่งคืนหนึ่งในขณะที่ลมอุ่นพัดผ่านพระราชวัง เหตุการณ์ประหลาดที่ไม่มีใครคาดคิดก็เกิดขึ้น

Page 2/12

ในยามดึกสงัด ขณะที่ทุกคนกำลังหลับใหล พระเจ้าพรหมทัตทรงสะดุ้งตื่นขึ้นเพราะได้ยินเสียงร้องโหยหวนประหลาดสี่ครั้ง เป็นเสียงสั้นๆ ว่า "สะ... นะ... ทุ... สะ..." เสียงนั้นดังก้องไปทั่วพระราชวังราวกับมาจากส่วนลึกที่สุดของพื้นดิน

Page 3/12

เช้าวันรุ่งขึ้น พระเจ้าพรหมทัตทรงเรียกพราหมณ์ปุโรหิตเข้าเฝ้าด้วยความกระวนกระวายใจ พระองค์ทรงเล่าเรื่องเสียงปริศนาที่ได้รับฟังมา ปุโรหิตผู้ละโมบเห็นโอกาสที่จะจัดพิธีใหญ่จึงทูลว่าเป็นลางร้ายที่อาจทำให้บ้านเมืองเกิดภัยพิบัติ

Page 4/12

ปุโรหิตทูลแนะนำว่า "ข้าแต่พระองค์ ทางเดียวที่จะปัดเป่าโชคร้ายนี้ได้ คือการทำยัญพิธีบูชาไฟครั้งใหญ่ โดยต้องฆ่าสัตว์อย่างละสี่ร้อยตัว ไม่ว่าจะเป็นช้าง ม้า โค รวมถึงเด็กชายและเด็กหญิง เพื่อสังเวยแก่เทพเจ้า"

Page 5/12

ข่าวการจัดพิธียัญบูชาแพร่กระจายไปทั่ว สัตว์น้อยใหญ่นับพันถูกจับมากักขังไว้ พวกมันร้องไห้ด้วยความหวาดกลัว เสียงร้องของพวกสัตว์ดังก้องไปถึงพระกรรณของพระนางมัลลิกาอัครมเหสีผู้มีจิตใจเมตตา

Page 6/12

พระนางมัลลิกาไม่อาจทนเห็นความทุกข์ยากนี้ได้ จึงรีบเข้าเฝ้าพระเจ้าพรหมทัตและทูลเตือนสติว่า "ข้าแต่เพคะ การฆ่าชีวิตผู้อื่นเพื่อต่อชีวิตตนเองนั้นหาใช่ทางพ้นทุกข์ไม่ เราควรไปปรึกษาพระโพธิสัตว์ผู้บำเพ็ญตบะอยู่ในป่า"

Page 7/12

พระเจ้าพรหมทัตทรงเชื่อในคำแนะนำ จึงเสด็จไปยังป่าหิมพานต์เพื่อพบกับพระดาบสสุมเมธผู้มีปัญญาญาณ เมื่อไปถึง พระราชาทรงเล่าเรื่องเสียง "สะ นะ ทุ สะ" ที่รบกวนจิตใจให้พระดาบสฟัง

Page 8/12

พระดาบสหลับตาลงใช้อภิญญาตรวจสอบแล้วจึงกล่าวว่า "เสียงเหล่านั้นไม่ใช่ลางร้ายสำหรับพระองค์ แต่เป็นเสียงร้องของสัตว์นรกสี่ตนที่เคยเป็นเศรษฐีในเมืองนี้ พวกเขาต้องตกนรกโลหกุมภีเพราะเคยใช้ชีวิตอย่างประมาทและทำผิดศีล"

Page 9/12

พระดาบสอธิบายต่อไปว่า เสียง "สะ" ย่อมาจากคำที่หมายถึง 'เราเสวยทุกข์มาแล้วหกหมื่นปี เมื่อไหร่จะสิ้นสุดเสียที' พวกเขาพยายามจะร้องบอกความทุกข์ทรมานในหม้อเหล็กแดงที่ร้อนระอุ แต่พูดได้เพียงคำเดียวก็จมลงไปใหม่

Page 10/12

เสียง "นะ" "ทุ" และ "สะ" ที่เหลือ คือเสียงของความเสียดายที่ไม่ได้ทำบุญเมื่อครั้งเป็นมนุษย์ และคำมั่นสัญญาว่าถ้าได้กลับไปเป็นมนุษย์อีกครั้ง จะหมั่นทำทานและรักษาศีลให้ดีที่สุด

Page 11/12

เมื่อทรงทราบความจริง พระเจ้าพรหมทัตทรงรู้สึกสลดพระทัยและเลิกหวาดกลัว พระองค์สั่งให้ยกเลิกพิธียัญบูชาทันที และประกาศให้ปล่อยสัตว์ทุกตัวที่ถูกคุมขังกลับคืนสู่ป่าและเจ้าของเดิม

Page 12/12

เมืองพาราณสีกลับคืนสู่ความสงบสุขอีกครั้ง พระเจ้าพรหมทัตทรงครองราชย์ด้วยธรรมะ ทรงหมั่นทำบุญและรักษาศีลตามคำสอนของพระดาบสสุมเมธ และเสียงร้องโหยหวนนั้นก็ไม่เคยปรากฏให้พระองค์ได้ยินอีกเลย
